# 用語と名前の決め直し（候補の一覧）

2026-10-06 時点のたたき台。本格開発の M0 で、参考作品の名前をそのまま使っている用語と、仮の名前を決め直す。決まったものから「決定」の欄を埋め、コード・画面・`docs/CONCEPT.md`・`docs/SPEC.md` の書き換えはまとめて行う。

## 決め方の目安

- 参考作品の固有の名前（その作品で作られた言葉）は、別の名前にする
- 一般的な言葉（弱点、連携技、防御など）は、そのまま使ってよい
- 世界観（未来の人々が作った記憶のバックアップ、データの修復）に合う言葉を選ぶ。ゲームの中の言葉の系統（カタカナの機械用語か、和語か）をそろえる
- 公開前に、決めた名前で商標の検索をする（特許庁の J-PlatPat。特にタイトルと、仕組みの名前）

## 4. タイトルとキャラ名の候補（世界観とストーリーから）

考えた時の軸：

- 舞台は「未来の人々が作った、過去の街のバックアップ」。修復は、実は現実を書き戻す「上書き」のためだった
- 核の問いは「記憶を直すことは、本当に正しいのか」。結末の答えは「過去を忘れず、今を生き、未来につなぐ」
- 約100年前・現在・数十年後の3つの時代。入口は神社の鳥居、公衆電話、市の端末
- コードネームの hourglass（砂時計）：落ちた砂は戻せない／ひっくり返すとやり直せる、の両方を持つ

どの候補も、決める前に商標と、同じ名前のゲーム・作品がないかを検索すること。

### 4-1b. タイトルの候補（方向性ごとに広げたもの）

選ぶ時の目安：

- **テーマが伝わるか**：「記憶を直すことは正しいのか」が感じられるか
- **ネタばれしないか**：中盤の転換（修復＝上書き、直すたびに誰かの記憶が消える）を、タイトルで明かしすぎないか。ほのめかす程度なら伏線になる
- **探しやすいか・覚えやすいか**：ストアで検索した時に埋もれないか、口に出して言いやすいか
- **ロゴにした時**：縦持ちのスマホのタイトル画面と、ストアのアイコンで映えるか

**A. 世界の仕掛け（バックアップ・保存・上書き）**

| 候補 | 込めた意味 |
| --- | --- |
| 上書き保存しますか？ | ゲームのセーブの問いかけと、街を上書きする物語を重ねた二重の意味。遊ぶ人自身の選択にも聞こえる |
| 未保存の明日 | まだ保存されていない（＝書き換えられていない）明日。結末の「今から未来を変える」につながる |
| 復元ポイント | パソコンの「ここまで戻す」点。どこまで戻すかを選ぶ物語 |
| 差分の街 | 現実と裏側の街の「差分」。直すたびに差分が生まれる |

**避けたい・注意するもの**

- 『Rewrite』（リライト）、『残響のテロル』（残響）、『君の名は。』に似た「きみの名前」、『あの日見た花の名前を僕達はまだ知らない。』に似た「花の名前」、「Chrono（クロノ）」、「Re:」で始まる題名：有名な作品と混同されやすい

### 4-2. 裏側の街と組織の呼び名

時代ごとに呼び名が違う、という案：同じ場所を、それぞれの時代の人が自分の言葉で呼んでいる。会話の中で、誰の目線かが自然に伝わる。

| 呼ぶ人 | 呼び名の候補 | 理由 |
| --- | --- | --- |
| ソラの時代（約100年前） | 隠り世（かくりよ）、神隠しの里 | 祭りの夜に開く「神隠しの異界」として祀られていた |
| 現在の主人公たち | 裏町（うらまち）、写し世（うつしよ） | 見た目が現実の街の写しなので、子どもたちが付けたあだ名 |
| 未来の記録局 | アーカイブ、第七保存域 など | 管理する側の、事務的な呼び名 |

記録局の候補：記録局（このまま）、記憶保全局、市民記憶保存局、アーカイブ局
