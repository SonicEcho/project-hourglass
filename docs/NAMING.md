# 用語と名前の決め直し（候補の一覧）

2026-10-06 時点のたたき台。本格開発の M0 で、参考作品の名前をそのまま使っている用語と、仮の名前を決め直す。決まったものから「決定」の欄を埋め、コード・画面・`docs/CONCEPT.md`・`docs/SPEC.md` の書き換えはまとめて行う。

## 決め方の目安

- 参考作品の固有の名前（その作品で作られた言葉）は、別の名前にする
- 一般的な言葉（弱点、連携技、防御など）は、そのまま使ってよい
- 世界観（未来の人々が作った記憶のバックアップ、データの修復）に合う言葉を選ぶ。ゲームの中の言葉の系統（カタカナの機械用語か、和語か）をそろえる
- 公開前に、決めた名前で商標の検索をする（特許庁の J-PlatPat。特にタイトルと、仕組みの名前）
