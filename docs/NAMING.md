# 用語と名前の決め直し（候補の一覧）

2026-10-06 時点のたたき台。本格開発の M0 で、参考作品の名前をそのまま使っている用語と、仮の名前を決め直す。決まったものから「決定」の欄を埋め、コード・画面・`docs/CONCEPT.md`・`docs/SPEC.md` の書き換えはまとめて行う。

## 決め方の目安

- 参考作品の固有の名前（その作品で作られた言葉）は、別の名前にする
- 一般的な言葉（弱点、連携技、防御など）は、そのまま使ってよい
- 世界観（未来の人々が作った記憶のバックアップ、データの修復）に合う言葉を選ぶ。ゲームの中の言葉の系統（カタカナの機械用語か、和語か）をそろえる
- 公開前に、決めた名前で商標の検索をする（特許庁の J-PlatPat。特にタイトルと、仕組みの名前）

### 0-1. 副題の候補（RESTOPIA に添える）

選ぶ時の目安：主語が読み違えられないこと（「記憶を直す街」は街が主語に見えるので使わない）、中盤の転換を明かしすぎないこと、短く言いやすいこと。

| 方向 | 候補 |
| --- | --- |
| 遊びの中心（直す・戻す） | 街の記憶を直す／記憶が戻る街／色が戻る街／欠けた街を直しに |
| 問いかけ | その記憶、直しますか？／直すか、忘れるか／正しい昨日はどこにある／忘れることは、罪ですか |
| 3つの時代 | 三つの時代の約束／昨日と明日のあいだで／過去と今と未来のきみへ |
| 場所・世界 | 写し世の街／もうひとつの、この街／鳥居の向こうの街 |
| 感情・余韻 | 忘れないで、この街を／きみが忘れた街で／まだ、ここにいる |
| 伏線（後で意味が反転する） | 理想郷のつくりかた／良かった過去へ／誰かのための昨日／やさしい上書き（※転換をやや明かす） |

### 0-2. キャッチーな副題とキャッチコピー（販促向け）

副題（タイトルの一部。ずっと残る）とキャッチコピー（ストアの説明・広告・紹介動画で使う。変えられる）を分けて考える。副題は短く覚えやすく、気になる一言はキャッチコピーに回すと、両方の良さを使える。

**気になる（続きを知りたくなる）**

| 候補 | ねらい | ネタばれ |
| --- | --- | --- |
| 昨日を直すと、明日が変わる | 原因と結果の一文。物語の前提がすぐ分かる | なし |
| その街は、未来が作った過去のバックアップ | 世界の仕掛けそのもの。「どういうこと？」と思わせる | なし（前提なので明かしてよい） |
| 未来から「過去を直して」と頼まれた | 始まりの事件。誰が、なぜ、が気になる | なし |
| この街は、もうひとつある | 現実そっくりの裏側の街 | なし |
| 思い出せない名前がある | 未来の街の異変と、伏線の「小さな違和感」 | なし |
| 直すたび、誰かが消える | 一番強いつかみ | 中盤の転換を明かす。使うならキャッチコピーにだけ |

**覚えやすい（口に出しやすい・リズムがある）**

| 候補 | ねらい |
| --- | --- |
| なおして、なくして | 似た音のくり返し。「直す」と「失う」が隣り合う、テーマのほのめかし |
| ただいま、昨日 | あいさつの形で短い。過去へ「帰る」物語 |
| 直す？ 忘れる？ | 二択の問い。直したいあかりと、忘れたいみお |
| 3つの時代、1つの街 | 数字の対比で覚えやすい |
| 過去のきみ、未来のきみ | 3人のヒロインのうち2人（ソラとミライ）を並べた形 |

**組み合わせの例**

- RESTOPIA ―昨日を直すと、明日が変わる―（キャッチコピー：その街は、未来が作った過去のバックアップ。）
- RESTOPIA ―なおして、なくして―（キャッチコピー：直すたび、誰かが消える。）
- RESTOPIA ―ただいま、昨日―（キャッチコピー：未来から「過去を直して」と頼まれた。）

ストアの名前の欄は文字数に上限がある（30文字ほど）。副題まで入れても収まる長さにする。

## 4. タイトルとキャラ名の候補（世界観とストーリーから）

考えた時の軸：

- 舞台は「未来の人々が作った、過去の街のバックアップ」。修復は、実は現実を書き戻す「上書き」のためだった
- 核の問いは「記憶を直すことは、本当に正しいのか」。結末の答えは「過去を忘れず、今を生き、未来につなぐ」
- 約100年前・現在・数十年後の3つの時代。入口は神社の鳥居、公衆電話、市の端末
- コードネームの hourglass（砂時計）：落ちた砂は戻せない／ひっくり返すとやり直せる、の両方を持つ

どの候補も、決める前に商標と、同じ名前のゲーム・作品がないかを検索すること。

### 4-1b. タイトルの候補（方向性ごとに広げたもの）

選ぶ時の目安：

- **テーマが伝わるか**：「記憶を直すことは正しいのか」が感じられるか
- **ネタばれしないか**：中盤の転換（修復＝上書き、直すたびに誰かの記憶が消える）を、タイトルで明かしすぎないか。ほのめかす程度なら伏線になる
- **探しやすいか・覚えやすいか**：ストアで検索した時に埋もれないか、口に出して言いやすいか
- **ロゴにした時**：縦持ちのスマホのタイトル画面と、ストアのアイコンで映えるか

### 4-1c. 造語・英語のタイトルの候補（G の方向を広げたもの）

英語・造語の題名で気をつけること：日本のストアではカタカナの読みも並べて出す（例：PALIMPSEST／パリンプセスト）。ありふれた単語だけの題名は検索で埋もれやすいので、造語にするか副題を付ける。どれも同名の作品・アプリ・商標がないかを必ず調べる。

**1. 上書き・復元（物語の仕掛けそのもの）**

| 候補 | 読み | 意味 | 気をつける点 |
| --- | --- | --- | --- |
| PALIMPSEST | パリンプセスト | 文字を削って上から書き直した羊皮紙。下の文字がうっすら残る。「上書きされた街に、消えた記憶の跡が残る」という世界そのもの | 日本では知られていない言葉。意味を副題で補うとよい |
| SAVE OVER | セーブオーバー | 英語で「上書き保存する」。ゲームのセーブと、街の上書きの二重の意味 | |
| LAST KNOWN GOOD | ラスト・ノウン・グッド | パソコンの「最後に正常だった状態に戻す」機能の名前。良かった過去に戻したい記録局の考えそのもの | 長め |
| ROLLBACK | ロールバック | 変更を取り消して前の状態に戻すこと | 一般的な言葉なので副題が要る |
| UNDO TOWN | アンドゥ・タウン | 「元に戻す」の街。軽くてかわいい響き | |

### 4-2. 裏側の街と組織の呼び名

時代ごとに呼び名が違う、という案：同じ場所を、それぞれの時代の人が自分の言葉で呼んでいる。会話の中で、誰の目線かが自然に伝わる。

| 呼ぶ人 | 呼び名の候補 | 理由 |
| --- | --- | --- |
| ソラの時代（約100年前） | 隠り世（かくりよ）、神隠しの里 | 祭りの夜に開く「神隠しの異界」として祀られていた |
| 現在の主人公たち | 裏町（うらまち）、写し世（うつしよ） | 見た目が現実の街の写しなので、子どもたちが付けたあだ名 |
| 未来の記録局 | アーカイブ、第七保存域 など | 管理する側の、事務的な呼び名 |

記録局の候補：記録局（このまま）、記憶保全局、市民記憶保存局、アーカイブ局

### 4-3. キャラ名

| 今の仮名 | 立場 | 候補 | 込めた意味 |
| --- | --- | --- | --- |
| 主人公 | 現在の高校生。プレイヤーの選択が人格になる。名前は変えられるようにして、決まった名前も用意する案 | 湊（みなと）／継（つぐ）／朔（さく）／刻也（ときや） | 湊：人や時代が行き交う港。継：結末の「未来につなぐ」。朔：新月＝何もない所からの始まり。刻也：時を刻む |
| あかり | 現在のヒロイン。和菓子屋の娘。店の初代は100年前にソラへ菓子を供えていた | 縁（ゆかり）／灯（あかり。今のまま）／結（ゆい）／小町（こまち） | 縁：ソラとの100年越しの縁、和菓子の「ゆかり」にも通じる。灯：日常を照らす。結：人を結ぶ |
| みお | 10歳。友達の死を自分のせいにして、記憶を消そうとしていた。「忘れることも救い」 | 澪（みお。今のまま）／凪（なぎ）／雫（しずく）／小雪（こゆき） | 澪：船が通った後に残る水の跡＝消えない記憶。凪：嵐の後の静けさ。雫：こぼれ落ちる涙と記憶 |
| 久世 | 市の情報システム課。つらい記憶を自動で整理する機能を作り、黙っていた | 久世 祐一（くぜ ゆういち。今の苗字）／真壁 透（まかべ とおる）／鳴海 修（なるみ おさむ） | 透：透明＝隠していたことを打ち明ける人。修：自分で「修める」責任。苗字は落ち着いた大人の響きに |
| りく | 消えた友人。未来を見て「バックアップごと壊すべき」と考える | 陸（りく。今のまま）／零（れい）／迅（じん）／燈也（とうや） | 零：ゼロに戻す＝全部壊して初期化する考え方。迅：先に走り出してしまう人。陸：地に足を着けた現実を選ぶ |
| ソラ | 約100年前（大正のころ）の巫女。街の始まりを守る | 鈴（すず）／千代（ちよ）／八重（やえ）／ソラ（今のまま） | 鈴：神社の鈴、裏側の街へ渡る合図にもできる。千代：千年続く街の始まり。どれも大正のころに多い名前 |
| ミライ | 数十年後、記録局長の娘。名前を呼び合えない街に生まれた | 永遠（トワ）／那由多（ナユタ）／ノア／ミライ（今のまま） | 名前が失われていく時代なので、「数」や「記録」を思わせる名前にして、物語で「本当の名前」を取り戻す案。那由多は大きな数の単位、トワは永遠 |

- 落ち着いた和の響きでそろえる：湊・縁・澪・真壁 透・陸・鈴・永遠（トワ）
