## 0. この話で、遊ぶ人に残したい気持ち

- **最後の日にシロをひとりにした、と思っていた → 本当は、一緒に川へ行っていた → 和解の相手はいない。持ち主がひとりで、静かに受け止める（切なさ）**。4-1 は「型を崩す話」（`docs/STORY.md` の 2-16。持ち主ひとりが静かに受け止める）。翌日に誰かと抱き合って泣く場面は作らない
- **時間を盗まれたせいで、たいちは「シロの最後の日、俺は友だちと遊びに行った」と思いこんで暮らしてきた**。覚えているのは、朝シロが立てなかったことと、夜シロが死んだことだけ。その間の五十二分が抜けている。子どもの腕時計のストップウォッチに、その日の記録「52:10」だけが残っている。返すと、その五十二分が、シロと川の浅瀬にいた時間だったと分かる
- **返すと、写しは消える。何も知らずに、笑って**（4章の「写しが消える重さに初めて気づく」。`docs/STORY.md` の 2-8）：写しのシロは、自分がくり返していることを知らない。最後に一度だけしっぽを振って、砂になる。ハルトは 1-1 のひなのを思い出す（レビューの C4 の回収）。ノアの「返すなら、早く。情が移る前に」（3章）の意味が分かる
- **時間の切実さ**（2-16 の7）：おじいちゃんが、物置のシロの首輪を「もう、片付けていいか」と聞いてきた。答えは日曜（37日目）に電話で、と言われている
- **仲間の心に映す**：
  - ハルト：たいちの「ひとりにした」に、言い返せない。自分も、誰かをひとりにした気がする（理由は分からない。6章の伏線）。最後に、写しが消えることを、最初に言葉にする
  - あかり：写しのシロを撮ろうとして、やめる。「撮ったら、残っちゃう気がして」（あかりの「終わらせたくない」の、反対側に一歩）
  - みお：男の子が泣く場面だけ、黙りこむ。帰り道の交差点で、一瞬足が止まる（`docs/STORY.md` の 2-10。7章の伏線）
  - 小夜子：写しが消えることを、仲間のなかで一番静かに受け止める。「わたくしも、ああなるのですね」とは言わない。日記に一行だけ書く（終章の伏線。言葉は 4. の 37日目）
  - 店長（早瀬）：たいちの時計に「電池を替えたら記録が消える。客に聞け」とメモを残す。消えるものを残すかどうかを、客に選ばせる人（4章の後半の前置き）

## 2. 人物（4-1）

**たいち**（今16歳。ハルトたちの高校の1年生。陸上部を夏でやめた。話し方：ぶっきらぼうで、短い。年上には一応「です」。名前は候補）

- 平成30年の夏休み（10歳）、田舎のおじいちゃんの家で、老犬のシロと過ごした。シロは、たいちが生まれる前からいた白い雑種
- シロの最後の日、覚えているのは、朝シロが立てなかったことと、夜シロが死んだことだけ。その間が抜けている。「昼は、友だちとプールに行った。シロを、ひとりにした」と思いこんでいる（本当は、プールの約束を断って、シロを台車に乗せて川へ行った）
- 子どものころの腕時計（安いデジタル。ストップウォッチ付き）を、ずっと捨てられずにいる。毎日の散歩を測っていた。最後の記録は「52:10」。何の五十二分か、分からない。電池が切れて、画面が消えかけている
- 犬を見ると道を変える。河川敷は毎日通るが、川には近づかない
- 弱さ（2-16 の3）：10歳の夏、止めるおじいちゃんに「シロは俺の犬だ！ じいちゃんのじゃない！」と言った（2晩目）

**たいちのおじいちゃん**（今78歳。田舎で一人暮らし。電話の声と色の札だけ。話し方：のんびり、言葉少な。名前は出さない）

- あの日、たいちが台車でシロを連れ出すのを、止めて、止めきれなかった。帰ってきた時のたいちの顔を覚えている。「お前、あの日、笑って帰ってきたぞ」（もう一人の側。2-16 の2）
- 物置のシロの首輪を、片付けていいか、たいちに聞いている

**写しのシロ**（平成30年の夏、15歳の老犬。白い雑種。後ろ足が弱って、ほとんど立てない）

- 自分がくり返していることに気づいていない（A〜D の B）。その夏の、その日のシロのまま。たいちの声がすると、しっぽだけ振る

**写しのたいち**（平成30年の夏、10歳。麦わら帽子。首から腕時計をさげている）

- シロの散歩を毎日測っている。「今日は、記録、取らない日」と言いながら、ボタンを押す

**過去（平成30年の夏、お盆の少し前。田舎のおじいちゃんの家と、田んぼと、川）**

- 第1幕「台車」：朝。庭。シロが立てない（たいちが覚えている始まりの端）。プールに誘いに来た友だちを、たいちは「今日、むり」と帰す。物置から台車を出す。おじいちゃん「どこ行く気だ」。たいち「川」。……壁の向こうで「シロ、川、行こう」
- 第2幕「あぜ道」：昼前。あぜ道。たいちが台車を押す。シロは台車の中で、風に鼻を上げる。追ってきたおじいちゃんに、たいちが「シロは俺の犬だ！ じいちゃんのじゃない！」。おじいちゃんは黙って、麦わら帽子をシロの上にかぶせて、戻っていく。……壁の向こうで「シロ、見て——」
- 第3幕「浅瀬」：昼。川の浅瀬。たいちがシロを抱いて、水に足をつける。シロがしっぽを振る。たいちが腕時計のボタンを押す。「今日は、記録、取らない日。……うそ。取っとく」。五十二分。帰り道、たいちは笑っている。**その後、遊ぶ人にだけ見える**：誰もいない浅瀬に、麦わら帽子が流れていく

## 8. 物語の確認メモ（物語のレビューの 6. を参考に）
