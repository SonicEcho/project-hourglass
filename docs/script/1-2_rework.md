## 0. この話で、遊ぶ人に残したい気持ち

- **さみしさ → 知らなかった愛情 → 泣き笑い**。1-1 より一段深く、「時間を返すことが、人の残りの人生を変える」ことを感じてもらう
- **時間を盗まれたせいで、ふみさんは、夫に大事にされていたか分からないまま暮らしていた**。夫は「ありがとうも、ごめんも言わない人」。たった一度振り返って言ってくれた言葉だけが、盗まれていた。返すと、ふみさんは時計を止めるのをやめ、自分で巻き始める
- **ハルトとあかりの心に映す**：
  - ハルト：言葉が足りない、きよしさんと同じ型の人。あかりに「ハルトも言わないよね」と言われる。最後に、あかりに小さく一言だけ言う
  - あかり：「終わること」が怖い。ふみさんが家を手放して町を出る＝この町での暮らしが終わることに、強く反応する。「終わってから分かっても遅い」
  - りく：記憶の中を走り抜けた跡が、また見つかる（ラムネ2本）

## 2. 人物

**ふみ**（今80歳くらい。この店のいちばんの常連）

- 毎月同じ日に、亡き夫きよしの手巻きの腕時計を巻いてもらいに来る（今のまま）
- 来週、隣の県の娘の家へ越す。家は手放す。「この年で一人は、心配だって言われてね」
- 夫は無口で、ありがとうも、ごめんも言わない人だった。四十年いっしょにいて、好きだと言われたことは一度もない。「わたしのこと、どう思ってたのかしらね」
- 時計を止めて、店に預けようとしている（「向こうでは、巻いてくれる人がいないから」）。本当は、終わりにしようとしている

**しげる**（今45歳。商店街の電器屋の主人。新しく足す人）

- 昭和63年は10歳。1-2 の写しの「電器屋の子ども」（「テレビ、砂嵐になっちゃった」）その人
- 入院中のふみさんのために、きよしさんが毎晩、店に来ていたのを覚えている。病室で野球中継を聞かせたいと、小さなラジオを買いに来て、使い方が分からず三晩通った。「おじさん、あの時、ずっと怖い顔してたけど、病院の話の時だけ、手が震えてた」
- ふみさんには言っていない（「言うことじゃないと思ってた。おじさんが言わないことを」）

**過去（昭和63年の夏。ふみさんの退院の日の夕方）**

- 第1幕「出迎えの支度」：きよしさんが、退院の迎えに行く前に、商店街の店を一軒ずつ回っている。八百屋に「あいつの好きなトマト、取っといてくれ」。駄菓子屋に「ラムネ、冷やしといてくれ」。時計屋の前で立ち止まる。店の人たちに冷やかされても、むすっとしたまま。商店街じゅうの「おかえり」は、きよしさんが頼んで回ったものだった（ふみさんは知らない）
- 第2幕「帰り道」：病院から、ふみさんを自転車の荷台に乗せて帰る。商店街の人が次々に「おかえり」と声をかける。ふみさんは照れて「みんな大げさ」。坂の手前で、チェーンが外れる。ふみさんが「降りて歩きます」と言うと、きよしさんは「乗っとけ」と、手を油だらけにして直す
- 第3幕「振り返った顔」：坂の上。坂を下りる前に、きよしさんが少しだけ振り返る。「お前がおらん家はな、時計の音ばっかりして、うるさくてかなわん」「……おかえり、ってことだ」。盗まれたのは、この一度きりの「振り返り」
