## 0. この話で、遊ぶ人に残したい気持ち

- **冷たかったと思っていた別れ → 本当は、泣くのをこらえていた母 → 離れていても、同じ時刻に同じ空を見る（泣き・小）**。1〜2章の「言われた一言」（いい仕事だ・いつか鳴らす・お前なら打てる）から一歩ずれて、3-1 は**言葉にしなかった約束**の話。3章の「さよなら」の話の最初（6. の題の案）
- **時間を盗まれたせいで、ちよは「母は、出ていく私に怒っていた」と思いこんで暮らしてきた**。覚えているのは、駅に着いた昼と、汽車の中で泣いた夜だけ。その間に、汽車を待つホームで、母が自分の顔を見ずに腕時計ばかり見ていたこと（終わりの端）が、六十年、刺さっている。返すと、ちよは母と交わした「八時の約束」を思い出し、弟ののぼると、同じ時刻に同じ空を見るようになる
- **時間の切実さ**（2-16 の7）：実家は今度の水曜（26日目）に取り壊される。弟ののぼるは、取り壊しの前に母の腕時計を届けに町へ来ていて、24日目の夕方の汽車で村へ帰る
- **仲間の心に映す**：
  - ハルト：施設で育ち、仕送りを送る相手も、待っている人もいない。ちよに言うかどうかを選べる（23日目。2-16 の「小さく選ぶ」）。最後に、♥が一番多い仲間に「八時に空を見て」と言われる（24日目）
