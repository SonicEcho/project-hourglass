# ペトラとの会話（段階116。たたき台）

テストプレイのメモ 31：「ペトラとの会話イベントが欲しい（後で仲良くなって、正体が分かっても許す伏線）」。

## 0. ねらい

- ペトラは時間保管局の取引の窓口の係（`docs/STORY.md` の 2-6）。ハルトたちをアーカイバーだと思って取引している。5章でアーカイバーではないと分かっても受け入れ、6章で登録が本物だったと分かる
- 5章で「受け入れる」が自然に見えるよう、それまでに少しずつ、規則の人の中にある好奇心と、ハルトたちへの信頼を見せる
- 逆の向きの伏線も置く：ペトラの帳簿（局の仕事）が誰かを悲しませていたと、ペトラ自身が気づいていく。正体が分かった時に、ハルトたちのほうがペトラを許す（責めない）流れにもつながる
- どれも短く（10〜15行）、交換所で「話す」を押した時だけ見る。物語は止めない
