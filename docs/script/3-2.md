## 0. この話で、遊ぶ人に残したい気持ち

- **甘酸っぱさ → 切なさ → それでも、楽しかった**（`docs/STORY.md` の 2-9）。1〜3-1 の話は、返すと持ち主の今が変わった（電話をかける、店で泣く、仲間が集まる、八時に空を見る）。**3-2 は、返しても今は変わらない**（`docs/STORY.md` の 2-16「型を崩す決まり」）。言えなかった言葉は、取り戻しても言えないまま。それでも、言えなかった帰り道が、どれだけ楽しかったかを思い出す。最後に持ち主が笑う
- **今の痛みは「思いこみ」ではなく「分からない」**：1〜2章の持ち主は、抜けた真ん中を悪い方に埋めていた（「俺がステージを台なしにした」など）。しおりは埋められなかった。**言ったのか、言わなかったのか、覚えていない**。どちらでも、答えは踏切の「じゃあな」だった、と思って、七年、同級生に会わずにきた。返すと「言わなかった」と分かる。分かっても、今も言わない
- **両側から見る**：とうやは、帰り道を全部覚えている（盗まれたのは、しおりの時間だから）。とうやの側も、言えなかった。二人とも、踏切の警報で言葉をのみこんだ
- **時間の切実さ**（2-16 の7）：とうやは鉄道会社の保線の仕事で、北の支社へ移る。30日目（日曜）の夕方の電車で町を出る
- **仲間の心に映す**：
  - ハルト：言えなかったことがあるかと聞かれて、「ある。言えないから、言えなかったことなんだろ」。言わないことを選ぶ人を、責めない側に立つ（29日目に選べる）
  - あかり：「言わなきゃ、終わっちゃうよ」と思わず口に出し、後で「終わるのが怖いのは、わたしの方だ」と気づく（7章の「終わるのが怖かったのは、楽しかったから」の前置き）。踏切で、写真を撮らない
  - みお：「好きって言えばいいだけじゃないですか！」と言う10歳。最後に「……言えないのも、ありなんですね」
  - 小夜子：「口に出さずに、願ったことがひとつ。……言わなくても、叶うことがあるのです。良いことか、悪いことかは、別として」（小夜子は、花火が一番大きく開いた時に「この夜が、ずっと続けばいいのに」と思い、そこで切り取られた。`docs/script/3-matsuri.md` の 2.。終章まで言わない）
  - りく：3-2 では出さない（夜ごとの謎は、ノア・時計屋・カイにする。下の 5.）
- **緩める話**（`docs/STORY.md` の 2-16「緩める話を挟む」）：3章は 3-1 と祭りの夜で、重い話と虚無が続いた。27日目の頭に、笑いだけの場面を2つ置く（カタカナ語しりとり、りくの回想「完璧な海水浴計画」）

## 2. 人物

**しおり**（今22歳。町の印刷会社の一年目。中学を出たのは平成31年3月、平成最後の卒業式。今の時代の人なのでひらがな。札は「シオリ」。名前は候補）

- 話し方：早口。言ってから、自分に突っこむ（「……って、何言ってんだろ、わたし」）。仕事の時は、ていねい語。照れると、なおさら早口になる
- 町に残った同級生は、自分だけ。だから、同窓会の連絡や、送る品の買い物は、いつも頼まれる。仕事で同窓会の案内状も刷る（自分は行かない）
- 覚えているのは、卒業式の後に校門を出た所と、夕暮れの踏切の「じゃあな」だけ。その間に、言うつもりだった言葉を、言ったのか、言わなかったのか、覚えていない
- 帰ってから、わけも分からず泣いた。それも覚えている。「どっちにしても、答えは『じゃあな』だった」と思って、成人式にも同窓会にも行かず、とうやに七年、会っていない
- 踏切の警報の音が鳴ると、なぜか息を止めてしまう（盗まれた時間の名残）
