## 0. この話で、遊ぶ人に残したい気持ち

- **38日目は緊張**：ずっと顔を合わせなかった店長に、こっそり使っていたことがばれる。でも店長は、止めに来たのではなかった。もっと前から、ひとりで「止まって見える時計」を数えていた
- **知らないほうが楽だ、と言う大人**：早瀬は、自分の砂時計（金色の砂）を見て「置いとけ」と言う。中身がいらないのではない。「思い出したら、もっと会いたくなる」から（2-9 の A）。妻のしずえさんは数年前に亡くなっている
- **4-1 からのバトン**：たいちの「知らないままよりは」が、早瀬の背中を押す。4-1 で知った「返すと写しが消える」を、今度は**持ち主本人が、自分の目で見る**
- **店を始めた日の誇りと、言いそびれた礼**（2-9 の A。ふみさんの「夫婦の思い出」と型を重ねない）：開店の日、客は一日にひとりだけ。看板を書き、通りで紙風船を配り、夜に「一個、売れたね」と泣き笑いしたのは、しずえさんだった。早瀬は「明日も、開ける」としか言わなかった
- **写しは何も知らずに、笑って消える**（2-9 の B）：写しのしずえさんは、くり返しに気づいていない。最後に話しかける年老いた早瀬を、夫だと分からない。「うちの人にも、そう言わせたいわ」と笑って、消える
- **早瀬が揺らぐ**（2-9・2-10）：「知らないままでいい時間もある、と思っていた。……間違っていたかもしれん」。ハルトに砂時計を渡さなかったことは、自覚の一言だけ（2-9 の D）
- **仲間の心に映す**：
  - ハルト：店長が、なぜ自分を雇ったのか、なぜ奥の部屋を見張るように片付けを任せたのか、少しだけ引っかかる（6章の前置き。答えは出さない）
  - あかり：伏せられた写真立てを見つける。撮らなかった写真のリスト（4-1 の絆）と並べて、「残す」ことをもう一度考える
  - みお：店長と野良猫の戦い（章をまたぐ持ちネタの1回目）で、笑いの係
  - 小夜子：写しのしずえさんが消える時、4-1 よりもはっきりと、自分と重ねる。でも口には出さない（終章の伏線）
