## 2. 人物

**けんた**（今37歳。商店街の楽器店の店主。話し方は今のまま：軽い口調）

- 高校3年の秋、バンド「ラストチャイム」（けんた・だいち・さき）で最後の文化祭のステージに立った。卒業後、三人で東京に出てプロを目指す約束をしていたが、けんたが一人で「やめる」と言って、二人とそれきり
- 店の奥の赤いギターに「売り物」の札。14日目に、買い手が決まって「売約済み」に変わる（土曜に引き取りに来る）
- 二十年、二人に連絡していない。「俺がステージを台なしにした。……たぶんな。覚えてないけど」。覚えていないのに、そう思いこんでいる（真ん中が抜けているので、悪い方に埋めた）
- 本当は、ステージの最後にマイクで「いつか、また鳴らします！」と言っていた（盗まれた時間の中）

**さき**（今37歳。ベース。看護師で、二児の母。新しく話す人。立ち絵が要る）

- 町の総合病院の看護師。13日目、病院の帰り道（バス停）で会う。みおが、さきの息子と同じ少年野球（顔見知り）
- 二十年前のことは怒っていない。「けんたが『やめる』って言った時、わたしもだいちも、少しほっとしたの。三人とも怖かったのよ、本当は」
- 「けんたは、自分のせいだと思ってるでしょ。……あのステージのあと、あいつ、マイクで何て言ったか、覚えてないの？」（さきは覚えている。言葉は言わない＝本人が思い出すまで）
- 「連絡しなかったのは、わたしも同じ。けんたから来るのを、待ってたのかもね。二十年も」

**だいち**（今37歳。ドラム。営業マン）：15日目に初めて会う（今のまま）。写しは声だけ

**写しのけんた・だいち・さき**（平成18年の秋、17歳。今の写しのまま。けんたは笑顔の絵がある）

**過去（平成18年の秋。けんたの高校の文化祭の一日）**
