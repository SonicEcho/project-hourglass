# 大正の祭りの夜と小夜子の脚本（段階90。たたき台）

**2026-10-22 たたき台**（開発者の確認待ち）。3章の骨組み（`docs/script/3-1.md` の 1.）の2つめ。3-1 を返した夜（24日目）から、小夜子が初めて今の街に来る日（26日目）まで。決まりは `docs/STORY.md` の 2-16（10の決まり）、小夜子の考え方は 2-7・2-10、伏線は 2-11、日常は 2-12、書き方は `docs/script/M1.md` の 0.。確認が済むまで、ゲームの台本は今のまま（24日目の夕暮れの少女の声まで）。

この話は「返す」話ではない。小夜子の夜は、まだ返さない（返すのは終章。`docs/STORY.md` の 2-9）。だから、持ち主に会う昼も、コマもない。代わりに、**同じ夜を2回見せる**。

## 0. この話で、遊ぶ人に残したい気持ち

- **ときめき → 虚無**（`docs/STORY.md` の 2-8 の3章）。1晩目は、提灯の灯りの中で、不思議な少女に手を引かれて祭りを回る（ときめき）。2晩目は、昨日とまったく同じ夜がもう一度始まり、屋台の人も、子どもも、同じ台詞を言う。覚えているのは小夜子だけ。百年、ひとりで、この夜をくり返してきた（虚無）
- **小夜子の答え**：「返すべきです。終わりがあるから、楽しい時間は楽しいのです」。自分が消える立場なのに、当たり前のように言う。その空しさを、まだハルトたちは分からない（4章で写しが消えると知ってから、意味が変わる）
- **旅の始まり**：「消える前に、この夜の外を見てみたい」。26日目、初めて今の街に出て、「また明日」を言う（百年ぶりに「明日」がある）
- **仲間の心に映す**：
  - ハルト：同じ夜をくり返す小夜子に、「今がずっと続けばいい」と流されてきた自分を重ねる（`docs/STORY.md` の 2-10）。言葉にはしない。最後に「明日も来る」と約束する
  - あかり：小夜子の「この夜は、前にもありました」に、自分のデジャヴ（プロローグから）を重ねる。「わたしも、ときどきある」。あかりと小夜子の連携技（`docs/CONCEPT.md`：あかりのデジャヴと、小夜子のくり返す祭りの夜が重なった時）の前置き
  - みお：同じ台詞をくり返す屋台の子に、手を振り続ける。「明日も、同じこと言うんですか」と、初めて写しのことを考える（7章の前置き。言葉は少なく）
  - りく：小夜子は、りくに会っている。りくが置いていった調査ノートの3章のページ（夜ごとの謎）

## 2. 人物

**小夜子**（写し。大正10年の夏、16歳。旧家の娘。浴衣に赤い鼻緒の下駄、月の形の簪。名前は決まっている。`docs/NAMING.md`）

- 話し方：ていねいで、少し古い言い回し（「まあ」「〜ですの？」「〜でございます」は使いすぎない）。好奇心のかたまりで、知らない物を見ると止まらない。カタカナ語を必ず言い間違える（「すまーとほん」）。アイスクリームは「あいすくりん」（大正の言い方）
- 大正10年の夏祭りの夜、厳しい家をこっそり抜け出して、一人で祭りに来た。初めての自由な夜。その夜が、楽しい時間として盗まれた
- 百年、同じ夜をくり返すうちに、デジャヴから自分がくり返していることに気づき、夜の端（切り取られた夜の縁）から、レストピアの棚の側へ出られるようになった（`docs/STORY.md` の 2-3）。でも、棚の外の奥へは行けない。誰もいない棚の間を歩いて、ほかの蔵書の音を聞いていた（3-1 の夜の下駄の音と赤い鼻緒）
- 祭りの夜のことは、屋台の位置も、くじの当たりも、花火の上がる時刻も、全部知っている
- 「返すべきです。終わりがあるから、楽しい時間は楽しいのです」。自分が消えることを、当たり前のように受け入れている（3章の虚無）
- りくに会っている。りくは、2晩目のさらに前、この夜を走り抜けていった（「あの方も、この夜を通っていかれました」）

**宮司さん**（今80歳くらい。町の神社の宮司。プロローグの夏祭りの神社と同じ。声と色の札。新しく話す人）

- 神社の古い写真と絵馬を守っている。りくが夏の前に、町の時計のことを聞きに来ていた（「熱心な子でしたな」）

**写しの人々**（大正10年の夏祭り。セピア）：金魚すくいではなく「金魚売り」・飴細工の職人・くじ引きの屋台の主人・風車を持った子ども・盆踊りの音頭取り（声だけ）

**過去（大正10年の夏。町の神社の夏祭り）**：プロローグ・1-1 と同じ神社の、百年前の夜。提灯の通り、飴細工、くじ引き、盆踊りのやぐら、最後に花火。小夜子は、花火が一番大きく開いた瞬間に「この夜が、ずっと続けばいいのに」と思った（そこで切り取られた。あかりの願いと同じ形。終章まで言わない）

## 3. 仕組み（作る段階で決める）

- **区画 `a3s`「大正の祭りの夜」**：部屋は4つ（鳥居と参道・屋台の通り・やぐらの広場・夜の端）。文字の地図で作り、絵は後で頼む。プロローグの参道の絵を、百年前の色に変えて使えるかも試す
- **コマのない区画**（2-3 の4晩目の書庫と同じ形。`docs/design/explore.md` の 2-6）：目当ての帯と、区画の奥の印。1晩目は「やぐらの広場の小夜子」（会話で終わる）、2晩目は「夜の端」（やぐらのぬしの後）
- **晩ごとに同じ地図**：2晩目は、1晩目の写しの台詞が、同じ順番で、まったく同じに出る（「くり返し」を、遊ぶ人に体で感じさせる）。小夜子の台詞だけが、昨日を覚えている
- **夜の巻き戻し**（演出）：1晩目の最後、花火の直前に、画面が白黒になり、砂が上へ逆に流れて、最初の鳥居に戻る（`@mono` と、逆に流れる砂の演出。新しく足す）
- **砂嵐**：大正の祭りの砂嵐4つ（名前は 6.）と、やぐらのぬし。1-1（平成の縁日）と物が重ならないよう、金魚・水風船・お面は使わない
- **戦闘の人数**：1. のおすすめ（3人のまま、並びを選ぶ）なら、チェックポイントに「並び」の窓を足す。作るのは段階91
- **小さく選ぶ所**（2-16）：25日目（宮司さんの絵馬）と、2晩目の最後（小夜子の「返すべきです」への返事）。選んだ方で、26日目の小夜子の一言が変わる

## 7. 確かめてほしいこと

1. **2晩の形**：1晩目は花火の直前に夜が巻き戻り、2晩目は昨日とまったく同じ夜（写しの台詞もまったく同じ）を小夜子だけが覚えている、でよいか

3. **戦闘の人数**：3人のまま、チェックポイントで並びを選ぶ（ハルトは外せない。物語で決まった人も外せない）でよいか。選ばなかった仲間の育ち方

5. **りくのページ**の中身（黒い砂時計の男を追った。「慣れるもんか」）
