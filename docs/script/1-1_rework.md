# 1-1「金魚の名前」の書き直し（段階63a。たたき台）

**2026-10-17 たたき台**（開発者の確認待ち）。開発者が2章の終わりまで遊んだ感想（1章で1時間、カイまで2時間で薄い。展開が早く、感情移入しにくい）から、1話を数日かけて味わう形に作り直す最初の1話。決まりは `docs/STORY.md` の 2-16「物語の濃さの決まり」、書き方は `docs/script/M1.md` の 0.（1行に1つの命令か台詞）。

手応えを確かめてから、1-2・2章へ広げる。確認が済むまで、ゲームの台本（`src/data/scriptM1.ts`）は今のまま。

## 0. この話で、遊ぶ人に残したい気持ち

- **ほのぼの → 胸がきゅっとする → じんわり**。1章の最初の話なので、重くしすぎない。でも「時間を盗まれる」ことの痛みは、ここで体で分かってもらう
- **時間を盗まれたせいで、今の兄妹がすれ違っていた**。返すと、二年分の距離が縮まる。返すことの意味（このゲームのくり返しの芯）を、最初の話で心に残す
- **ハルトとあかりの心に映す**：
  - ハルト：施設で年下の面倒を見ている「お兄ちゃん」。家族のいない自分が、兄と妹の話にどこまで踏みこんでいいのか分からない。最後に、自分の金魚と自分の居場所を少しだけ受け入れる
  - あかり：「終わること」が怖い。もう一匹の金魚が死んだこと、残った一匹も年老いていることに、強く反応する。「間に合わせたい」と自分から言う
  - りく：いないことで存在感を出す。1-1 の記憶の中を、りくが走り抜けていった跡を見つける

## 2. 人物

**ゆうま**（今21歳。商店街のコンビニでアルバイトの大学生）

- 隣の町の実家を出て、この町で一人暮らし。気だるそうだが、根は面倒見がいい
- 2年前、妹のひなのから夜中に電話があった。泣きながら「まつりが死んだ」と言われ、名前の意味を思い出せないまま「金魚くらいで泣くなよ。……名前、なんだっけ」と言ってしまった。ひなのは黙って電話を切り、それきり話していない
- 本当は、名前を付けた縁日の夜の真ん中が盗まれていた。覚えていないのは、ゆうまのせいではない（遊ぶ人とハルトたちだけが知っている）
- 昼に話すたびに、盗まれた時間のかけらを少しずつ思い出す（記憶の先が開く。下の 3.）

**ひなの**（今18歳。隣の町の高校3年。ゆうまの妹）

- はっきり物を言う、意地っ張り。でも、兄がくれた物はみんな取ってある
- 金魚の「なつ」を、11年ひとりで世話してきた。なつは年を取って、最近えさをあまり食べない
- 兄に「なつが弱ってる」と言いたくて、コンビニの前まで来ては、入れずに帰っている（2日目に、ハルトたちが見かける）
- 返された後、ハルトたちに「なんとなく、前にも会った気がする」と言う（返された時間には、写しの中で最後の一回に起きたことが入る。`docs/STORY.md` の 2-14）

**過去（平成の終わり。11年前の夏、隣の町の神社の縁日）**

- ゆうま10歳、ひなの7歳。ゆうまは友だちと花火を見る約束をしていたのに、母に「ひなのも連れて行って」と言われ、ふてくされていた
- 第1幕「しぶしぶの兄」：手を引かれて歩くひなのに、ゆうまは「お前なんか、来なきゃよかったのに」と言ってしまう
- 第2幕「迷子」：ひなのがいなくなる。ゆうまは自分の言葉を後悔しながら、縁日じゅうを探す。ひなのは金魚すくいの屋台で、一人でポイを握っていた。「おにいちゃん、金魚ほしいって言ってたから」
- 第3幕「ふたりで、なつまつり」：二人で金魚をすくう。名前を付ける（なつ・まつり）。「ふたりそろってないと、意味ない」「だから、ずっといっしょなの」。ゆうまは「来年も、連れてきてやるよ」と約束する（その約束は、中学に上がって守れなくなった。盗まれたのは、この約束をした夜の真ん中）

## 3. 仕組みで変えること（作る時の段階で決める）

脚本のために決めた形。作る時に `docs/design/explore.md` に書く。

- **記憶を3晩に分ける**：1-1 の区画を3つの部分（入口と広場／屋台の通り／社の前）に分ける。1晩に1つの部分を進み、その部分のコマを集めると、その夜は終わる（時計屋に戻る）
- **持ち主が少し思い出すと、記憶の先が開く**：部分の境目は、厚いノイズの壁でふさがっている。昼に持ち主と話して、盗まれた時間のかけらを持ち主が少し思い出すと、その夜、壁が薄れて先へ進める（昼の場面に意味を持たせ、夜を分ける理由にする）
- **写しの台詞が、コマで先へ進む**：今は何度話しても同じ台詞。コマを集めるたびに、写しの兄妹の場面が1つずつ先へ進む（過去の物語を、区画の中で見ていく）。くり返しの台詞は、まだ戻っていない所でだけ使う
- **夜ごとの小さな山場**：第2夜の終わりに番人（金魚すくいの屋台の前）。第3夜にぬし
- **コマの数**：今の8つ（返すのに要る数）を、3晩で 3・3・2 に分ける
- **選ぶ**：昼の場面に、ハルトのひと言を選ぶ所を2つ置く。台詞が少し変わるだけで、話は分かれない
