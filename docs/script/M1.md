## 0. 書き方の決まり

段階22で、台本のデータ（`src/data/`）にそのまま写せるように、1行に1つの命令か台詞を書く。

| 書き方 | 意味 |
| --- | --- |
| `あかり〔笑顔〕「……」` | 台詞。名前の札と、立ち絵の表情 |
| `あかり「……」` | 表情は前の行のまま |
| `〈語り〉……` | **名前の札のない語りの文**。文字の上を細かい砂が流れ、砂の落ちる音が付く（プロローグだけ。語り手はりく。6章で回収） |
| `〈地の文〉……` | ハルトの心の中の文。名前の札なし、砂の演出なし |
| `〔演出〕……` | 背景・BGM・効果音・暗転・1枚絵・画面の揺れなど |
| `（声）` | 立ち絵を出さない人の台詞（担任、施設の子ども、電話の相手など） |
| `▼選択肢` | 選択肢。`→ A` のように分かれ先を書き、`▲合流` で戻る |
| `◆` | 伏線のメモ（画面には出さない）。回収する章を書く |

- 1行の本文は、スマホの会話の枠に2〜3行で収まる長さ（全角40字くらいまで）にする
- キャラの話し方：ハルト（「俺」。口数が少ないツッコミ役。「……」が多い）、あかり（「わたし」。世話焼き、小言がお母さんっぽい）、りく（「俺」。口ぐせ「〜だろ」「なあ」。計画が好き）

### プロローグ「あの夏」

**P-1 黒い画面**

```
〔演出〕黒い画面。砂の落ちる音が、さらさらと続く
〈語り〉あの夏のことを、今でも覚えている。
〈語り〉夕方の神社。提灯に、ひとつずつ灯りが入っていくところ。
〈語り〉焼きそばのにおいと、遠くで鳴ってる太鼓と、アスファルトの熱。
〈語り〉俺たちは七歳で、世界は、あの参道くらいの広さしかなかった。
〈語り〉この夏だけは、誰にも渡さない。
〔演出〕明転。背景：夕暮れの神社の参道。BGM：プロローグの祭り
```

**P-2 参道の入口**

```
子りく〔得意げ〕「よし、そろったな！ 作戦会議だ！」
子あかり〔笑顔〕「りく、またノート持ってきたの？」
子りく「あたりまえだろ。今日は『夏祭り完全攻略計画』の本番なんだから」
〔演出〕効果音：ノートを広げる音
子りく「まず、りんご飴。次に射的。金魚すくいで三匹すくって、最後は——」
子あかり「最後は？」
子りく「ひみつ。最後のが、計画の目玉だからな」
〈語り〉最後の計画が何なのか、俺は知っていた。だから、あの夜が来るのが、楽しみで仕方なかった。
〔演出〕子ハルトが、少し離れた所に立っている
子あかり〔笑顔〕「ハルトも、はやくー！」
子ハルト〔通常〕「……うん」
〈語り〉三人で祭りに来たのは、あの年がはじめてだった。
〈語り〉誰かと歩く参道は、ひとりの時より、ずっと短く感じた。
子りく〔得意げ〕「ハルト、お前も計画に入ってるからな。三人用の計画なんだから」
子ハルト「……三人用？」
子りく「そうだよ。二人じゃさびしいし、四人だと多い。三人がちょうどいいんだろ」
子あかり〔笑顔〕「なにそれ」
```

**P-3 屋台めぐり（屋台をタップして回る）**

読むだけにならないように、プロローグの真ん中は、遊ぶ人が自分で屋台を選んで回る。参道の1枚絵に屋台の印を出し、タップした屋台の場面へ進む（段階24の日常と同じ仕組み）。画面の端に、子どものりくの字で書いた「計画表」を出し、回った屋台に丸が付く。4つ全部に丸が付くと、P-4 へ進む。

```
〔演出〕背景：参道（屋台の並び）。効果音：にぎわい。画面の端に「計画表」（りんご飴・射的・お面・金魚すくい）
子りく〔得意げ〕「順番は自由。……ほんとは自由じゃないけど、今日は特別だ」
子あかり〔笑顔〕「ねえ、どこから行く？」
〔演出〕屋台の印をタップして選ぶ（4つ）
```

金魚すくい（小さな遊び：タイミングでタップ）

```
〔演出〕背景：金魚すくいの屋台。効果音：水の音
屋台のおじさん（声）「はい、ポイ一枚ね。破れたらおしまいだよ」
子りく〔得意げ〕「三匹すくう。計画だからな」
〔演出〕効果音：水の音。ポイの破れる音
子りく〔あせり〕「……計画、修正」
〔演出〕子あかりが、黙って水面を見ている
子ハルト〔通常〕「……あかり？」
子あかり〔デジャヴ〕「なんかね。前にも、こうしたことある気がする」
子りく「去年も来たんだろ、親と」
子あかり〔笑顔〕「……そうかも。そうだよね」
〈語り〉金魚が、水面に近づく。その一瞬。
〈語り〉水の音も、提灯の灯りのゆれ方も、今でも覚えてる。
〔演出〕金魚すくいの遊び：金魚が泳ぎ回り、水面に近づくと、ほんの少し光る。光った瞬間にタップすると、すくえる。早すぎ・遅すぎは、ポイが少し破れる（3回でおしまい）
〔演出〕すくえた時。効果音：水がはねる音。成功の音
子あかり〔笑顔〕「とれたー！ ハルト、なんでわかったの？」
子ハルト〔笑顔〕「……いま、だと思った」
子りく〔あせり〕「またそれかよ」
〔演出〕すくえなかった時
屋台のおじさん（声）「残念。でも、一匹あげよう。大事にしなよ」
〔演出〕どちらの時も、続けて
子あかり〔笑顔〕「名前、つけなきゃ！」
▼選択肢（金魚の名前）
  ケイカク（りくの案） → 子りく〔得意げ〕「計画の金魚だからな」
  あかね（あかりの案） → 子あかり〔笑顔〕「夕焼けの色だから！」
  ゆうやけ（ハルトの案） → 子ハルト〔笑顔〕「……ゆうやけ。……色が、そうだから」
▲合流
```

◆ 「いま」：一番いい瞬間が分かる勘（6章で回収。アーカイバーの才能）。射的と金魚すくいの「光った瞬間」は、遊ぶ人自身のタップを、ハルトの勘として見せる（1-D のシャッターと同じ手触り）。
◆ あかりのデジャヴ（エピローグのあかりの道で回収）。袋や「だれかと」には触れない（もっともらしい別の説明「去年も親と来た」だけを置く）。
◆ 射的の景品と金魚の名前は、1-A で施設の台所に出てくる（遊ぶ人が選んだものが10年後に残っている、という小さなご褒美）。

**P-5 計画の目玉**

```
子りく〔得意げ〕「よし、時間だ。計画の目玉。ついてこい」
〔演出〕暗転 → 背景：神社の裏の高台（夜）。足音
子あかり〔心配〕「どこ行くの、りく。こっち、暗いよ……」
子りく「いいから。……ほら、ここ」
〔演出〕効果音：花火の上がる音。1枚絵：高台で花火を見る3人の後ろ姿
子あかり〔笑顔〕「わあ……！」
子りく〔得意げ〕「どうだ。『三人で花火を見る』。これが計画の目玉」
子あかり〔笑顔〕「りくの計画、はじめて成功したんじゃない？」
子りく「はじめてじゃない。……二回目くらいだろ」
〈語り〉花火の音が、胸の奥まで響いてた。
〈語り〉このまま夜が終わらなければいいのにって、たぶん三人とも思ってた。
〈語り〉でも、花火は終わる。何度思い出しても、同じところで終わる。
〔演出〕最後の花火が消える。静かになる
子あかり〔心配〕「……終わっちゃうね」
子りく〔通常〕「なあ、ふたりとも」
〔演出〕遠くで最後の太鼓が鳴り、声がかき消える
〈語り〉あの約束を、俺はまだ守れていない。
〈語り〉あの時の言葉を、今でも、一文字も間違えずに言える。
〈語り〉来年も、3人で来ような。
〔演出〕砂が画面いっぱいに流れ、暗転。砂の落ちる音が、少しだけ長く残る
```

◆ プロローグの語り手はりく（6章で、同じ語りの文に初めて「りく」の名前の札が付く）。**初めて遊ぶ人には、ハルトの語りだと思いこんでもらう**（`docs/STORY.md` の 2-11）。そのための決まり：
  - 語りの一人称は「俺」（ハルトもりくも「俺」）。1章のハルトの心の中の文（〈地の文〉）も「俺」で、同じ人の語りに見える
  - 語りは、誰か1人を外から見守る書き方（「あいつが笑ったのを見たのは」など）をしない。三人のこと、祭りの景色、気持ちだけを語る
  - 「あいつは、いつもひとりで空を見てた」（`docs/STORY.md` の 2-11 にあった伏線）は使わない。プロローグでハルトが空を見る場面があるので、「あいつ＝ハルト」と分かり、語り手がハルトでないことに気づかれるため
  - ハルトの勘（「いま」）は、語りではなく台詞で見せる
  - 最後の一文はりくの台詞だが、「あの時の言葉を」とだけ言い、誰が言ったかを語りでは言わない（ハルトがりくの言葉を覚えている、と読める）
  - 語りに、りくの口ぐせは混ぜすぎない（「〜だろ」はハルトも使う）
  - 1章の最初のハルトの心の中の文（1-A）で「夏が来るたびに、あの祭りを思い出す」と言わせ、語りとハルトを結びつけて思いこませる

**回収で意味が変わる語りの文**（初めて読む時はハルトの思い出に読め、6章で「りくの言葉だった」と分かると意味が変わる）

| 語りの文 | 初めて読む時 | 6章で分かること |
| --- | --- | --- |
| 「この夏だけは、誰にも渡さない。」（P-1） | 大事な思い出だ、という気持ち | ヴィクトの砂時計の中で、りくがこの夏だけは奪わせなかった。6章の「ずっと、ここにいた。3人の夏だけは、渡さなかった」に直接つながる |
| 「最後の計画が何なのか、俺は知っていた。」（P-2） | 大人になってから振り返った言い方 | 計画を立てたのはりく。知っていて当たり前だった（読み返すと分かる、公平な手がかり） |
| 「何度思い出しても、同じところで終わる。」（P-5） | 懐かしい思い出 | りくは砂時計の中で、この夏を本当に何度もくり返していた（3章の小夜子のくり返しとも重なる） |
| 「あの約束を、俺はまだ守れていない。」（P-5） | ハルトの後悔。りくがいなくなることの予感 | 約束をしたのはりく本人。8章とエピローグで、りくが自分で守りに行く（`docs/STORY.md` の 2-10） |

- 画面の手がかり：語りの文に流れる砂の色を、ヴィクトの鎖の砂時計の砂と同じ色（暗い金）にする。5章でヴィクトの砂時計を見た時に、気づく人だけが気づく
- 6章の回収の場面（たたき台）：りくの砂時計に入ると、プロローグと同じ語りの文が同じ演出で流れ、文と文の間に、プロローグにはなかった語りが挟まる（「……もう、何回目だろうな」）。最後に語りの枠に初めて「りく」の名前の札が付き、「ずっと、ここにいた。3人の夏だけは、渡さなかった」
◆ 「三人で花火を見る」は、りくの計画で成功した唯一のもの（6章の絆の出来事で回収）。
◆ あかりの「……終わっちゃうね」：終わることが怖い心の始まり（7章で回収）。
