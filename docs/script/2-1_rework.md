## 0. この話で、遊ぶ人に残したい気持ち

- **ほめられたい → ほめ方を知らない人の愛情 → 言葉が次の人へ渡る（泣き笑い）**。1章の2話（兄妹・夫婦）より一段広く、「言われた一言が、人の一生を支えて、次の人へ渡っていく」ことを感じてもらう。2章の題「背中を押す声」の最初の話
- **時間を盗まれたせいで、いさむは「自分は親方に一度もほめられなかった」と思いこんで暮らしてきた**。だから自分も、誰もほめずに来た（弟子を取らなかった。孫のみおも、ほめたことがない）。返すと、いさむは親方と同じやり方で、みおの背中を押す
- **仲間の心に映す**：
  - みお：町じゅうの「助っ人」をして、頼まれた数を数えて自慢する（「今日は六つ。新記録です！」）。本当にほめてほしい相手は、じいちゃんだけ。じいちゃんだけは、一度も「よくやった」と言ってくれない。明るい子の、小さな影を初めて見せる
  - ハルト：みおに「せんぱい」と呼ばれ、初めて「後ろの人の背中を押す側」に立つ。1-2 で「……助かってる」と言えたハルトが、もう一歩だけ進んで、最後にみおへ短く一言だけ言う

## 2. 人物

**いさむ**（今75歳。みおの祖父。歯車職人。話し方は今のまま：「わし」「〜とる」「〜せん」。口数が少ない）

- 五十年あまり、時計の修理の部品（小さな歯車）だけを削ってきた。今週で工場を閉める。機械は、11日目の朝に引き取り屋が持っていく
- 親方の源三に、一度もほめられたことがない、と思っている。「職人は、ほめられて育つもんじゃない」と自分に言い聞かせてきた
- だから自分も、誰もほめない。弟子を取らなかった。みおが何を手伝っても「そうか」しか言わない。みおに「歯車の削り方を教えて」と言われても「覚えんでいい。もう誰も要らん仕事だ」と断る
- 本当は、みおがかわいくて仕方がない。言い方が分からないだけ

**みお**（小学4年、10歳。話し方は今のまま。`docs/script/M2.md` の 8.）

- 8日目の夕暮れに加入する（今の 5-C と同じ。忘れた傘を取りに戻り、ハルトの袖をつかんで一緒に入る）
- 町じゅうの助っ人。頼まれごとを数えて自慢する。じいちゃんにだけは、ほめられたことがない。それを明るく笑って話す（「じいちゃんは『そうか』しか言わないんです。そうか星人です！」）。泣かない。泣くのは第3夜の終わり、じいちゃんの泣き笑いを見た時だけ

**すみ**（今77歳。源三の娘。工場の隣の銭湯「松の湯」の女将。新しく足す人。名前は候補）

- 昭和44年は22歳。銭湯の番台に座っていた（今の 2-1 の写しの「銭湯のおかみさん」を、すみの母から、すみに替える）
- あの夜、父の源三が珍しく酒を飲み、ぽつりと言ったのを覚えている。「あいつは、俺より上手くなる」。いさむには言っていない（「父が言わないことを、わたしが言うのは違うと思って」）。1-2 のしげるさんと同じ「もう一人の側」

**写しの源三**（親方。昭和44年に50代。話し方は今のまま：こわもて、江戸っ子ふう「〜ねえ」「うるせえ」）

- ほめる時に背中を向ける照れ屋（今のまま）。口では何も言わず、物で背中を押す人（湯たんぽ、置いていくルーペ、拾っておく欠けた歯車）

- 口が悪いが面倒見がいい。「親方が人をほめるもんか」と言いながら、いさむを一番気にしている

**過去（昭和44年の冬。翌年が大阪万博。いさむ18歳、見習い3年目）**

- 第1幕「今日はお前がやれ」：雪の朝。親方がいさむに、時計屋から頼まれた歯車を、初めて一人で削らせる。としおは「親方が人をほめるもんか」。いさむは手がかじかんで震える。銭湯のすみが、湯たんぽを持ってくる（「父さんが、あんたの手を冷やすなって」。親方は知らん顔）
- 第2幕「欠けた歯」：昼すぎ。一つ目を削り損ねる（歯が一枚欠ける）。日暮れが迫って焦ったいさむは、としおの削った歯車と、こっそり取り替えようとする（弱さ、ずるさ）。としおが止める。「親方は一目で分かる。……それにな、あの人が待ってんのは、お前の歯車だ」。いさむは、もう一度削り直す。親方は何も言わず、作業台に自分のルーペを置いて帰っていく
- 第3幕「いい仕事だ」：夜。削り直した歯車を見せる。長い沈黙。親方は背中を向けて「いい仕事だ」（今のまま）。**その後、遊ぶ人にだけ見える**：誰もいなくなった工場で、親方が屑箱から欠けた一つ目の歯車を拾い、胸のポケットにしまう

- **8日目の小さく選ぶ所**：選んだ方で、11日目のいさむの一言が変わる（「お前さんの言うとおりだった」／「あの時、黙って聞いてくれて、ありがとうな」）
- **2-2 から後**：中身は今のまま、12日目（2-2）・13日目（2-3）・14日目（2章の終わり）にずらした。12日目の夕暮れの蔵書の棚（「最後の文化祭」の札）を、11日目の調査ノートの場面から分けた
- **すみ・写しのすみ・写しのとしお**：立ち絵はまだない（色の札）

## 6. 今の脚本から、変える・消す・残す

- **残す**：みおの加入（傘・袖・アイス一本）、ジョーカーズと手描きのジョーカー、ムーブメントの開放、「歯車は一個じゃ回らねえ」、親方の「いい仕事だ」と耳まで赤い、いさむがみおに同じことをする、すき焼き、最後に削った歯車をハルトが預かる、みおの「楽しい時間は、ぜんぶ、持ち主に返しましょう」
- **変える**：2-1 を3晩に分けた（雪の朝・昼すぎ・夜の3幕）。写しの台詞を、くり返しから3幕の物語に。いさむの「今」に、ほめられた覚えがない・みおをほめない・道具を鉄の値段で手放す・機械の引き取りの日を足した。写しの「銭湯のおかみさん」を若いすみに、「先輩の職人」をとしおに替えた。「歯車は一個じゃ回らねえ」のチェックポイントを2晩目へ移した。返した翌日を、2章の2日目（6日目）から11日目へ移した
- **足す人**：すみ（今77歳。源三の娘。銭湯の女将。立ち絵が要る）、写しのすみ（22歳。立ち絵はすみの若い姿。セピア）、写しのとしお（立ち絵は、今の写しの職人の絵があればそれを使う）、引き取り屋（声だけ）
