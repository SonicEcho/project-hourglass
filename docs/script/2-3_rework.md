## 0. この話で、遊ぶ人に残したい気持ち

- **信じてもらえた一言 → 自分を信じられない親 → 同じ一言を、次の子へ（燃え → 泣き）**。2章の題「背中を押す声」の最後の話。2-1 の「いい仕事だ」（ほめる言葉）、2-2 の「いつか、また鳴らします」（約束の言葉）に続いて、「お前なら打てる」（信じる言葉）
- **時間を盗まれたせいで、こうじは「父の『お前なら打てる』は、外れた言葉だった」と思いこんで暮らしてきた**。打った覚えがないので、父は息子を励ますためにうそを言った、と。だから、補欠の息子そうたに、同じ言葉を言えない（「言って、打てなかったら、あいつは俺みたいになる」）。返すと、こうじはスタンドで、そうたに同じ言葉を叫ぶ
- **取られて、取り返す**：2章の山場。目の前で持ち去られる悔しさ（3晩目）と、自分たちの足で取り返しに行く燃え（4晩目）。カイは倒さない。逃げきって、正しい棚に戻す
- **仲間の心に映す**：
  - みお：そうたと同じ少年野球のチーム（4年、外野。そうたは6年、補欠）。毎日最後まで残って素振りをするそうたを知っている。「知ってほしい」と一番強く思う。取られた夜に初めて泣きそうになる（泣かない。泣くのは20日目、スタンドで）
  - ハルト：手を伸ばせば届くところで、取られる（りくの電話が切れた時と同じ）。4晩目の前、♥が一番多い仲間に「ハルトなら、できる」と背中を押される（2章の題を、ハルト自身が受け取る）
  - あかり：「信じる言葉」を言う側。ハルトが自分を責める時に、責めないで、信じる（4晩目の前）
  - りく：記憶の中のベンチに、りくの字の落書き（「ここ、通過。暑い」）。4晩目の書庫の扉に、りくが電話で言った「黒い砂時計をいくつも下げた」の印（ヴィクトの影の2つ目。1つ目はりくの電話）

## 2. 人物

**こうじ**（今40歳。商店街のパン屋の店主。二代目。話し方は今のまま：気さくで、少し照れ屋）

- 平成10年の夏、小学6年。少年野球の補欠。最後の試合の最終回、二点差・ツーアウト二塁で代打に出て、父の「お前なら打てる！」でヒットを打ち、一点を返した（次の打者が三振して、一点差で負け）。盗まれたので、覚えていない
- 覚えているのは、ベンチに座っていたことと、帰り道にラムネを飲んで泣いたこと。「負けたから泣いたんだろうな」
- 父の「お前なら打てる」は覚えている（盗まれた真ん中の前に、何度も言われていた）。打った覚えがないので、「親父は、息子を励ますために、当たらない言葉を言ってた」と思っている。だから、そうたには言えない
- 息子のそうた（6年、補欠）の試合を、一度も見に行っていない。「パン屋は朝が早い」「土曜は一番忙しい」。本当は、自分が打てなかった（と思っている）グラウンドに立つ息子を見るのが怖い

**まさる**（今70歳。こうじの父。パン屋の先代。引退して、商店街の裏に一人で住んでいる。話し方：声が大きい、おおらか、「〜だぞ」「わっはっは」。新しく話す人。立ち絵が要る）
