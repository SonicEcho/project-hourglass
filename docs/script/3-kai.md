- **本気のカイ**（`riversideEnemies.ts` の `KAI_REVENGE`。負け戦のカイとは別の id で、絵は同じ）：部位「枠の刃」（壊すとシャッターを封じ、弱点「雷」が見える。印は絵の左上の枠の角）、行動「露出」（攻撃の後、まだ誰にも割り当てていない手札を1枚、その戦闘から消す。`EnemyActionDef` の `erasesCard`。新しい仕組み）。勝てる戦い（打ち切りなし）。数値は自動対戦で測った（`docs/design/battle.md` の 13.）
- **花火**：案Aのとおり、戦闘の前後の会話だけで見せる。勝った後の会話の頭で、あかりの「ハルト、今！」と花火、カイの枠が焼ける
- **流れ**：31日目の朝の教室 → 昼 → 夕暮れの蔵書の棚（31-B）→ 祭りの夜（カイ）に入る会話（3k-1）→ 探索 → ノアとの口論（3k-6）→ ノアひとり（3k-7）→ 時計屋の奥（31-C）。32日目の朝の教室 → 昼 → 夕暮れの3章の終わり（32-B）→「つづく」。31日目と32日目の昼は、選べる話だけ（必ず見る出来事はない）
- **小さく選ぶ所**：31日目のカイの前の選択は `カイの前`（keep／self）に覚え、32日目の小夜子の日記の一行が変わる
- **雨**：32日目の雨の場面は、今の絵に灰色をかけて雨の粒を降らせる背景にした（`classroom_rain`・`clock_shop_rain`・`factory_rain`・`care_home_rain`。会話の背景の演出に `rain` を足した）
- **流れの終わり**（つづく）は32日目の後に移り、30日目の「つづく」にいたセーブは31日目から続く（`RENAMED_EVENTS`）
