# 素材の決まり（素材台帳の書き方）

RESTOPIA は買い切りで売るので、使う素材はすべて「売り物に使ってよいか」を確かめられる状態にしておく（`docs/ROADMAP.md` の「絵と音の素材の管理」）。

- **台帳の正は `src/data/assets.ts`**（プログラムが読む形）。タイトルの「クレジット」の画面と、テスト（`tests/assets.test.ts`）が同じ台帳を読む。この文書には決まりだけを書き、一覧は写さない
- 素材のファイルは `public/assets/` に置く（`ui/`、`chara/`、`bg/`、`se/`、`bgm/` など種類ごとのフォルダ）
- 素材の読み込みは `src/assets/loader.ts` だけで行う。画面は台帳の id で素材を使い、ファイルがない・読み込めない時は図形で代わりに描く

## 台帳に書くこと

| 項目 | 書くこと |
| --- | --- |
| `id` | 画面から使う名前（`title.hourglass` のように「場所.もの」）。ファイルを差し替えても変えない |
| `kind` | `image`（PNG など）／`svg`／`audio`／`font`／`library` |
| `title` | 表示名（クレジットの画面に出る） |
| `file` | `public/` からの場所（ライブラリはなし） |
| `status` | `placeholder`（仮。公開前に差し替える）か `final`（本番） |
| `source` | 入手元。自作／フリー素材（サイト名と URL）／AI（サービス名、使った版＝無料か有料のプラン名、プロンプト、設定）／ライブラリ（npm の名前と URL） |
| `author` | 作者（クレジットの画面に出る） |
| `license` | ライセンスの名前（自作なら「自作」） |
| `commercialUse` | 売り物（買い切りのアプリ）に使えるか |
| `creditRequired` と `credit` | 作者名などの表示が要るか。要るなら、その文 |
| `modifyAllowed` | 改変してよいか（色を変える、切り抜く、つなげる、なども改変） |
| `acquiredAt` | 手に入れた日（YYYY-MM-DD） |
| `termsCopy` | 手に入れた時の利用規約・ライセンス文の控えの場所（`docs/licenses/` など）。フリー素材とライブラリは必須 |
| `notes` | 気をつけること（使える範囲の条件など） |

テストが、書き漏れ（ファイルがない、クレジットの文がない、AI のプロンプトがない、規約の控えがない、本番なのに売り物に使えない、など）を見つけて、公開を止める。

## 素材を手に入れる時の決まり

**フリー素材**

- 「フリー」でも、売り物での利用、改変、クレジットの表示に条件があることが多い。素材ごとに利用規約を読み、台帳に書く
- 規約は変わることがあるので、手に入れた時の規約の文を `docs/licenses/` に保存し、`termsCopy` に場所を書く
- 「商用は別ライセンス」「アプリへの組み込みは不可」「素材の再配布は不可（アプリに同梱するのは可か）」に特に気をつける

**AI で作る素材**

- 使うサービスの利用規約で、作ったものを売り物に使えるかを確かめる（無料の版と有料の版で違うことがある）。使った版を `plan` に書く
- 特定の作家や作品の名前を指示に入れて、似せた絵を作らない
- 見た目をそろえるため、使った指示（プロンプト）と設定を台帳に残す
- ストアによっては、AI で作った素材を使っていることの申告を求められる。公開の前に、各ストアの最新の決まりを確かめる

**ライブラリ**

- 配布物に入るライブラリ（`package.json` の `dependencies` と、`?debug=1` で読み込む eruda）は台帳に載せる。テストが `package.json` と合っているかを確かめる
- ライブラリを足した・外した時は、台帳とライセンス文の控え（`docs/licenses/`）も合わせる

**フォント**

- 今は端末のフォントを使っていて、配布物にフォントは入っていない。フォントのファイルを同梱する時は、売り物のアプリへの埋め込みが許されているか（SIL Open Font License など）を確かめて台帳に載せる

## 公開前の確認

- 台帳に `placeholder`（仮）が残っていないか（`?debug=1` のクレジットの画面に「仮／本番」が出る）
- `final` の素材はすべて `commercialUse` が true か（テストが確かめる）
- クレジットの画面に、表示が必要なものがすべて出ているか
- AI の素材を使っていることの申告が、出すストアで必要か
- 心配な素材は差し替える（読み込みは1か所なので、ファイルと台帳を変えるだけ）
