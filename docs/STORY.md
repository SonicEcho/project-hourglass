## 2. 世界の土台：砂時計（決まった）

```
  上の玉   未来：まだ落ちていない砂（残りの時間）   … ノアの時代
   くびれ  現在：今、落ちている一粒                 … ハルトたちの時代
  下の玉   過去：落ちて積もった砂（生きてきた時間） … 桜子の時代
```

- 時間は流れていく。でも砂時計のように、**量に限りがある**
- 同じ砂が、未来 → 現在 → 過去へと流れていく。3つの時代は別々の世界ではなく、1本の流れの上・真ん中・下
- 未来の人たちは、残り少ない時間の中で、時間を止めようとしている

## 2-1. 物語の骨組み（決まった）

**時間泥棒を追う物語**（たたき台の「骨組み2」に「骨組み1」の要素を少し足す）

- 街の時間が、どこかで少しずつ盗まれている。時代ごとに、時間が抜き取られた跡が残っている。ハルトたちは、時代をまたいで「誰が、何のために時間を盗んでいるのか」を追う
- 盗んでいたのは、残り時間の少ない未来の人たち。そして、ハルト自身も盗まれた時間と関わっている（中身はこれから決める）
- **「楽しい時間はあっという間に過ぎる」のは、その楽しい時間が盗まれているから**（開発者の発想）
- 骨組み1の要素：未来の人たちは、盗んだ時間で「一番幸せな瞬間」を集め、そこで時間を止めようとしている（思い出だけの理想郷）

大事にしたい感覚：時代の空気を味わう、見たことのない景色、謎を解く感触

## 2-2. レストピアと時間泥棒の仕組み（決まった。開発者の案）

- **レストピア**：未来の人たちが、限られた残り時間の中で、いろいろな時代から盗んできた楽しい時間を体験し、永遠のように楽しい瞬間を過ごそうとしている場所
- **盗み方**：盗まれる時間は、動画のキャプチャーのように切り取られる。その場の景色も、そこにいた人々も、まるごと持っていかれる
- **元の時間では**：切り取られただけなので、時間そのものは続く。ただ、**切り取られた間の記憶がなくなる**。だから、楽しい時間は「あっという間」に感じる（始まりと終わりしか覚えていない）
- **ハルトの正体**：レストピアの側で、過去の楽しい時間を盗むエージェント。ある時、盗むはずが、何かの拍子で現代の時間に迷い込んでしまった

## 2-3. キャラと仕組みの細部（決まった）

- **盗まれた時間の中の人々は「写し」**：元の時間の本人は、記憶の一部をなくしただけで、そのまま暮らし続ける。レストピアにいるのは、切り取られた瞬間の人々の写し
- **桜子は写し**：大正の祭りの夜から盗まれた時間の中にいる写し。100年間、同じ祭りの夜をくり返すうちに、自分がくり返していることに気づき、**盗まれた時間の外（レストピアの側）へ出られるようになった**。本物の桜子は、とっくに大正で一生を終えている
- **ハルトは子どものころに迷い込んだ**：子どものエージェントとして、現代の楽しい時間を盗みに来た時に、現代に取り残された。そこから現代で育ったので、**あかり・りくと過ごした時間は本物**
- **迷い込んだ「何かの拍子」**：盗もうとしたその場で、誰かが強く「この時間を終わらせたくない」と願った。その力に引っぱられて切り取りに失敗し、ハルトだけが現代に取り残された。**願ったのが誰かは、物語の謎の一つ**
- **「直す」＝盗まれた時間を取り戻して、元の時間に返すこと**：返された人は、なくしていた楽しい記憶を取り戻す。その代わり、その時間の中にいた写しは消える（桜子のいる祭りの夜を返せば、写しの桜子は消える）。誰かの記憶を取り戻すことと、写しの命が天秤にかかる

## 4. やめた案（くり返さないためのメモ）

- 裏側の街＝未来が作ったバックアップ、記録の層（現実離れしていて、分かりにくい）
- 秒のすきま・縫い目・糸（言葉がしっくりこない）
- 砂粒の中・くびれの中に入る（別の空間に入る発想がしっくりこない）
- 直すと未来の砂が減る、という代償
- 記録局が砂時計を横に倒して止める、という計画
- 桜子＝砂時計を返した巫女、ハルト＝未来の砂で作られた人、という結びつけ
- 人々の記憶の「切り取られた穴」をハルトとの思い出が埋めている、という案（ハルトと過ごした時間は本物にする）
