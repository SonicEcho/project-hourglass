# 物語の練り直し（たたき台 第2版）

2026-10-06 時点のたたき台。`docs/CONCEPT.md`（構想ノート）の世界観を、1から考え直した案。開発者が確認するまで、構想ノートは書き換えない。

第1版の「裏側の街＝未来が作ったバックアップ」「記録の層」の案はやめた（現実離れしていて、分かりにくかったため）。新しい案は、**誰もが経験したことのある「時計の秒針が止まって見える」現象**を軸にする。

## 1. 決まったこと

| 項目 | 決まったこと |
| --- | --- |
| タイトル | RESTOPIA（レストピア）。副題なし |
| キャッチコピー | 思い出だけの理想郷 |
| キャラ名 | ハルト（固定）・あかり・みお・早瀬・りく・桜子・ノア |
| 世界の軸 | 時計の秒針が止まって見える瞬間（止まった1秒）の中に、もう一つの街がある。その中は、すべての時代でつながっている |
| ハルトの正体 | 未来の記録局が、現在に送り込んだ人（A案）。本人は知らない |

## 2. 世界のルール（7つ）

1. **時間は「瞬間」を縫い合わせて流れている**。人が覚えている瞬間が、時間を縫い合わせる糸になっている
2. **時計の秒針が止まって見えるのは、縫い目に触れた時**。ふつうの人は、すぐに弾き返されて「気のせい」で終わる
3. **縫い目の向こうに「秒のすきま」がある**。そこでは時間が進まない。中で何時間過ごしても、外では1秒もたたない
4. **秒のすきまには「今」がない**。どの時代の縫い目から入っても、同じすきまに着く。だから、大正・現在・未来の人が出会える。戻る時は、それぞれ自分の時代の、入った1秒に戻る
5. **誰にも覚えられなくなった瞬間は、糸がほどけて、すきまへ落ちる**。落ちた瞬間の中にあったもの（閉店した店、忘れられた人、消えた思い出）も、一緒に現実から消えて、すきまへ行く
6. **すきまに落ちた瞬間は、縫い戻せる**。縫い戻すと、現実に戻ってくる（最初からそうだった形で）
7. **糸の量には限りがある**。どこかを縫い戻すと、そのぶん別の所の糸がゆるみ、誰かの瞬間がほどけて落ちる

**呼び方**

- 秒のすきま：ハルトたちの呼び方。大正の人々は「神隠しの間」と呼んでいた
- **レストピア**：未来の記録局が、秒のすきまの中に作ろうとしている「理想の街」と、その計画の名前（下の「4.」）

## 3. 秒のすきまの中はどんな場所か

- **入った瞬間の街が、止まったまま広がっている**：宙に浮いた雨粒、羽ばたいたまま止まった鳩、歩きかけた人々。音がなく、自分の足音と心臓の音だけが聞こえる
- **ほかの時代の瞬間が、つぎはぎで混ざっている**：すきまに落ちた瞬間が、パッチワークのように街に貼りついている。現代のコンビニの隣に、大正の祭りの提灯が止まったまま浮いている。奥へ進むほど古い瞬間や、未来の瞬間が増える
- **色**：大切に覚えられていた瞬間ほど色鮮やか。ほどけかけた瞬間は、色が抜けて輪郭だけになっている
- **歪み（モンスター）**：誰にも覚えられずに長くすきまにある瞬間が、ゆがんで形を持ったもの。止まった鳩と時計が混ざった獣など。ボスの「歪みの獣」もこれ
- **長くいすぎると危ない**：すきまにいる間は、自分の瞬間も少しずつほどける。長くいるほど、自分のことを忘れていく（1回の潜入に限りがある理由）

## 4. 何が起きているのか（物語の芯）

**未来の困りごと**

ノアの時代（数十年後）の街では、縫い目がほつれ続けている。時計は一日に何度も止まり、人や店が、ある日ふっと消える。人々は互いの名前を覚えていられない。覚えられなかった瞬間がすきまへ落ち、糸がさらに減る、という悪い流れが止まらない。

**記録局の答え：レストピア計画**

- 「時間が流れるから、失われる。それなら、時間の流れない場所で暮らせばいい」
- 秒のすきまの中に、街の一番良かった瞬間だけを集めて、終わらない一瞬の街＝**レストピア**を作る。そこへ街の人々を移す。誰も年をとらず、誰も忘れず、何も失われない。**思い出だけの理想郷**
- 悪意はない。名前を呼び合えなくなった人々を、本気で救いたいと思っている。率いるのはノアの母（記録局長）

**なぜ現在が必要か**

- 未来の瞬間は、もうほとんどほどけていて、理想の街を作れるほど色鮮やかな瞬間が残っていない
- 現在（ハルトたちの時代）には、まだ色鮮やかな瞬間がたくさんある。特に、街の記念祭
- 現在の瞬間を縫ったりほどいたりできるのは、現在に糸を持つ人だけ。だから記録局は、現在にハルトを送り込んだ

**ハルトの「修復」の正体**

- ハルトたちは、すきまに落ちた店や人を縫い戻して、現実に取り戻す（序盤の喜び）
- でも、縫い戻すたびに、ルール7で別の所の糸がゆるみ、誰かの瞬間がほどけてすきまへ落ちる。落ちた瞬間は、記録局がレストピアの材料として集めている
- つまり、**ハルトが直すほど、レストピアが育っていく**。記録局はそれを分かっていて、ハルトを送り込んだ

## 5. キャラクターと世界のつながり

| キャラ | すきまとの関わり |
| --- | --- |
| **ハルト** | 記録局が、たくさんの人の糸を使って現在に縫いこんだ人。子どものころの思い出（あかり・りくとの日々）も縫いこまれたもの。すきまに自由に出入りでき、縫い戻すのが一番うまい。**ハルトだけ、時計が止まって見えたことがない**（自分の糸がこの時代にないので、縫い目に「触れる」感覚がない） |
| **あかり** | 和菓子屋の娘。店の初代は100年前、神隠しの間へ消えた巫女（桜子）のために、毎年祭りの菓子を供えていた。すきまで桜子と出会う。記録局の「良かった瞬間だけの街」に心が揺れる |
| **みお** | 友達を亡くした日の記憶を消したくて、一人ですきまに通い、その瞬間をすきまへ落とそうとしていた。すきまの奥で、止まったままの「あの日の友達」の瞬間に出会ってしまう |
| **早瀬** | 市の情報システム課。市の時報や時計のネットワークの記録から、時計が止まる場所と時刻のかたよりに気づいた。10年前、「つらい瞬間をすきまへ落として忘れさせる」仕組みを市のサービスに組みこんでしまい、それがほつれを早めていた。みおの家族もそのサービスを使っていた |
| **りく** | 記念祭の夜、すきまに落ちて出られなくなった（現実では「消えた」）。すきまでノアと出会い、ハルトの正体と、修復の代償を知る。「縫い目を全部閉じて、すきまをなくすべきだ」と考える。でもそうすると、すきまで生きている桜子は消える |
| **桜子** | 大正のころ、祭りの夜にすきまへ渡る役目を担っていた巫女。ある年、すきまから戻れなくなり、「神隠し」として伝えられた。すきまでは時間が進まないので、100年たった今も少女のまま。自分が消えた時代と、そこから続く街を守りたい |
| **ノア** | 記録局長の娘。未来の縫い目から、すきまに入れる。母の計画を止めるために、現在へ（すきまを通して）呼びかけていた。記念祭の夜の異変は、その呼びかけで起きた |

## 6. 物語の流れ

| 段階 | 内容 |
| --- | --- |
| 序盤：直すことの喜び | 記念祭の夜、時計台の秒針が止まり、りくが消える。ハルトたちは秒のすきまへ。すきまに落ちていた閉店した店を縫い戻すと、次の朝、店が現実に戻っている |
| 伏線：小さな違和感 | 縫い戻すたびに、街のどこかで「誰かの名前が出てこない」「部屋に入って何をしに来たか忘れる」が増える。時計の止まる回数が増える。ハルトだけ、時計が止まる話に共感できない |
| 中盤：りくとの再会と転換 | すきまの奥でりくと再会。りくは、縫い戻すたびに誰かの瞬間が落ちていること、それがレストピアの材料になっていることを知っていた。喜びが罪悪感に反転する |
| 後半：選ぶ物語へ | 何を縫い戻し、何を縫い戻さないかを選ぶ。記録局は「良い瞬間を守る協力者」として誘ってくる。後半の終わりに、ハルトの正体が明かされる |
| 終盤と分岐 | レストピアを完成させるか、縫い目を閉じるか、別の道を探すか |

## 7. 結末

| 結末 | 内容 |
| --- | --- |
| レストピアの完成 | 街の人々は、終わらない一番良い瞬間の中で、永遠に暮らす。誰も悲しまないが、明日は来ない。ハルトの縫いこまれた思い出も、そこでは本物として続く |
| 縫い目を閉じる（りくの道） | すきまはなくなり、もう何も縫い戻せないし、何も落ちない。時間は流れ続けるが、すきまに残った桜子は消え、すきまに支えられていたハルトもほどけていく |
| 真のエンディング（周回） | 人と人が同じ瞬間を一緒に覚えていると、その瞬間は太い糸になって、ほどけにくくなる。ハルトたちが絆を深めた人々の瞬間が、ほつれた時間を縫い合わせる。ハルトも、一緒に過ごした人たちに覚えられていることで、この時代に残れる。作られた始まりでも、一緒に過ごした「今」は本物だった |

## 8. 遊びの仕組みとのつながり

- **日常と潜入が自然に分かれる**：すきまの中の冒険は、外では1秒。だから日常パートの合間に、いつでも潜入できる。長くいすぎると自分を忘れていくので、1回の潜入に限りがある
- **ターン制の戦闘と相性が良い**：すきまの中は時間が止まっている。「考えている間は時間が止まる」戦闘が、そのまま世界の設定になる
- **素材**：歪みを倒すと「時のかけら」（ほどけた瞬間のかけら）が手に入る。今の「記憶の断片」を言い換えられる
- **ナビカス盤の名前の案**：各キャラの道具を懐中時計にして、盤を時計の中の機械（歯車の並び）にする。パーツは歯車、コマンドラインは歯車の通り道。名前の候補：歯車盤、ムーブメント
- **修復と代償**：縫い戻すと、別の所がほどける（糸の量に限りがある）。今の「修復と代償のルール」をそのまま置き換えられる
- **人とのつながりで支える**：日常パートで関係を深めた人の瞬間は、太い糸なのでほどけにくい（代償が軽い）
- **違和感ノート**：日常の中で、時計が止まる、デジャヴを感じる、名前が出てこない、などの現象に出会うと記録される。集めるほど真相に近づく

## 9. よくある現象と、物語での理由

| 現象 | 物語での理由 |
| --- | --- |
| 時計の秒針が止まって見える | 縫い目に触れた瞬間 |
| デジャヴ | 縫い戻された瞬間を、前にも一度過ごしていた |
| 名前が喉まで出かかって出てこない | その人と一緒にいた瞬間が、すきまに落ちた |
| 部屋に入って何をしに来たか忘れる | その用事の瞬間がほどけた |
| 何でもない日常の夢 | すきまに落ちた自分の瞬間を、眠っている間に見ている |
| 神隠し（昔話） | 大正の人々が、すきまに落ちた人をそう呼んだ |

全部を説明しすぎない。いくつかは、説明しないまま余韻として残す。

## 10. 似ている作品と、違いの出し方

- **『ペルソナ3』の「影時間」**（1日と1日の間に隠された時間に、限られた人だけが入り、怪物と戦う）にかなり近い。違いとして、①入口が誰もが経験する「止まって見える秒針」であること、②すきまの中で時代を越えて出会えること、③戦うだけでなく、落ちた瞬間を「縫い戻す」ことが遊びの中心であること、をはっきり見せる
- **『モモ』**（時間を盗む灰色の男たち）にも、時間を集める組織という点で少し近い
- 時間が止まる表現そのものはよくあるので、「縫い目」「糸」「つぎはぎの瞬間」という見た目と言葉を、この作品だけの看板にする
