# 物語の練り直し（たたき台）

2026-10-06 時点のたたき台。`docs/CONCEPT.md`（構想ノート）の物語に、主人公ハルトの正体（A案：記録局が過去に送り込んだ人）を組み込む案。開発者が確認するまで、構想ノートは書き換えない。名前は `docs/NAMING.md` の第一候補（ハルト・あかり・みお・早瀬・りく・桜子・ノア）で書く。

## 1. 決まったこと

- 主人公の名前は**ハルトに固定**（プレイヤーは名前を変えられない）
- 名前の文字の決まり：過去＝漢字（桜子）、現在＝ひらがな（あかり・みお・りく）、未来＝カタカナ（ノア）。**ハルトだけ、現在の人なのにカタカナ**。これが最初の手がかりになる
- 主人公の正体は**A案**：未来の記録局が、過去（現在）に送り込んだ人。本人は知らない

## 2. ハルトの正体（A案）の中身

**記録局が送り込んだ「修復の手」**

- 記録局は、良かった過去で今と未来を上書きする計画（レストピア計画）を進めている。上書きには、裏側の街の記録を、現在の側から一つずつ直していく人が要る
- そのために、未来で作った人を、作った思い出と一緒に現在へ置いた。それがハルト
- ハルトが裏側の街で記録を直せるのは、そのために作られたから（ほかの人より簡単に入れる、修復の力が強い）
- 本人は、自分を現在のふつうの高校生だと思っている

**作られた思い出と、その代償**

- ハルトの子どものころの思い出（あかり・りくとの幼なじみの日々）は、記録局が書き足したもの。あかりとりくの記憶にも、ハルトとの思い出が書き足されている
- 書き足した分だけ、街のどこかの記憶が引き抜かれている（修復と代償のルールと同じ仕組み）。ハルトが「いる」こと自体が、最初の代償だった

**なぜ「ハルト」か**

- 記録局の時代の名前の付け方（カタカナの短い名前）で付けられた。現在の名簿にも、そのままカタカナで載っている

## 3. 物語の流れへの組み込み（構想ノートの5つの段階に合わせて）

| 段階 | 今の構想 | 練り直し案 |
| --- | --- | --- |
| 序盤：直すことの喜び | 記念祭の夜、ノアの信号で市の端末が暴走し、りくが消える。ハルトたちは裏側の街へ | そのまま。ハルトが一番うまく直せることを、遊びの中で自然に見せる（「なぜか自分だけ入れる」「直すのが早い」） |
| 伏線：小さな違和感 | 修復のたびに、誰かが家族の名前を思い出せない、などの異変 | 異変に加えて、ハルトのまわりの違和感を重ねる（下の「4. 手がかり」） |
| 中盤：りくとの再会と転換 | りくは未来の層でノアと出会い、修復が記録局の復元テストで、直すたびに誰かの記憶が削られると知っていた | りくは、それに加えて**ハルトが記録局の送り込んだ人だと知っている**。でも、まだハルトには言えない。りくの「バックアップごと壊すべき」という考えには、「作られた友達を、それでも友達だと思いたい」揺れも混ざる |
| 後半：選ぶ物語へ | 代償を見て直す対象を選ぶ。記録局が「協力者」として勧誘してくる | 後半の終わり（終盤の入口）で、**ハルトの正体が明かされる**。記録局の勧誘は「あなたは最初からこちら側の人間だ」という形になる |
| 終盤と分岐 | 何を直したか、誰との絆を深めたかで結末が変わる | 結末の選択に、ハルト自身の存在がかかる（下の「5. 結末への影響」） |

- 構想ノートの「終盤、未来の層で大人の自分と出会う」は、なくす。代わりに、未来の層で「ハルトの記録（作られた時の資料）」と、作った側の記録局長に出会う

## 4. 手がかり（カタカナの名前に重ねる、小さな違和感）

- 子どものころの写真が、どこにも1枚もない（家族のアルバムには、ハルトがいるはずの場所だけ空いている）
- あかりとりくが覚えている「子どものころの出来事」が、少しずつ食い違っている
- 学校の名簿や市の記録で、ハルトの登録の日付だけが新しい
- ハルトだけ、潜入用のデバイスがなくても裏側の街に入れる
- ノアの信号が、なぜかハルトにだけはっきり届いた
- 記録局の敵が、ハルトにだけ攻撃をためらう

どれも物語の中では直接指摘しない。気づくかはプレイヤー次第（構想ノートの「伏線：小さな違和感」と同じ方針）。

## 5. 結末への影響

正体が明かされた後のハルトの選択が、結末を大きく分ける。

- **上書きを完成させる**：ハルトの作られた過去は「本当の歴史」になる。あかりとりくとの思い出も本物になる。ただし、今と未来は上書きされる
- **上書きを止める**：今と未来は守られる。でも、ハルトの過去は作り物のままで、記録局の支えがなくなったハルトは、だんだん消えていく
- **真のエンディング（周回）**：「人とのつながりで支える」（修復と代償のルールにある、現実で関係を深めた人の記憶は代償が軽い・発生しない仕組み）で、ハルトを覚えている人たちの記憶が、ハルトをこの時代につなぎ止める。作られた始まりでも、一緒に過ごした「今」は本物だった、という答え

構想ノートの結末の答え「過去を忘れず、今を生き、未来につなぐ」が、ハルト自身の物語にも重なる。

## 6. 気をつける点

- **構想ノートの方針との関係**：構想ノートには「発端を主人公の過去設定ではなく、プレイヤー自身の行動に置くことで、物語を自分事に保つ」とある。A案は主人公の過去設定を足すが、物語の発端は変えない（ノアの信号、りくが消える、自分で直す）。正体が明かされた時、それまでプレイヤーがしてきた修復が「作られた目的どおりの行動だった」と分かり、そこから自分で選び直す形にして、自分事のまま保つ
- **どんでん返しを重ねすぎない**：中盤の転換（修復＝上書き）と、ハルトの正体の判明は、時期を分ける（中盤と、後半の終わり）
- **あかりのルートとの関係**：あかりの「良かった過去でやり直したい」気持ちと、作られた幼なじみの思い出が重なる。あかりが記録局側につく理由に、「上書きを完成させれば、ハルトとの思い出が本物になる」を足せる

## 7. 開発者に決めてほしいこと

1. ハルトは、自分の正体に**いつ気づく**か（後半の終わりで明かす案。もっと早く／遅くもできる）
2. ハルトの作られた思い出は、**あかりとりくの両方**に書き足されているか（片方だけにする案もある）
3. 「大人の自分と出会う」場面をなくしてよいか
4. 上書きを止めた時、ハルトは**消える**か（真のエンディング以外で、消える結末を作るか）
5. ハルトを送り込んだのは、記録局長（ノアの母）本人か、記録局のほかの誰かか
