# 人物の一覧

名前を思い出すための早見表。顔は立ち絵の最初の表情から切り出した（絵のない人は「絵なし」）。
くわしい設定は各章の脚本（`docs/script/`）の「人物」と、`docs/STORY.md`。この一覧と顔の絵は Claude が作り直せる（新しい人や絵が増えたら頼む）。

「写しの〇〇」は、持ち主の記憶の中にいる、その時代の姿（今の人とは別の札で話す）。
