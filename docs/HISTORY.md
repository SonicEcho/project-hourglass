## 以前に挙がった候補（2026-10-09 までの記録）

- **物語と名前**：タイトルは RESTOPIA、物語は「盗まれた楽しい時間を取り戻して返す」話に決まり、`docs/CONCEPT.md` に反映済み。細かい決まりとやめた案は `docs/STORY.md`、名前と用語は `docs/NAMING.md`。2026-10-07 に開発者と物語を深く話し合い、`docs/STORY.md` の 2-8〜2-12 に決めた（本編35〜45時間、物語の背骨、章立てと各章で返す時間、仲間の心の変化、伏線と回収・どんでん返し、日常と絆の出来事・小話・一人ひとりのくせ）。段階10で、画面とデータの用語（星図、星の砂、ムーブメント、ギア、ブリッジ、狂い、スナップ、アルバム、延長、記憶の欠片、時分解）とキャラ名（ハルト）を置き換え、記憶の欠片を感情の種類（勇気・高揚・安堵・驚嘆）に作り直した。敵・ボス・技・スナップ・アイテム・武器・ギアの固有の名前は、まだ古いまま（`docs/SPEC.md` の段階10の記録）
- **本格開発へ**：マイルストーン（M0 土台 → M1 垂直スライス（プロローグと1章の最初）→ M2 1〜2章 → M3 3〜5章 → M4 6〜7章 → M5 8章〜エピローグ → M6 磨き込みと公開）が `docs/ROADMAP.md` にある（2026-10-07 に決まった物語に合わせて書き直し、開発者と確認して決定）。M0 は段階11（セーブと中断・再開）、段階12（自動対戦の測定）、段階13（章・日・区画を持てる周回）まで進めた。段階14で設計書を分け、段階15で素材台帳を作り、段階16の試作でエンジンは Phaser 3 を続けると決めた。段階17でデータの一覧表を作った。絵の方向性は、すべてイラスト（AI の無料枠を使い倒す）、探索は見下ろしの1枚絵＋見えないマス目に決めた（`docs/ART.md`）。段階18a（会話の試作にあかりとハルトの立ち絵、PR #24〜#26）・18b（縁日の見下ろしの絵の地図、PR #27）で確かめ済み。立ち絵の背景は `scripts/cutout.py`（rembg の isnet-anime）で抜く。音は BGM を Suno で自作（本番の曲は M1 の頃に有料の版で作る）、効果音は効果音ラボと決め、段階19で音の仕組みを作った（PR #28）。M0 の残りは磨きの段階。ボスの勝率（42%）は今は調整せず M1 の新しいボスで測る、固有の名前は M1 と一緒に決める、と開発者と決めた（2026-10-07）。用語は、敵・技などの固有の名前が未定（決まったら置き換える）

試作の続きとして挙がっていたもの：

- 遊んだ感想をもとにした成長マップの調整（マスの配置、ポイントの量、覚える技、ボスの強さ）
- 遊んだ感想をもとにしたナビカス盤の調整（パーツを縦に置くとコマンドラインを1マスしか使わないので、取り合いが弱いかもしれない）
- 遊んだ感想をもとにした武器の調整（素材・断片の量、進化先の効果、経験値）。通常アイテムを戦闘で使えるようにする案（使うか断片化するかの取捨選択）は見送り中
- 育成の別の仕組み：カード昇格。武器の続き（2回目の進化、持ち替え、武器から技を覚える）
- 戦闘の幅を広げる：敵やボスの種類、コンボ・連携技の追加、総攻撃や3人技
- 磨き込み：見た目、初めての人向けの説明
- 後回しにした絵の作業：縁日の地図を ChatGPT で作り直す（看板に文字を入れない）、あかりのリボンの色
- 公開前に、参考作品の名前をそのまま使っている用語を独自の名前に変える（ナビカス盤、スフィア盤、CTB など）。開発者が公開前に考える。仕組みは著作権の心配は少ないが、見た目も元作品に寄せすぎないようにする
