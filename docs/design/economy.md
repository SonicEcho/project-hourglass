## 2. 考え方

1. **1つの入手物に、1つの役目**。星の砂は星図、経験値は武器のレベル、素材は武器の中身と進化、ギアはムーブメント、スナップはアルバム、記憶の欠片は交換所（と武器に少し）、消費アイテムは探索の中の回復
2. **主な入手先を1つに決める**（ほかの所でも少しは手に入る）

   | 入手物 | 主な入手先 | ほかの所 |
   | --- | --- | --- |
   | 星の砂 | 物語の戦闘とぬし | 狩り（前の章の区画は半分）、落とし物 |
   | 素材 | 敵（物語の1回目でも十分に入る。狩りで足す） | 宝箱、狩りの採取、交換所（古い時代のいつもの素材） |
   | ギア | 宝箱・出来事・落とし物（**探して見つける楽しみ**） | 交換所（章ごとに少し） |
   | スナップ | ぬし・返した報酬・宝箱（**物語の節目のごほうび**） | 落とし物 |
   | 記憶の欠片 | 要らない素材の時分解 | 落とし物 |
   | 消費アイテム | 交換所 | 宝箱、狩りの採取、勝利のアイテム |
3. **伸びしろは、見えない壁ではなく「伸びにくさ」で区切る**（2026-10-16 に開発者と決めた）。はっきりした上限は数値を合わせやすいが、遊ぶ人には「頑張ったのに強くならない」壁に見え、苦手な人が狩りで追いつく道も狭める。そこで、狩るほど強くはなるが、ゆるやかにしか伸びない形にする
   - **星図**：章が進むと区域そのものが広がる（まだの章の区域は見せない。その章で初めて星図を開いた時に「星図が広がった！」）。禁止ではなく、新しい物が増える喜びにする。今の48の星のうち、はくちょう座（17の星。段階56）が2章の区域。3章から区域を足し、区域を足すたびに1マスの費用を少しずつ上げる
   - **武器**：レベルの上限は作らない。狩りで**前の章の区画**の砂嵐と戦うと、経験値が半分（格下の砂嵐からは伸びにくい）。進化は鍵の素材（先の区画で手に入る）で止まる
   - **狩りの星の砂**：今の章の区画は全部、前の章の区画は半分
   - 測定は「狩りをしない方針」で目安に合わせ、のちに「狩りを少しする方針」も足して、楽になりすぎないかを確かめる
   - クリア後は、最後の区域と砂の底の深い階が開く（やり込みの伸びしろ。下の 6.）
4. **素材は「時代の仲間」でまとめて数を抑える**。1区画で新しい素材は8〜10種（いつもの3・珍しい3・レア1・部位2・ぬし1）。同じ時代の区画（昭和の商店街と昭和40年代の上京など）では前の素材を一部また出す。どの素材も「何かの進化の鍵」か「狙って上げたい能力値」を持たせ、ただの数合わせにしない
5. **「全部集め」はやり込みに、「先へ進むのに要る物」は物語に**置く。進化の本道の鍵は物語の1回目で必ず手に入る（ぬしの部位・宝箱）。寄り道の鍵・レア・図鑑を埋める物は、狩り・逃げる敵・落とし物・砂の底に置く

## 4. レストピアの拠点（ハブ）

- **入り方**：昼の日常の時計屋の「時計屋の奥へ（レストピア）」（紫の「扉」）。返した区画が1つでもあり、2章（5日目）から出る（段階60。1章は物語に集中する。1章の終わりの会話で、入口の脇の砂時計に気づく）。日も昼の回数も使わない（段階43の狩りの入口を、ここへ移した）。夕暮れの物語でレストピアに行った時に寄れるようにするかは、物語の流れと合わせて後で決める
- **作ったこと**（段階50、2026-10-16）：拠点の画面（`HubScene`。蔵書の棚の絵とレストピアの曲）。狩り、育成（星図・ムーブメント・武器、入れ替えられるスナップがあればアルバム。今の章で開いているものだけ）、交換所と落とし物の棚（準備中）、時計屋へ戻る。育成の画面の見出しは「レストピア（蔵書の棚）」、戻るボタンは「レストピアへ戻る」（戻り先 `SceneTarget` の `place`・`label`）。狩りの左上は「レストピアへ戻る」。拠点にいることはセーブしない
- **拠点でできること**：①**狩り**（返し終えた時間に入り直す）、②**交換所**、③**落とし物の棚**（任意のクエスト）、④**育成**（星図・ムーブメント・武器・アルバム。今はチェックポイントからしか開けない）、⑤**目録**（あとで。下の 6.）
- **物語の中の意味**（2026-10-16 決まった。`docs/STORY.md` の 2-2）：拠点は、ハルトたちが見てきた記憶の砂時計が並ぶ、レストピアの入口の棚。昼でもハルトが柱時計に触れると開く。初めて入った時と、2-3 を持ち去られた後に初めて入った時に会話が流れる（`HUB_SCENES`。見たかどうかは物語の変数 `見た:id`）
- **背景**：レストピアの蔵書の棚（絵はある）。棚の前に、交換所の番人と落とし物の棚を置く。交換所の番人を誰にするか（アーカイバーの誰か、新しい人物）は物語と合わせて決める（それまでは仮の人物）
- 7章で記憶の砂時計を持ち歩くようになったら、どこからでも拠点に入れる（`docs/ROADMAP.md` の M4）

## 5. 新しく入れるもの

### 5-1. 消費アイテム：小さなポーチ

- 探索（物語の1回目・狩り・砂の底）に持ち込む。**種類は章ごとに足していく**（下の表。終章までに7種類ほど）。新しい種類は、その章の敵の新しい攻め方に「備える」物にする

  | 時期 | 足す物 | ねらい |
  | --- | --- | --- |
  | 2章（今） | ポーション（1人の HP を回復）、エーテル（1人の MP を回復）、ハイポーション（1人の HP を多く回復） | チェックポイントまでもたせる |
  | 3章 | 全体の回復（全員の HP を少し） | 全体攻撃の多い敵 |
  | 4章 | 起こす物（倒れた仲間を HP 少しで戻す） | 仲間が4人以上になり、控えと入れ替える前に |
  | 5章 | 状態を戻す物（順番の入れ替え・後回しなどを消す） | イリス・ヴィクトの「時間」の攻め方 |
  | 6章〜 | 上の物の強い版（ハイエーテル、全体のハイポーション） | 終盤の敵の強さ |
  | やり込み | 砂の底でしか手に入らない物（1戦に1回だけの強い物） | 裏ボスと深い階 |

- **1種類3個まで**持てる（ポーチの上限。中盤で4個に増やす候補）。種類が増えても、1戦で何個も使って押し切れないよう、1つの戦闘で使えるのは3回まで（候補）。戦闘中は「その他」から使い、手番を1つ使う
- チェックポイントでは補充しない（HP・MP は全回復するので、「チェックポイントまでもたせる」ための物）。補充は交換所・宝箱・狩りの採取・勝利のアイテム
- 武器に吸わせる役目と、時分解の材料からは外す（素材と混ぜない）
- 数値は自動対戦で、ポーチを使う方針と使わない方針の両方を測って決める
- **作ったこと**（段階51、2026-10-16）：戦闘の「その他」から使う（`docs/design/battle.md` の 10-4）。たたき台の数値は、ポーション HP 50、ハイポーション HP 100、エーテル MP 12（`src/data/pouch.ts`）。1種類3個まで、1戦に3回まで。武器の画面の素材の一覧から外し、時分解できなくした。拠点の画面にポーチの中身を出す。測った勝率は `docs/design/battle.md` の 13.

### 5-2. 交換所（ショップ）

- **番人：時間保管局の取引の窓口の係「ペトラ」**（2026-10-16 に開発者と決めた。名前と見た目も段階52の前に決めた。`docs/STORY.md` の 2-6）
  - ふだんはアーカイバー相手に、切り取りの時に出る記憶の欠片を引き取って、仕事に要る物と交換している（時間保管局は欠片を集めている）。中立なのは、現場の仕事を知らない窓口の係で、規則どおりに取引するだけだから
  - **最初**：「入口の部屋まで来られるのはアーカイバーだけ」という規則どおりに考えて、ハルトたちをアーカイバーだと思い込んで取引を始める（遊ぶ人には、ただの勘違いに見える。名前も登録も口にしない。2026-10-16 開発者の指摘で、帳簿でハルトの登録を見つける形から変えた）
  - **5章**（時間保管局の本部）：アーカイバーではないと分かる。それでも「規則上、登録は消えていない」「局長から取引を続けるよう言われた」と受け入れる（局長がハルトたちに力を貸すのと同じ時期）
  - **6章**（ハルトの正体）：「やっぱり、登録は本物だった」と分かる。最初の勘違いが、正体の伏線だったと分かる
  - 2章からカイたちアーカイバーと戦っているのに話が伝わらないのは、時間保管局が縦割りで忙しいから（局長の設定の笑いどころと同じ）。どこかの台詞で一言触れる
- 新しいお金は作らず、**記憶の欠片**で交換する。欠片は要らない素材2つの時分解で1つ（今のまま）。「武器に吸わせて能力値 +1」か「交換に使う」かを選ぶことになる
- **並ぶ物**：消費アイテム（いつでも）、古い時代のいつもの素材（返し終えた区画の分だけ）、章ごとに入れ替わるギア1〜2つ（1回だけ）、目録を埋めると増える物（やり込み）
- 進化の鍵・スナップ・星の砂は並べない（物語と狩りで手に入れる）
- 欠片の値段の目安：ポーション 1、ハイポーション 2、エーテル 2、いつもの素材 1、ギア 8〜15
- **作ったこと**（段階52、2026-10-16）：拠点の「交換所」（`ExchangeScene`）。初めて開くとペトラの会話（`exchange_intro`）。札は「ポーチ」「素材」「ギア」。欠片は4種類のどれでも1つは1つで、多く持っている種類から使う（`payFragments`）。素材は返し終えた区画の砂嵐が落とす「いつもの」素材（`areaCommonItems`）。ギアは2章（ムーブメントが開いてから）の MPギア（10）とパワーギア（12）を1回ずつ（物語の変数 `交換:id` に覚える）。ポーチが満タンの消費アイテムは交換できない。品物は `src/data/exchange.ts`

### 5-3. 任意のクエスト：レストピアの「落とし物」

- **物語の中の意味**（2026-10-16 開発者と決め直した。`docs/STORY.md` の 2-2）：拠点の棚の砂時計は、ハルトたちが見てきた記憶。その記憶の中で、あの時は気づかなかった小さなこと（落ちていた物、言えなかったひと言など）が「落とし物」。見つけたら、今の持ち主に届けに行く（目録の「返した時間」の欄に印が付く）。段階53で、初めて棚を開く時の会話を足す
- **受け方**：拠点の落とし物の棚から。受けても日は進まず、昼の回数も使わない。同時に受けられるのは3つまで
- **出る時期**：区画を返した次の日から、その区画の落とし物が棚に届く。章ごとに2〜4個
- **中身の種類**
  - 狩りの頼み：「この素材を3つ届けて」「逃げる敵を捕まえて」（狩りの目的になる）
  - 探し物：返し終えた区画の、狩りの時だけ出る物を見つける（狩りの区画に置く）
  - 写しの心残り：区画の中の写しの人にもう一度会い、短い会話（話せる人の会話を使い回せる）
  - 持ち主のその後：現代の持ち主の昼の出来事につながる（8章で持ち主たちが待っている場面の積み重ねにもなる）
  - 連作：同じ時間の落とし物が2〜3回続き、最後に大きなごほうび（一部の結末はクリア後）
- **作ったこと**（段階53、2026-10-16）：拠点の「落とし物の棚」（`LostScene`、`src/core/lost.ts`、`src/data/lost.ts`）。種類は「探し物」（記憶をたどると金色に光る所が出る。声が残っている物はその場で会話）と「取り出す」（その区画のいつもの素材を3つ集める）の2つにした。写しの心残りは、記憶の中の人と話せない設定（`docs/STORY.md` の 2-2）に合わせて、探し物の「残っている声」で表した。届けるのは物ではなく、記憶の中のことを今の持ち主に伝えること。持ち主のその後・連作は3章から。2章までの4つは `docs/milestones/M2.md` の段階53の詳細
- **報酬**：ギア（落とし物でしか取れない物を少し）、スナップ、消費アイテム、記憶の欠片、星の砂少し。進化の本道の鍵は出さない（寄り道の鍵は出してよい）

### 5-4. 記憶の「薄れ」（段階57。2026-10-16 開発者と決めた）

記憶をたどる（狩り）は日も昼の回数も使わないので、入り直せば何度でも集められた。そこで、同じ記憶を続けてたどるほど実入りが減る「薄れ」を入れた（中身は `docs/milestones/M2.md` の段階57の詳細）。

- 濃い 100% → 少し薄い 60% → 薄い 30% → かすか 10%（`MEMORY_FADE_RATES`）。同じ記憶は1日4回まで。1日たつごとに1段階戻る
- 素材は1つずつ割合の確率で残り、星の砂と経験値は割合をかける（前の章の区画の半分と重ねる）。落とし物の光る所は薄れても見つけられる
- 1回に入った中は、倒した敵と拾った採取の場所が戻らないので、もとから有限。薄れは「入り直し」を抑える
- クリア後（日が進まない）の戻し方は、クリア後を作る時に決める
- **やめた案**：1日1回だけ（全体で数回しか行けず、やり込みが細る）、昼の回数を使う（絆の出来事と取り合いになる）、1回に持ち帰れる素材の上限と取捨選択（入り直しには効かず、毎回の選択が「おまかせ」だけになりやすい）。持ち帰りの取捨選択は、1回が長く引き返せない**砂の底**で生きるので、そちらの案に回す（下の 6.。見本は `docs/sketches/carry_select.png`）

## 6. やり込みの積み上げ（物語の途中からクリア後まで）

構想ノートの「クリア後のやり込み」（砂の底、強化されたボスとの再戦、武器の最後の進化、目録）と、真のエンディング（裏ボス）につなげる。周回制にはしないので、**1回の物語の中で、やり込みが少しずつ広がる**形にする。

- **砂の底の案：持ち帰りの取捨選択**（2026-10-16 開発者と相談）：砂時計に入る数（例えば10）までしか持ち帰れず、帰る時に何を持ち帰るか選ぶ。深い階ほど良い物が出るので「この先の物のために、今の物を捨てるか」が悩みどころになる。見本の画面は `docs/sketches/carry_select.png`（鍵・レア・部位の印、吸わせた時の上がり方、「おまかせ」で鍵 → レア → 部位 → 珍しい → いつもの の順に詰める）

| 時期 | 新しく広がるやり込み | 入手物との関わり |
| --- | --- | --- |
| 1〜2章 | 狩り、逃げる敵のレア、寄り道の進化、宝箱を全部開ける | 素材のレア、寄り道の鍵 |
| 2章の終わり〜3章 | 拠点・交換所・落とし物、ポーチ | 欠片の使い道、落とし物だけのギア |
| 3〜5章 | スナップ昇格、2本目の武器（選ばなかった枝）、落とし物の連作 | スナップの種類より「深さ」、素材の需要が2倍に |
| 6〜7章 | 砂の底の入口と前半の階（目立たない所に）、目録 | 砂の底の素材、目録のごほうび |

- **目録（図鑑）**：返した時間（落とし物の印も）、敵（倒した・部位を壊した）、素材、ギア、スナップ。埋めた数で交換所の品が増え、節目でごほうび（ギア・スナップ）

- **クリア後の続き**：クリアしたセーブで、ラスボスの前から続ける（周回制にはしない）。章の上限が外れ、最後の区域と深い階が開く
- **やり込みでも、狩りの量で押し切れないように**：やり込みのごほうびは「強さ」より「選べる幅」（寄り道の進化、変わったギア、昇格したスナップ）を多めにする

## 9. 武器の進化の効果のバランス

### 9-1. 今の伸び方（2章の終わり、段階42の数値）

- 進化の効果も型の効果も、**通った分がすべて足し算で積み上がる**（`src/core/weapon.ts`）
- 例：ハルトの火の本道（フレイムブレード → 紅蓮の刃 → 煌炎の剣、型は毎回「烈」）：攻撃 18 →（進化 +12）、火のダメージは素材の火18で +36%、進化 +10%、型の烈 +15%×3 = +45%、合わせて **+91%**。部位の道（ブレイクエッジ → クラッシュエッジ → グランドエッジ、型「砕」）は部位へのダメージが **+130%**
- 例：あかりの回復の道（癒しの杖 → 慈雨の杖 → 祝福の杖、型「灯」）：ラウンドの始めの回復が 5% + 3% + 3% + 灯の3%×3 = **毎ラウンド約20%**。強すぎる
- 敵は 1-1 のぬし（HP1500・攻撃23）から 2-2 のぬし（HP3500・攻撃46）まで約2.3倍。2章までは釣り合っているが、このまま4〜6回目の進化を積むと、割合の効果だけが先に伸びて終盤の敵が追いつかない

### 9-2. 決まり（たたき台）

1. **強さの予算**：仲間の強さの伸びのうち、武器の分は約3分の1（残りは星図・ムーブメント・スナップと遊ぶ人の腕）。進化1回で、その章の敵の伸び（章ごとに約1.3倍）の3分の1くらい強くなる
2. **本道・寄り道・型の役目**
   - 本道：能力値を確実に伸ばす。段ごとに攻撃（魔力）+3、+4、+5、+5、+6、+6。属性の道は弱点を突けるぶん、物理の道より1低い
   - 寄り道：能力値は同じ段の本道より1〜2低く、**変わった力を1つ**（先制、MP 節約、バトンなど）。寄り道の力は重ならない種類にする
   - 型：進化の半分くらいの大きさ。2つの型は「攻め」と「守り・便利」に分け、どちらかがいつも上にならないようにする。**型の割合の効果は +10%**（今の +15% から下げる）
3. **割合の効果に、種類ごとの上限**（武器・型・ギア・星図を合わせた合計。上限を超えた分は効かず、武器の画面に「上限」と出す）

   | 種類 | 上限（たたき台） |
   | --- | --- |
   | 属性のダメージ | +80% |
   | 部位へのダメージ | +100% |
   | 自分のコンボのダメージ・回復 | +60% |
   | ラウンドの始めの回復 | 最大 HP の 6% |
   | 魔法・スキルの MP 消費 | −2 |
   | 延長で引く枚数 | +2 |
   | バトンを受けた時の倍率 | 1.75 |

4. **4回目より先**：能力値の伸びを抑え、新しい遊び（2つ目の属性、武器ごとの技）を足す。最後の進化（やり込み）は「強さ」より「選べる幅」
5. **測り方**：自動対戦の測定に「進化の道ごとの勝率」を足し、どの本道もぬしの勝率が ±5% に収まるようにする（寄り道は少し低くてよい）

### 9-3. 今の数値で直す所（段階54）

- 回復の道（癒し → 慈雨 → 祝福・陽だまり）と型「灯」の重なり：上限 6% で止める（進化先の 5% → 3% のような減り方もやめ、本道は 3% から少しずつ）
- 型「烈」：+15% → +10%
- 寄り道「ばば抜きのカード」（コンボ +30%）と「幻のカード」の道（+20%）、型「結」（+15%）の重なり：上限 60% で止める
- 直した後に、2-1〜2-3 のぬしの勝率を測り直す
- **作ったこと**（段階54、2026-10-16）：上限は `PASSIVE_CAPS`（`src/data/constants.ts`）で、`passiveRate` が止める。武器の画面の武器の札の下に「上限：火 +80%・回復 6%」のように出す。型の烈・結を +10% に、回復の道を 3% → +1% → +1%（合わせて 5%）にした。自動対戦の測定に「進化の道ごとの勝率」（`measureEvolutionPaths`。1人の1回目の進化先を決めて通す）を足した
