# 設計書：育成

今の育成の仕組み（星図・ムーブメント・武器）。数値・形・名前はすべて仮で、正は `src/data`。ロジックは `src/core/growth.ts`・`navi.ts`・`weapon.ts`（Phaser を読み込まない。受け取った状態を書き換えず、新しい状態を返す）。

構想ノート（`docs/CONCEPT.md`）では育成は4つ（星図・ムーブメント・武器・スナップ昇格）。スナップ昇格はまだ作っていない（M3 の予定）。

| 育成 | 役割 | 試した段階 |
| --- | --- | --- |
| 星図 | 量の成長（能力値・魔法・スキル） | 段階7 |
| ムーブメント | 詰めて組み合わせる成長（戦い方の味付け） | 段階8 |
| 武器 | 育てて分岐する成長（進化） | 段階9 |

## 1. 戦闘への反映

- 戦闘に使うキャラは、星図 → ムーブメント → 武器 の順に反映して作る（`src/scenes/run.ts` の `currentParty`）
- 能力値は足し算。戦い方の効果は「キャラの特性」として戦闘に渡す（`battle.md` の「キャラの特性」）。戦闘ロジックは育成の仕組みを知らない
- 戦闘の結果（`getBattleResult`）には、倒した敵が落とした素材と、仲間ごとの行動の回数が入る。周回の側で武器に貯める

## 2. 星図

- 全員で1枚の星図を共有する。**夏の大三角のまわりの本物の星座**の48個の星（出発点3、魔法・スキル10、能力値の小28・大7）と、星座の線に沿った55本の道（段階56）。データは `src/data/growthMap.ts`：星ごとに、実際の赤経・赤緯、星座、何章の区域か、効果。位置は空を見上げた向き（東が左）で、1度あたり13。小さな星座はその中心から広げる（タップできるように。星同士は34より近くしない）。道は「星-星」の一覧（隣は道で決める）
- 星座と仲間：わし座（ハルト。アルタイルが出発点。攻撃・HP・ダブルスラッシュ・ファイア）、こと座（あかり。ベガ。魔力・MP・ケアル・ケア・アイス）、いるか座（みお。スアロキン。速さ・サンダー・ひらめき）、や座・こぎつね座（3つをつなぐ橋。道は点線）、はくちょう座（2章の区域。大きな能力値とファイラ・ブリザラ・サンダラ）、ヘルクレス座（3章の区域。段階91。小夜子の出発点 ヘルクレス座π。こと座κからつながる。11の星）。七夕の織姫（ベガ）と彦星（アルタイル）の間に天の川
- **行き止まり**の星は、大きな能力値か魔法・スキル（隅まで行く意味を出すため）。ただし将来の星座へつなぐ場所（`GROWTH_FRONTIER`：わし座λ → たて座・いて座、はくちょう座ρ → ケフェウス座、はくちょう座κ → りゅう座）はそのままにして、外へ向かう薄い点線と「？」を出す。3章からの星座は、ここにつなぐ
- 書き間違いは `checkGrowthMap` とテストで止める（知らない星への道、同じ道、近すぎる星、どの章でもその章までの星だけで全部へ行けるか、行き止まりの決まり）
- 各キャラが自分の駒を持つ。出発点はキャラごとに違い、まわりはそのキャラの得意分野
- **星の砂**（パーティ共通の財布）を払って、自分の駒が開けたマスの隣の、まだ開けていないマスを1つ開ける。駒がそこへ進み、効果を得る。効果はそれ以降ずっと続く
- マスの開放はキャラごと。他のキャラの得意分野にも、道をたどれば入れる
- 費用：能力値（小）3、能力値（大）6、魔法・スキル8。もう覚えている魔法・スキルのマスと、他のキャラの出発点は「通るだけ」で3（段階62で値段を3倍、能力値の上がり幅を2倍にした。星図をゆっくり広げるため）（効果なし）
- 覚えた魔法・スキルは、元の魔法・スキルの後ろに加わる
- 星の砂の入手：周回の始めに8（段階62で 3 → 8）。戦闘に勝つと戦闘ごとに決まった量（`CAMPAIGN` の `reward`）、部位を1つ壊すごとに +2
- ポイントは残して次に持ち越してよい
- **章の区域**（段階49。`docs/design/economy.md` の 2.）：マスに「何章の区域か」を持たせられる（`GrowthNodeDef` の `chapter`）。今は、はくちょう座（17の星）が2章の区域。章は今の章のパーティの `chapter`（試作の5戦は制限なし）。まだの章の区域のマスと道は描かず、開けられない。その章で初めて星図を開いた時に「星図が広がった！」（見たことは物語の値 `星図:広がった:2` に覚える）

**おすすめの道**（段階100。`src/core/recommend.ts` の `recommendStar`）：今の仲間の、まだ開けていない星を「価値 ÷ そこまで開けるのに要る星の砂」で比べ、一番よい星までの道を金色の点線で光らせ、次に開ける星の上に「おすすめ」と書く。価値は `GROWTH_RECOMMEND`（まだ覚えていない魔法・スキル 10、大きな能力値 7、能力値 3。その仲間の星座の星は 1.5倍）。道の値段は今の値段で数え、章の来ていない星は通らない。何も選んでいない時の説明に「おすすめ：○○（金の道・あと n pt）」と「おすすめを選ぶ」（次の星を選んで寄せる）。開けるのは、遊ぶ人が「開ける」を押した時だけ（星の砂は取り消せないため）

## 3. ムーブメント

- 仲間ごとに盤を1枚持つ。盤の形はキャラごとに違う（`src/data/navi.ts` の `NAVI_BOARDS`。ハルト 4×4、あかり 3×5（縦長）、みお 4×4 の四隅なし）
- 盤の中の1列が**ブリッジ**（光る縦の帯。全員、左から2列目。2026-10-16 に横から縦にした）
- 能力値ギアの名前は、上がる能力値＋「ギア」（HPギア・MPギア・パワーギア・マジックギア・ガードギア・スピードギア。2026-10-16 に「○○メモリ」から替えた）
- **ギア**は色付きのブロック（1〜4マス）。盤のマスに、はみ出さず・重ならずに置ける。90度ずつ回転できる
  - 能力値ギア：盤のどこに置いても効く
  - 効果ギア：ブリッジに1マス以上乗っている時だけ効く。台座のふちを金にして、能力値ギア（黒いふち）と見分ける（ブリッジの金の帯と同じ金。乗って効いている時は軸の石が光る。段階146 の調整）
- **狂い**：同じ色の別々のギアが辺で接していると、その組ごとに狂いが1つ。1つにつき、ラウンドの始めに最大HPの5%を失う。接している所が赤く焼けて煙が出る（段階146。文字は出さない）
- 色は赤・青・緑・黄の4色。画面では色を金属で見せ、名前も金属にする（赤＝銅、青＝鋼、緑＝青銅、黄＝真鍮。段階146。`docs/ART.md` の 5-9）。同じギアを複数持てて、同じ効果は重なる
- 戦闘の外（星図から開く）でいつでも、何度でも外して付け直せる（費用なし）
- ギアの入手：周回の始めに6つ。試作の5戦は、戦闘1〜4に勝つと、その戦闘に決まった3つの候補から2つ選ぶ（`CAMPAIGN` の `naviReward`。シードで変えない）。勝った後に星図を開くと選ぶ画面が出る（2つ選ぶまで閉じられない）
- 物語の区画（段階38）：ギアは戦闘では手に入らない。区画の宝箱（`AreaChest` の `gears`）と、出来事のごほうび（会話のきっかけの `gears`。初めて見た時。段階39から、返した翌日の出来事など日常の印の `gears` も。見終えた時。今後のクエストの報酬も同じ形）で手に入る
- 盤の狂いの効果は盤ごとに持たせてある（将来、りくだけ「狂いを力に変える」に差し替えられるように）

**画面**：上からキャラの切り替え、盤（1マス最大56。盤が広いと縮める）、説明、ギアの一覧（形の絵と名前。多い時は指で上下にずらす。段階127）、ボタン（回転・はめる・外す・戻る）。ギアを選んで盤のマスをタップすると影（置けない時は赤）→「回転」→「はめる」（影をもう一度タップしても決定）。ギアを選んだままキャラの枠をタップすると別の盤に移せる。ブリッジに乗っていない効果ギアは暗く表示し、×の印を付ける（段階126）。盤の下に、能力値・効いている効果・効かない効果ギア（ブリッジの外）・狂い（毎ラウンドの始めに減る HP の量。最大HP×狂いの割合の切り捨てで、戦闘と同じ `bugHpLoss`）。**置ける影がある時は、盤の下を「置いた時▶」としてはめた後の結果にし、狂いの赤い辺もはめた後の形で出す。効果ギアの影には「効く」「効かない」**（段階126。レビューの項目5・35・36。手で置くパズルのまま、試す前に結果が分かるように。おまかせ配置や正解の位置の案内は出さない）

## 4. 武器

- 仲間1人に武器1本（持ち替えはまだない）：ハルト「記録の剣」、あかり「祈りの杖」、みお「切り札のトランプ」（段階38で「投げカード」から替えた。id は `throwCards`。`src/data/weapons.ts`）
- パラメータ：**攻撃値**（キャラの攻撃に足す）と、**属性値**（火・氷・雷。1につきその属性のダメージ +2%）
- **素材**（段階27b で作り直した。くわしくは 6.）：敵は倒すと素材を1つ落とす（いつもの素材・珍しい素材・レアを確率で。体勢が崩れた敵を倒すと出やすい）。部位を壊すと、その部位の素材を必ず落とす。素材は武器に**直接刻む**。素材ごとに上がる能力値・下がる能力値が違い、刻む前にプレビューで見せる。刻印を1つ使う
- **記憶の欠片と時分解**：要らない素材・アイテムを2つ時分解すると、記憶の欠片が1つ（その素材が一番大きく上げる能力値の欠片）。欠片は刻印を使わずに、その能力値 +1。通常アイテムは、今は戦闘で使えない（時分解するだけ）

| 記憶の欠片 | 1つで上がるパラメータ |
| --- | --- |
| 勇気 | 攻撃 +1 |
| 高揚 | 火 +1 |
| 安堵 | 氷 +1 |
| 驚嘆 | 雷 +1 |

- 素材・アイテム・欠片はパーティ共通の持ち物。刻んだものは取り消せない
- **刻印**：武器のレベルごとに増える（Lv1 で6、Lv2 で12、Lv3 で18）
- **武器レベル**：その武器を持つキャラが戦闘で行動すると、1回につき経験値1（防御以外。連携技は2人とも、追加行動も数える）。経験値4で Lv2、8で Lv3（だいたい戦闘3つで Lv3）。段階42で Lv7 まで伸ばした（16で Lv4、26で Lv5、38で Lv6、52で Lv7。だいたい1つの区画で2レベル）
- **刻印**（段階42で足した分）：Lv4 から1レベルで4つずつ（Lv4 で22、…、Lv7 で34）
- **狩りの経験値**（段階49）：狩りで前の章の区画の砂嵐と戦うと、経験値は半分（切り捨て。`BattleRecord` の `expRate`）。武器のレベルに章ごとの上限は作らない（`docs/design/economy.md` の 2.）
- **傾向**：戦闘に勝つたびに、そのキャラの盤にはまっているギアの色ごとのマス数を武器に貯める。一番多い色が「傾向」（同じ数なら傾向なし）。進化の条件に使うので、武器の画面に見せる
- **進化**（段階42から、進化ツリー。くわしくは 8.）：次の進化先の条件を満たすと、そこへ進化できる（何度も。戻せない）。1回目は Lv3 で3つから、2回目は Lv5、3回目は Lv7。進化するたびに型を2つから1つ選ぶ。以下は1回目の進化の話。Lv3 で進化先の条件を満たすと、3つの進化先から1つを選んで進化できる。パラメータは引き継ぎ、進化先の効果が加わる。条件は「能力値」と「鍵の素材」（段階27b。進化すると鍵を1つ使う。みおの切り札のトランプのトリックカードだけ「傾向が黄」）。条件は `WEAPON_DATA` の `evolutions`
  - 効果の例：通常攻撃に属性が乗る（弱点を突けて延長の手段が増える。魔力で計算）、能力値、キャラの特性（部位の割増し、再生、延長で引く枚数）
  - 進化すると、そのキャラの盤に1マス増える（段階111。テストプレイのメモ 24：前は2マスで、増えすぎていた）。形は選んだ型で決まる（段階100b から：ブリッジが伸びる型は盤のすぐ下の新しい行を、ブリッジの列から近い順に埋める。盤が広がる型は盤のすぐ右の新しい列を、上から埋める。どちらも、すでにある盤のマスに接する所だけで、行・列がそろうと次の行・列へ。盤ができるだけ四角に広がり、伸びた所にもいろいろな形のギアが入る。`extendBoard`）

**画面**：上からキャラの切り替え、武器のカード（名前、Lv と経験値、攻撃値・火・氷・雷、刻印、傾向）、進化先（条件を ✓／✗ で。鍵の素材の手に入れ方は長押し。全部 ✓ なら「進化」→ 確認 → 演出）、下の段は「素材」と「記憶の欠片」のタブ（くわしくは 6-7）。星図の「武器」ボタンは、進化できる武器があると金色になる。勝った時の表示に、手に入れた素材・アイテムとレベルアップを出す。

## 6. 武器と素材の作り直し（段階27b。2026-10-09 にたたき台どおりに作った）

**ねらい**：モンハンの素材集め（この素材が欲しいから、あの敵を狩る。部位を壊すと違う素材が出る。レアが出ると嬉しい）と、ダーククロニクルの武器ビルドアップ（素材を刻んで能力値を伸ばし、能力値と条件で進化先が分かれる）を組み合わせる。遊ぶ人が楽しめるかは、次の4つがそろうかで決まる。

1. 目標が見える（何を集めれば、どう育つか）
2. 集める理由が具体的（「あの敵の、あの素材」が欲しい）
3. 刻む時に悩む（どの素材を、どの武器に入れるか）
4. レアの喜び（出た瞬間が嬉しく、使い道が特別）

今の作り（素材 → 時分解 → 混ざった欠片 → 刻む）は、何から何が出るかが見えにくく、時分解に判断がない（全部時分解するのが正解）。素材の種類にも意味がない。これを次のように変える。

### 6-1. 素材を直接刻む。素材ごとに上がり下がりが違う

- 素材は、時分解しないで、そのまま武器に刻む。素材ごとに、上がる能力値・下がる能力値が違う（下の表）
- 刻む前に、武器の能力値がどう変わるかをプレビューで見せる（「氷 4 → 6、火 2 → 1」）。取り消しはできない（今と同じ）
- 能力値は今と同じ4つ（攻撃・火・氷・雷。属性は1につきその属性のダメージ +2%）。下がって0より小さくはならない

### 6-2. 刻める数に上限（刻印）

- 武器のレベルごとに刻印が増える：Lv1 で6、Lv2 で12、Lv3 で18（合計）。経験値の仕組み（戦闘での行動の回数。Lv2 は4、Lv3 は8）は今のまま
- 枠を使い切ったら、レベルが上がるまで刻めない。何でも入れればいいわけではなく、どの素材を枠に入れるかを考える
- 1-1 で手に入る素材は、2人合わせて15〜20個ほどの見込み（雑魚戦4つで敵10体ほど＋宝箱＋ボス）。1人あたり8〜10個なので、Lv1 の6枠ではあふれ、選ぶことになる

### 6-3. 敵の落とし物：いつもの素材・珍しい素材・レア、部位破壊

### 6-6. 時分解：要らない素材の整理

- 時分解は「要らない素材を、記憶の欠片に変える」役目にする（ダーククロニクルの分解と同じ）。素材2つで、その素材の一番大きい能力値に対応する欠片1つ（勇気＝攻撃、高揚＝火、安堵＝氷、驚嘆＝雷）
- 欠片は、刻印を使わずに刻める。1つで、その能力値+1（下がる能力値はない）
- 下がる能力値のある素材や、余った素材が無駄にならない安心のための仕組み。素材のまま刻む方が強い（素材2つで+3〜+4、欠片にすると+1）
- 通常アイテム（ポーションなど）は、今は戦闘で使えないので、時分解して欠片にするだけ（M2 以降、戦闘で使えるようにするか考える）
- **出す時**（段階100c）：時分解は、どれかの武器の刻印が初めていっぱいになった時（`anySlotsFull`）か、交換所を初めて開いた時（ペトラが時分解を教える。拠点は2章から）の、早い方から出す。一度出たら物語の変数 `武器:時分解`（`DECOMPOSE_VAR`）に覚えて、その後はずっと出す（レベルが上がって枠が空いても隠さない）。1章の終わりでも枠に空きがあり、使う理由がないため。初めて出た時に説明「時分解と記憶の欠片」（`growth_decompose`）

- 「おすすめ」（段階100 で選び方を `recommendMaterials` にまとめた）：一番近い進化先の、足りない能力値を上げる素材に ★ を付け、一番よい素材を金の枠にして一覧の先頭へ並べる。進化先の条件を下げる素材と、これから使う進化の鍵（持っている武器の、まだ通っていない進化先の鍵。`upcomingKeys`）を、要る数より多く持っていない素材は勧めない。能力値がそろっている時は、上がる合計の大きい素材から勧める。刻むのは遊ぶ人（取り消せないため）。この武器の進化の鍵になる素材には「鍵」と付け、選ぶと「進化の鍵にもなる素材」と出す（うっかり刻んで鍵を使い切らないように）
- 勝利の表示：手に入れた素材を種類ごとに（いつも・珍しい・レアで色を変える）。レアは「レア！」の帯と効果音

## 8. 進化ツリー（2026-10-10 に開発者と決めた。段階42で作った（8-5）。名前・数値は仮）

**ねらい**：武器は1回で終わらず、ツリーをたどって何度も進化していく。次の進化先はすべて見えて、その先は「何に育つかは分からないが、どちらへ向かうかは分かる」。遊ぶ人が「この先に行きたいから、この素材を狩る」と決められるようにする。名前・数値・条件はすべて仮。

### 8-1. ツリーの形：枝分かれだけ（合流しない）。行けない枝は2本目の武器で

- 段ごとに枝分かれし、合流はしない。1回選ぶと、ほかの枝には戻れない（進化は今と同じく戻せない）
- 例（記録の剣）：進化は6回（1回目〜5回目と最後）。途中の段は3〜5つにしぼり（枝分かれしない段もある）、最後で6つになる（3 → 3 → 4 → 5 → 5 → 6）
- **選ばなかった枝は、同じ種類の武器をもう1本手に入れて、持ち替えて育てれば目指せる**（構想ノートの「成長は武器に溜まるので、持ち替えても無駄にならない」）。武器の持ち替えと、2本目の手に入れ方は、作る時に決める
- 今の武器から行けない進化先は薄く出し、詳しく見ると「同じ種類の武器をもう1本育てれば目指せる」と出す
- 遊ぶ人の面白さ（やり込み）を、作る量より優先する（2026-10-10 開発者と決めた。絵は開発者が用意する）

### 8-1b. 寄り道（短い枝）

- 本道の途中から、1〜2段で終わる短い枝を生やす。記録の剣の例では4本で、一番先は全部で10（本道6、寄り道4）。全部集めるのがやり込みになる
- 寄り道の条件は変わったものにする：日常の小さな遊びの結果（射的の点数、金魚すくいの数）、戦い方（ボスの部位を全部壊して勝つ、延長を5回つなぐ）、能力値を低いままにする（雷2以下）、など
- 能力も変わったものにする（戦闘の最初に全体へ小さなダメージ、大技の予告が早く見える、など）。本道の一番先より弱くてもよいが、ほかにない使い道がある
- 寄り道の入口には「寄り道」の札を付ける（影だけの時も付ける。どこかに寄り道があることは分かる）。2段先の寄り道は、伸びる方向の代わりに条件の手がかりを見せる

### 8-1c. 型（進化のたびに選ぶ）

- 進化するたびに、その進化先の2つの型から1つを選ぶ（例：紅蓮の刃の「烈」火の技の威力+15%、「灯」火の攻撃で受けるダメージ-20%）。名前は「紅蓮の刃・烈」。絵は同じ
- 型は次の進化に引き継ぐ。進化を重ねるほど組み合わせが増え、同じ進化先でも中身が人それぞれになる
- 型ごとに、盤（ムーブメント）に足すマスの形が変わる（例：横に2マス／縦に2マス。構想ノートの「武器ごとの形を盤に足す」）。今の「進化するとブリッジの行の右端に2マス」を置き換える
- 型を見せるのは1段先（選ぶ前）と、今の武器・通った道（選んだ型）だけ
