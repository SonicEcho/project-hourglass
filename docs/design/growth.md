# 設計書：育成

今の育成の仕組み（星図・ムーブメント・武器）。数値・形・名前はすべて仮で、正は `src/data`。ロジックは `src/core/growth.ts`・`navi.ts`・`weapon.ts`（Phaser を読み込まない。受け取った状態を書き換えず、新しい状態を返す）。

構想ノート（`docs/CONCEPT.md`）では育成は4つ（星図・ムーブメント・武器・スナップ昇格）。スナップ昇格はまだ作っていない（M3 の予定）。

| 育成 | 役割 | 試した段階 |
| --- | --- | --- |
| 星図 | 量の成長（能力値・魔法・スキル） | 段階7 |
| ムーブメント | 詰めて組み合わせる成長（戦い方の味付け） | 段階8 |
| 武器 | 育てて分岐する成長（進化） | 段階9 |

## 1. 戦闘への反映

- 戦闘に使うキャラは、星図 → ムーブメント → 武器 の順に反映して作る（`src/scenes/run.ts` の `currentParty`）
- 能力値は足し算。戦い方の効果は「キャラの特性」として戦闘に渡す（`battle.md` の「キャラの特性」）。戦闘ロジックは育成の仕組みを知らない
- 戦闘の結果（`getBattleResult`）には、倒した敵が落とした素材と、仲間ごとの行動の回数が入る。周回の側で武器に貯める

## 2. 星図

- 全員で1枚の星図を共有する。7列×9行の格子に48マス（出発点3、魔法・スキル10、能力値35）。上下左右に隣り合うマスが道でつながる。形は `src/data/growthMap.ts` に文字の絵で書く
- 各キャラが自分の駒を持つ。出発点はキャラごとに違い、まわりはそのキャラの得意分野（ハルト：下の中央・攻撃とHP・物理の技、あかり：左・魔力とMP・回復、みお：右・速さ・雷と手札の技）。上の方は大きな能力値と強い魔法
- **星の砂**（パーティ共通の財布）を払って、自分の駒が開けたマスの隣の、まだ開けていないマスを1つ開ける。駒がそこへ進み、効果を得る。効果はそれ以降ずっと続く
- マスの開放はキャラごと。他のキャラの得意分野にも、道をたどれば入れる
- 費用：能力値（小）1、能力値（大）2、魔法・スキル3。もう覚えている魔法・スキルのマスと、他のキャラの出発点は「通るだけ」で1（効果なし）
- 覚えた魔法・スキルは、元の魔法・スキルの後ろに加わる
- 星の砂の入手：周回の始めに3。戦闘に勝つと戦闘ごとに決まった量（`CAMPAIGN` の `reward`）、部位を1つ壊すごとに +2
- ポイントは残して次に持ち越してよい

**画面**：上から星の砂、星図（1マス約46）、説明、キャラの切り替え、「ムーブメント」「武器」ボタン、「戦闘Nへ」。マスは種類で色と形を変える（能力値は丸・大は白い縁、魔法・スキルは金のひし形、出発点はキャラの色）。今のキャラが開けたマスは明るく、開けられるマスは黄色い枠。タップで説明、同じマスをもう一度タップで開ける。長押しで詳細。キャラの枠の長押しで能力値と魔法・スキル。

## 3. ムーブメント

- 仲間ごとに盤を1枚持つ。盤の形はキャラごとに違う（`src/data/navi.ts` の `NAVI_BOARDS`。ハルト 4×4、あかり 5×3、みお 4×4 の四隅なし）
- 盤の中の1行が**ブリッジ**（光る横の帯）
- **ギア**は色付きのブロック（1〜4マス）。盤のマスに、はみ出さず・重ならずに置ける。90度ずつ回転できる
  - 能力値ギア：盤のどこに置いても効く
  - 効果ギア：ブリッジに1マス以上乗っている時だけ効く
- **狂い**：同じ色の別々のギアが辺で接していると、その組ごとに狂いが1つ。1つにつき、ラウンドの始めに最大HPの5%を失う。接している辺を赤く光らせる
- 色は赤・青・緑・黄の4色。同じギアを複数持てて、同じ効果は重なる
- 戦闘の外（星図から開く）でいつでも、何度でも外して付け直せる（費用なし）
- ギアの入手：周回の始めに6つ。戦闘1〜4に勝つと、その戦闘に決まった3つの候補から2つ選ぶ（`CAMPAIGN` の `naviReward`。シードで変えない）。勝った後に星図を開くと選ぶ画面が出る（2つ選ぶまで閉じられない）
- 盤の狂いの効果は盤ごとに持たせてある（将来、りくだけ「狂いを力に変える」に差し替えられるように）

**画面**：上からキャラの切り替え、盤（1マス最大56。盤が広いと縮める）、説明、ギアの一覧、ボタン（回転・はめる・外す・戻る）。ギアを選んで盤のマスをタップすると影（置けない時は赤）→「回転」→「はめる」（影をもう一度タップしても決定）。ギアを選んだままキャラの枠をタップすると別の盤に移せる。ブリッジに乗っていない効果ギアは暗く表示する。盤の下に、効いている効果と狂いの数。

## 4. 武器

- 仲間1人に武器1本（持ち替えはまだない）：ハルト「記録の剣」、あかり「祈りの杖」、みお「投げカード」（`src/data/weapons.ts`）
- パラメータ：**攻撃値**（キャラの攻撃に足す）と、**属性値**（火・氷・雷。1につきその属性のダメージ +2%）
- **素材**（段階27b で作り直した。くわしくは 6.）：敵は倒すと素材を1つ落とす（いつもの素材・珍しい素材・レアを確率で。体勢が崩れた敵を倒すと出やすい）。部位を壊すと、その部位の素材を必ず落とす。素材は武器に**直接吸わせる**。素材ごとに上がる能力値・下がる能力値が違い、吸わせる前にプレビューで見せる。吸わせ枠を1つ使う
- **記憶の欠片と時分解**：要らない素材・アイテムを2つ時分解すると、記憶の欠片が1つ（その素材が一番大きく上げる能力値の欠片）。欠片は吸わせ枠を使わずに、その能力値 +1。通常アイテムは、今は戦闘で使えない（時分解するだけ）

| 記憶の欠片 | 1つで上がるパラメータ |
| --- | --- |
| 勇気 | 攻撃 +1 |
| 高揚 | 火 +1 |
| 安堵 | 氷 +1 |
| 驚嘆 | 雷 +1 |

- 素材・アイテム・欠片はパーティ共通の持ち物。吸わせたものは取り消せない
- **吸わせ枠**：武器のレベルごとに増える（Lv1 で6、Lv2 で12、Lv3 で18）
- **武器レベル**：その武器を持つキャラが戦闘で行動すると、1回につき経験値1（防御以外。連携技は2人とも、追加行動も数える）。経験値4で Lv2、8で Lv3（だいたい戦闘3つで Lv3）
- **傾向**：戦闘に勝つたびに、そのキャラの盤にはまっているギアの色ごとのマス数を武器に貯める。一番多い色が「傾向」（同じ数なら傾向なし）。進化の条件に使うので、武器の画面に見せる
- **進化**：Lv3 で進化先の条件を満たすと、3つの進化先から1つを選んで進化できる（1回だけ。戻せない）。パラメータは引き継ぎ、進化先の効果が加わる。条件は「能力値」と「鍵の素材」（段階27b。進化すると鍵を1つ使う。みおの投げカードだけ、まだ「傾向が◯色」）。条件は `WEAPON_DATA` の `evolutions`
  - 効果の例：通常攻撃に属性が乗る（弱点を突けて延長の手段が増える。魔力で計算）、能力値、キャラの特性（部位の割増し、再生、延長で引く枚数）
  - 進化すると、そのキャラの盤のブリッジの行の右端に2マス増える（効果ギアを乗せやすくなる）

**画面**：上からキャラの切り替え、武器のカード（名前、Lv と経験値、攻撃値・火・氷・雷、吸わせ枠、傾向）、進化先（条件を ✓／✗ で。鍵の素材の手に入れ方は長押し。全部 ✓ なら「進化」→ 確認 → 演出）、下の段は「素材」と「記憶の欠片」のタブ（くわしくは 6-7）。星図の「武器」ボタンは、進化できる武器があると金色になる。勝った時の表示に、手に入れた素材・アイテムとレベルアップを出す。

## 6. 武器と素材の作り直し（段階27b。2026-10-09 にたたき台どおりに作った）

**ねらい**：モンハンの素材集め（この素材が欲しいから、あの敵を狩る。部位を壊すと違う素材が出る。レアが出ると嬉しい）と、ダーククロニクルの武器ビルドアップ（素材を吸わせて能力値を伸ばし、能力値と条件で進化先が分かれる）を組み合わせる。遊ぶ人が楽しめるかは、次の4つがそろうかで決まる。

1. 目標が見える（何を集めれば、どう育つか）
2. 集める理由が具体的（「あの敵の、あの素材」が欲しい）
3. 吸わせる時に悩む（どの素材を、どの武器に入れるか）
4. レアの喜び（出た瞬間が嬉しく、使い道が特別）

今の作り（素材 → 時分解 → 混ざった欠片 → 吸わせる）は、何から何が出るかが見えにくく、時分解に判断がない（全部時分解するのが正解）。素材の種類にも意味がない。これを次のように変える。

### 6-1. 素材を直接吸わせる。素材ごとに上がり下がりが違う

- 素材は、時分解しないで、そのまま武器に吸わせる。素材ごとに、上がる能力値・下がる能力値が違う（下の表）
- 吸わせる前に、武器の能力値がどう変わるかをプレビューで見せる（「氷 4 → 6、火 2 → 1」）。取り消しはできない（今と同じ）
- 能力値は今と同じ4つ（攻撃・火・氷・雷。属性は1につきその属性のダメージ +2%）。下がって0より小さくはならない

### 6-2. 吸わせられる数に上限（吸わせ枠）

- 武器のレベルごとに吸わせ枠が増える：Lv1 で6、Lv2 で12、Lv3 で18（合計）。経験値の仕組み（戦闘での行動の回数。Lv2 は4、Lv3 は8）は今のまま
- 枠を使い切ったら、レベルが上がるまで吸わせられない。何でも入れればいいわけではなく、どの素材を枠に入れるかを考える
- 1-1 で手に入る素材は、2人合わせて15〜20個ほどの見込み（雑魚戦4つで敵10体ほど＋宝箱＋ボス）。1人あたり8〜10個なので、Lv1 の6枠ではあふれ、選ぶことになる

### 6-3. 敵の落とし物：いつもの素材・珍しい素材・レア、部位破壊

- 倒した敵1体につき、素材を1つ落とす。どれが出るかは表の確率（シード付きの乱数。同じシードなら同じ）

| 種類 | 確率（ふつうに倒した時） | ダウン中・体勢が崩れた時に倒した時 |
| --- | --- | --- |
| いつもの素材 | 75% | 60% |
| 珍しい素材 | 20% | 30% |
| レア | 5% | 10% |

- 体勢が崩れた敵を倒すと、珍しい素材とレアが出やすい（戦い方とつながる。連携技でとどめを刺すと出やすい）
- 部位破壊：壊した部位ごとに、決まった素材を必ず1つ（モンハンの「狙って壊す」）
- レアが出た時は、勝利の表示に「レア！」の帯と、専用の効果音
- ボスは、倒した時にボスの素材を1つ必ず落とす（部位の素材とは別）

### 6-5. 進化の条件：能力値＋鍵の素材

- M1 のスライスでは、1-1 のボスの前に進化できるように、鍵は雑魚の珍しい素材にする（ボスの素材は M2 以降の上位の進化の鍵）

### 6-6. 時分解：要らない素材の整理

- 時分解は「要らない素材を、記憶の欠片に変える」役目にする（ダーククロニクルの分解と同じ）。素材2つで、その素材の一番大きい能力値に対応する欠片1つ（勇気＝攻撃、高揚＝火、安堵＝氷、驚嘆＝雷）
- 欠片は、吸わせ枠を使わずに吸わせられる。1つで、その能力値+1（下がる能力値はない）
- 下がる能力値のある素材や、余った素材が無駄にならない安心のための仕組み。素材のまま吸わせる方が強い（素材2つで+3〜+4、欠片にすると+1）
- 通常アイテム（ポーションなど）は、今は戦闘で使えないので、時分解して欠片にするだけ（M2 以降、戦闘で使えるようにするか考える）

### 6-7. 画面

- 武器の画面：武器の能力値と吸わせ枠（「枠 4/6」）、進化先（条件の ✓/✗。鍵の素材は持っている数と、どの敵が落とすか）、下の段は「素材」と「記憶の欠片」のタブ。素材は上がり下がりを小さく書き、選ぶとプレビュー。「吸わせる」「時分解」
- 「おすすめ」：今の武器が、一番近い進化先に近づく素材に ★ を付ける（迷う人のため）。この武器の進化の鍵になる素材には「鍵」と付け、選ぶと「進化の鍵にもなる素材」と出す（うっかり吸わせて鍵を使い切らないように）
- 勝利の表示：手に入れた素材を種類ごとに（いつも・珍しい・レアで色を変える）。レアは「レア！」の帯と効果音

### 6-8. セーブ・測定・テスト

- 持ち物の形が変わるので、セーブの版を上げた（版6）。武器の吸わせ枠（absorbed）は0で補い、今のデータにない素材は捨てる（M1 は試遊の前なので、置き換えはしない）
- 1-1 の測定（`npm run measure`）に、吸わせ方の方針（`src/sim/autoArmory.ts`：一番近い進化先へ向けて吸わせ、鍵は残し、残りは時分解）を足した。2026-10-09 の測定：ボスの前に1人以上進化できた割合 61〜64%（目安の5〜8割）
- 落とし物の確率は、シードを固定したテストで確かめる

### 6-9. 後で作るもの（M2 以降）

- 同じ盗まれた時間にもう一度入って狩る仕組み（返した後の時間に入れる、など）。ハクスラの本番
- 素材の図鑑（目録）、武器の持ち替え、2回目より先の進化（ボスの素材やレアを鍵に。進化ツリーは 8.）

## 7. 将来の拡張を妨げないための決まり

- 盤の形はキャラごとのデータに持たせる（武器ごとの形を足せるように）
- 武器のパラメータを増やす時に、感動（魔力）・期待（速さ）・特性の欠片・郷愁を足す（`docs/NAMING.md`）
- 星図の「ギア獲得」「ロック」マス、武器の持ち替え・2回目の進化・武器から技を覚える、スナップ昇格は、まだ作らない

## 8. 進化ツリー（2026-10-10 に開発者と決めた。M2 以降で作る。名前・数値は仮）

**ねらい**：武器は1回で終わらず、ツリーをたどって何度も進化していく。次の進化先はすべて見えて、その先は「何に育つかは分からないが、どちらへ向かうかは分かる」。遊ぶ人が「この先に行きたいから、この素材を狩る」と決められるようにする。名前・数値・条件はすべて仮。

### 8-1. ツリーの形：枝分かれだけ（合流しない）。行けない枝は2本目の武器で

- 段ごとに枝分かれし、合流はしない。1回選ぶと、ほかの枝には戻れない（進化は今と同じく戻せない）
- 例（記録の剣）：進化は6回（1回目〜5回目と最後）。途中の段は3〜5つにしぼり（枝分かれしない段もある）、最後で6つになる（3 → 3 → 4 → 5 → 5 → 6）
- **選ばなかった枝は、同じ種類の武器をもう1本手に入れて、持ち替えて育てれば目指せる**（構想ノートの「成長は武器に溜まるので、持ち替えても無駄にならない」）。武器の持ち替えと、2本目の手に入れ方は、作る時に決める
- 今の武器から行けない進化先は薄く出し、詳しく見ると「同じ種類の武器をもう1本育てれば目指せる」と出す
- 遊ぶ人の面白さ（やり込み）を、作る量より優先する（2026-10-10 開発者と決めた。絵は開発者が用意する）

### 8-1b. 寄り道（短い枝）

- 本道の途中から、1〜2段で終わる短い枝を生やす。記録の剣の例では4本で、一番先は全部で10（本道6、寄り道4）。全部集めるのがやり込みになる
- 寄り道の条件は変わったものにする：日常の小さな遊びの結果（射的の点数、金魚すくいの数）、戦い方（ボスの部位を全部壊して勝つ、延長を5回つなぐ）、能力値を低いままにする（雷2以下）、など
- 能力も変わったものにする（戦闘の最初に全体へ小さなダメージ、大技の予告が早く見える、など）。本道の一番先より弱くてもよいが、ほかにない使い道がある
- 寄り道の入口には「寄り道」の札を付ける（影だけの時も付ける。どこかに寄り道があることは分かる）。2段先の寄り道は、伸びる方向の代わりに条件の手がかりを見せる

### 8-1c. 型（進化のたびに選ぶ）

- 進化するたびに、その進化先の2つの型から1つを選ぶ（例：紅蓮の刃の「烈」火の技の威力+15%、「灯」火の攻撃で受けるダメージ-20%）。名前は「紅蓮の刃・烈」。絵は同じ
- 型は次の進化に引き継ぐ。進化を重ねるほど組み合わせが増え、同じ進化先でも中身が人それぞれになる
- 型ごとに、盤（ムーブメント）に足すマスの形が変わる（例：横に2マス／縦に2マス。構想ノートの「武器ごとの形を盤に足す」）。今の「進化するとブリッジの行の右端に2マス」を置き換える
- 型を見せるのは1段先（選ぶ前）と、今の武器・通った道（選んだ型）だけ

### 8-2. 何を見せるか（今の武器からの近さで決める）

| 近さ | 見せるもの |

| 次（1段先） | 今と同じ：名前、能力（上がる値、属性、特性）、条件の ✓/✗、鍵の素材を落とす敵 |
