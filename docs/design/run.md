# 設計書：周回・画面の移り変わり・セーブ

今の周回（戦闘と育成をくり返す流れ）と、その状態の持ち方、セーブ。数値の正は `src/data`。

## 1. 物語の形：章 → 区画 → 戦闘

- データは `src/data/story.ts` の `STORY`。今は試作の1章（id `prototype`）・1区画（id `trial`）に5戦（`CAMPAIGN`、id `battle1`〜`battle5`）だけ
- 章・区画・戦闘には変わらない名前（id）を付ける。セーブはこの名前で場所を覚える（名前を変えても id は変えない。並べ替えても壊れない）
- 戦闘ごとに持つもの：敵、勝った時の星の砂、通常アイテム、ギアの報酬の候補、ボスかどうか（`src/data/campaign.ts`）
- 今の5戦

| 戦闘 | 敵 | ねらい |
| --- | --- | --- |
| 1 | スライム×2 | 弱点と延長を覚える |
| 2 | スライム、フロストバット | |
| 3 | スライム、フロストバット、アーマードッグ | |
| 4 | 同じ3体の強化版（HP・攻撃・魔力 ×1.3。鋼の爪も落とす） | |
| 5 | ボス「歪みの獣」 | 部位破壊と大技 |

## 2. 進み具合

- 周回の状態（`run.progress`）は「章・区画・区画の中の何戦目・何日目」。ロジックは `src/core/progress.ts`
- 何日目は1から始まり、今は増えない（M2 で「1日＝昼の日常1枠＋夜の潜入1枠」を入れる時に進める。`docs/CONCEPT.md`）
- 勝った後の出来事は4つ：同じ区画の次の戦闘へ／次の区画へ／次の章へ／最後まで終わった。戦闘のない区画は飛ばす。今は1区画なので、ボスに勝つと「最後まで終わった」
- 「次の区画へ」「次の章へ」の時の画面は、今は次の戦闘と同じ（星図に戻るだけ）。M1 以降で作る
- 戦闘のシードは「周回のシード＋最初から数えて何戦目か」。周回のシードは、始めるたび・やり直すたびに新しくする（URL の `?seed=数字` やデバッグメニューで固定している時は変えない）

## 3. 画面の移り変わり

タイトル →「はじめる」→ 星図（ムーブメント・武器）→「戦闘Nへ」→ 戦闘 → 勝利 →「星図へ」→ … → ボス → 結果画面 → タイトル

- 勝利の表示：星の砂 +N（合計）、素材・アイテム、武器のレベルアップ、ギアを選べるか、次の戦闘の名前。ボスは報酬なし
- ギアの報酬は、星図を開いた時に選ぶ（まだ受け取っていない報酬は、勝った戦闘の id で覚える）
- 負けた時の結果画面：「この戦闘からやり直す」（育成はそのまま、新しいシード）／「最初から」（育成もリセット）／「タイトルへ」
- 最後まで終わった時の結果画面：「クリア！」と、壊した部位・手に入るはずの素材とギア（表示のみ）、「タイトルへ」

## 4. セーブと中断・再開

- 戦闘の外（星図・ムーブメント・武器）を自動でセーブする。戦闘の途中で閉じた時は、その戦闘の前（星図）から再開する。戦闘中のセーブは M2 で作る
- セーブは1つだけ（自動のセーブ）。保存するもの：版の番号、保存した日時、シード（固定中か）、進み具合、星図、ムーブメント、まだ受け取っていない報酬、武器・素材・欠片
- いつ保存するか：星図・ムーブメント・武器の画面を描き直す時（中身が前と同じなら書き込まない）、勝って報酬を受け取った時、ブラウザが裏に回った時。最後まで終わったらセーブを消す
- タイトル：セーブがあれば「つづきから」（下に「戦闘3の前（3/5）」と保存した日時）と、2回押しの「はじめから」。読めないセーブは消さずに別の場所へ移し、「セーブを読めませんでした」と出す。URL の `?seed=` は、つづきからでも優先する
- **データの形が変わっても読めるように**：版の番号（今は2）が古いセーブは、移行の手順を順に通して今の版に直してから読む。今より新しい版は読まない。読む時に、今のデータにない名前（星図のマス、ギア、素材・アイテム、欠片、武器、進化先、章・区画・戦闘）は捨てるか最初の場所に置き換え、足りないキャラや武器は初めの状態で補い、ギアは今の盤に置き直す（置けないものは外す）
- **セーブの形を変える時の手順**：`SAVE_VERSION` を1上げ、`MIGRATIONS[古い版]` に直す手順を足し、古い版のセーブを読むテストを足す
- 保存の窓口は `src/save/storage.ts` の1か所（今は localStorage）。アプリにする時は、ここだけ差し替える。保存できない時も遊びは止めない
- ロジックは `src/core/save.ts`、周回との橋渡しは `src/scenes/run.ts`
