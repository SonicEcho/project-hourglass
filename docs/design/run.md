# 設計書：物語の流れ・周回・画面の移り変わり・セーブ

物語の流れ（段階23。プロローグから「つづく」まで）、戦闘と育成をくり返す周回、その状態の持ち方、セーブ。数値の正は `src/data`。

## 0. 物語の流れ：章 → 出来事（段階23）

- データは `src/data/story.ts` の `SLICE_FLOW`（名前は M1 のスライスの時のまま。段階34から2章の終わりまで）。章（プロローグ、第1章、第2章）ごとに、出来事を順に並べる。ロジックは `src/core/flow.ts`、画面は `src/scenes/FlowScene.ts`
- 出来事には変わらない名前（id）を付け、セーブはこの名前で覚える。会話の出来事の id は、台本（`src/data/scriptM1.ts`・`scriptM2.ts`）の場面の id と同じ
- 出来事の種類

| 種類 | 画面 | 今の中身 |
| --- | --- | --- |
| 会話（dialogue） | 会話の画面（`docs/design/dialogue.md`） | 台本の場面1つ。続く会話の出来事は、会話の画面1回で続けて読む |
| 日が変わる（day） | 黒い画面に「2日目」。タップで次へ | 何日目かを決める |
| 昼の日常（daily） | 日常の画面（`docs/design/daily.md`） | 場所を選び、印をタップして場面を見る。プロローグの屋台めぐりも |
| 探索（explore） | 探索の画面（`docs/design/explore.md`） | 区画（`area`）を歩く。途中の会話は区画のきっかけから出す |
| 時間を返す（return） | 返す画面（`docs/design/return.md`） | 集めたコマで、盗まれた時間を持ち主に返す（段階28） |
| 物語の戦闘（battle） | 戦闘の画面 | 区画の戦闘（`battle`。`AREA_BATTLES` の id）を、探索の外で戦う。勝ち負けにかかわらず次の出来事へ。前の区画の探索の状態は片付ける（段階40。2-3 の返す直前のカイの負け戦） |
| つづく（end） | 「つづく」と「タイトルへ」 | 流れの終わり（段階34から2章の終わり。id `ch2_end`）。試遊の版のお礼の文もここ。セーブはここに残る |

- 仮の画面（段階34で、会話・昼の日常にも広げた）：まだ中身のない出来事は、仮の画面でつないで通しで遊べる状態を保つ。案内（`note`）を書いた出来事と、区画（`area`）のない探索・時間を返す（`isPlaceholder`。段階36から、仮の探索・時間を返すにも区画の id を書く。返した翌日の場面を出すため。`docs/design/daily.md` の 5.）。中身を作る段階で、台本や区画を入れて案内を消す。仮の会話の手前で、会話をまとめて読むのは止める
- 仮の画面の中身：章・何日目、種類（「会話（仮）」「昼の日常（仮）」「探索（仮）」「時間を返す（仮）」）、出来事の名前、何をする所かとどの段階で作るかの案内、「次へ」、左上の「タイトル」
- 段階40で、2章の終わりまで仮の画面がなくなった（2-3 は返す出来事の代わりに、カイの負け戦の会話 → 物語の戦闘 → 持ち去られる会話）
- 今の流れ（段階34）：プロローグ → 1章（1日目・2日目は中身あり。3日目・4日目は仮の画面。2日目の終わりは「2日目　おわり」、4日目の終わりで「第1章　おわり」）→ 2章の扉（台本）→ 5日目〜8日目（仮の画面）→ つづく。出来事の一覧は `docs/milestones/M2.md` の段階34の詳細。2章のパーティは段階38までは1章のまま
- **今どこか**：周回の状態の `run.event`（今の出来事の id）。会話の場面を読み始めるたびに、その場面の出来事へ移してセーブする（閉じても、読んでいた場面の最初から続く）。出来事を終えた画面は、流れの画面へ `done` を付けて戻り、次の出来事へ進む
- **何日目**：出来事の並びで決まる（その出来事より前で最後に日が変わった日）。`run.progress.day` も、出来事が変わるたびにそろえる
- **覚えた値**：会話の `@set`（プロローグの景品、金魚の名前）は `run.vars` に入れてセーブし、後の会話に渡す
- デバッグメニュー：「次の出来事へ飛ばす」「↑ の出来事へ飛ぶ」「試作の5戦を最初から」

## 2. 進み具合

- 周回の状態（`run.progress`）は「章・区画・区画の中の何戦目・何日目」。ロジックは `src/core/progress.ts`
- 何日目は1から始まり、物語の流れの「日が変わる」出来事で進む（段階23。上の 0.）
- 勝った後の出来事は4つ：同じ区画の次の戦闘へ／次の区画へ／次の章へ／最後まで終わった。戦闘のない区画は飛ばす。今は1区画なので、ボスに勝つと「最後まで終わった」
- 「次の区画へ」「次の章へ」の時の画面は、今は次の戦闘と同じ（星図に戻るだけ）。M1 以降で作る
- 戦闘のシードは「周回のシード＋最初から数えて何戦目か」。周回のシードは、始めるたび・やり直すたびに新しくする（URL の `?seed=数字` やデバッグメニューで固定している時は変えない）

## 3. 画面の移り変わり

起動（素材の読み込み）→ タイトル →「はじめる」→ 物語の流れ（会話・日常・探索 ⇄ 戦闘・仮の画面・日の扉…）→「つづく」→ タイトル

試作の5戦（デバッグメニューの「試作の5戦を最初から」）：星図（ムーブメント・武器）→「戦闘Nへ」→ 戦闘 → 勝利 →「星図へ」→ … → ボス → 結果画面 → タイトル。探索の戦闘は、同じ戦闘の画面を「探索から来た戦闘」として使う（`docs/design/explore.md` の 3.）。探索のチェックポイントから育成の画面（星図・武器）を開くと、星図の下のボタンが「探索へ戻る」になる（段階26。戻り先はセーブしない。`src/scenes/run.ts` の `setHubReturn`）

- タイトルから物語の流れへ移る時は、余韻を入れる（段階32b 調整5）：押したボタン以外は押せなくなり、ボタンと小さな文字が消え、砂時計の砂が強く流れて光が明るくなり、砂の音がする（BGM は止めない）。暗転して一呼吸おいてから次の画面（約2.5秒）。会話の途中から続く時は、会話の画面を明転で始める
- タイトルの右上の「オプション」に、音の設定（BGM・効果音・文字の音・出力先）と「説明を読む」「遊んだ記録」「クレジット」をまとめる（段階32b 調整3。前は4つのボタンが並んでいた）。スマホは最初に画面に触れるまで音を出せないので、それまでタイトルに「画面をタップすると音が出ます」と出す
- オプションの「クレジット」で、素材とライブラリの一覧（素材台帳から作る）。`?debug=1` の時は各素材に「仮／本番」と入手元も出す
- 勝利の表示：星の砂 +N（合計）、素材・アイテム、武器のレベルアップ、ギアを選べるか、次の戦闘の名前。ボスは報酬なし
- ギアの報酬は、星図を開いた時に選ぶ（まだ受け取っていない報酬は、勝った戦闘の id で覚える）
- 負けた時の結果画面：「この戦闘からやり直す」（育成はそのまま、新しいシード）／「最初から」（育成もリセット）／「タイトルへ」
- 最後まで終わった時の結果画面：「クリア！」と、壊した部位・手に入るはずの素材とギア（表示のみ）、「タイトルへ」

## 4. セーブと中断・再開

- 物語の流れ（出来事が変わった時、会話の場面を読み始めた時、覚えた値が変わった時）と、戦闘の外（星図・ムーブメント・武器）を自動でセーブする。戦闘の途中で閉じた時は、「つづきから」で**その戦闘の始めから**続ける（段階44。戦闘を始めた時にセーブの `battle` に戦闘の id と勝った時・負けた時の行き先を書き、終わったら消す。途中の状態は残さず、シードは同じ。始めの HP・MP・つながりゲージ・ポーチは戦闘の前のまま。記憶をたどる戦闘と試作の5戦は書かない。デバッグで出来事へ飛ぶと消す）。タイトルの「つづきから」の下に「（砂嵐の途中）」のように出す
- セーブは1つだけ（自動のセーブ）。保存するもの：版の番号、保存した日時、シード（固定中か）、進み具合、星図、ムーブメント、まだ受け取っていない報酬、武器・素材・欠片、今の出来事、物語で覚えた値、探索の状態、章の中で引き継ぐつながりゲージ、返した時間、持っているスナップとアルバムの中身（段階41）
- いつ保存するか：星図・ムーブメント・武器の画面を描き直す時（中身が前と同じなら書き込まない）、勝って報酬を受け取った時、ブラウザが裏に回った時。最後まで終わったらセーブを消す
- タイトル：セーブがあれば「つづきから」（下に章と出来事の名前と、保存した日時）と、2回押しの「はじめから」。読めないセーブは消さずに別の場所へ移し、「セーブを読めませんでした」と出す。直す手順がない古い版（版1・2）は、壊れているのではないので、知らせずに消す。URL の `?seed=` は、つづきからでも優先する
- **データの形が変わっても読めるように**：版の番号（今は11）が古いセーブは、移行の手順を順に通して今の版に直してから読む。今より新しい版は読まない。読む時に、今のデータにない名前（星図のマス、ギア、素材・アイテム、欠片、武器、進化先、章・区画・戦闘）は捨てるか最初の場所に置き換え、足りないキャラや武器は初めの状態で補い、ギアは今の盤に置き直す（置けないものは外す）
- **セーブの形を変える時の手順**：`SAVE_VERSION` を1上げ、`MIGRATIONS[古い版]` に直す手順を足し、古い版のセーブを読むテストを足す
- 保存の窓口は `src/save/storage.ts` の1か所（今は localStorage）。アプリにする時は、ここだけ差し替える。保存できない時も遊びは止めない
- ロジックは `src/core/save.ts`、周回との橋渡しは `src/scenes/run.ts`

## 5. 遊んだ記録（段階32b）

試遊（`docs/milestones/M1.md` の「完成の基準」）で、どこに何分いたか・どこでやめたか・何回負けたかを知るための記録。遊ぶ人の端末に残し、画面で見せる（サーバーは使わない。遊んだ人にスクリーンショットを送ってもらう）

- 数えるもの：物語の出来事ごとに、いた時間と、探索の戦闘で勝った・負けた回数。ほかに、記録を始めた日時、「はじめから」を押した回数、一番先まで進んだ出来事、最後にいた出来事とその日時、「つづく」まで着いた回数
- 時間は、流れの画面から先（会話・日常・探索・戦闘・育成・返す画面）にいて、画面が表に出ていて、最後に触ってから3分以内の間だけ、5秒ごとに今の出来事へ足す。1回に足すのは15秒まで（端末が眠っていた間がまとめて入らないように）。タイトル・クレジット・記録の画面にいる間は数えない
- 出来事に入ったのは、流れの画面を開いた時と、今の出来事が変わった時（`run.ts` の `setEvent`・`advanceEvent`）。デバッグで飛んだ時も入ったことになる
- 保存はセーブとは別（`restopia.playlog`）。「はじめから」でも消えない。記録の画面の「記録を消す」（2回押し）で消す。読めない時は新しい記録にし、今の流れにない出来事は捨てる
- 記録の画面「遊んだ記録」：タイトルの右上の「オプション」の「遊んだ記録」と、「つづく」の画面の「遊んだ記録を見る」から開く。上にまとめ（遊んだ時間・負けた回数・はじめた回数・一番先・最後）、下に日ごと・区画ごとの表（段階34。流れの順に、プロローグ・1日目…の行と、その日の探索の区画の行を字下げして並べる。晩に分けた区画は、2晩目・3晩目の時間と勝ち負けを1晩目の行に足して1行にする（段階78）。日の行は、その日の探索以外の出来事を合わせた時間。まだ着いていない行は暗く、最後にいた出来事を含む行に印）。1画面に全部入れる。記録そのものは、今までどおり出来事ごとに持つ（`playLogSections` は画面に出す時にまとめるだけ）
- ロジックは `src/core/playlog.ts`、時間を数える窓口は `src/scenes/playRecord.ts`、画面は `src/scenes/PlayLogScene.ts`
