# 設計書：物語の流れ・周回・画面の移り変わり・セーブ

物語の流れ（段階23。プロローグから「つづく」まで）、戦闘と育成をくり返す周回、その状態の持ち方、セーブ。数値の正は `src/data`。

## 0. 物語の流れ：章 → 出来事（段階23）

- データは `src/data/story.ts` の `SLICE_FLOW`（M1 のスライス）。章（プロローグ、第1章）ごとに、出来事を順に並べる。ロジックは `src/core/flow.ts`、画面は `src/scenes/FlowScene.ts`
- 出来事には変わらない名前（id）を付け、セーブはこの名前で覚える。会話の出来事の id は、台本（`src/data/scriptM1.ts`）の場面の id と同じ
- 出来事の種類

| 種類 | 画面 | 今の中身 |
| --- | --- | --- |
| 会話（dialogue） | 会話の画面（`docs/design/dialogue.md`） | 台本の場面1つ。続く会話の出来事は、会話の画面1回で続けて読む |
| 日が変わる（day） | 黒い画面に「2日目」。タップで次へ | 何日目かを決める |
| 昼の日常（daily） | 日常の画面（`docs/design/daily.md`） | 場所を選び、印をタップして場面を見る。プロローグの屋台めぐりも |
| 探索（explore） | 探索の画面（`docs/design/explore.md`） | 区画（`area`）を歩く。途中の会話は区画のきっかけから出す |
| 時間を返す（return） | 仮の画面 | 段階28で作る |
| つづく（end） | 「つづく」と「タイトルへ」 | スライスの終わり。セーブはここに残る |

- 仮の画面：章・何日目、種類（「探索（仮）」など）、出来事の名前、何を作るかの案内、「次へ」、左上の「タイトル」
- **今どこか**：周回の状態の `run.event`（今の出来事の id）。会話の場面を読み始めるたびに、その場面の出来事へ移してセーブする（閉じても、読んでいた場面の最初から続く）。出来事を終えた画面は、流れの画面へ `done` を付けて戻り、次の出来事へ進む
- **何日目**：出来事の並びで決まる（その出来事より前で最後に日が変わった日）。`run.progress.day` も、出来事が変わるたびにそろえる
- **覚えた値**：会話の `@set`（プロローグの景品、金魚の名前）は `run.vars` に入れてセーブし、後の会話に渡す
- デバッグメニュー：「次の出来事へ飛ばす」「↑ の出来事へ飛ぶ」「試作の5戦を最初から」

## 1. 物語の形：章 → 区画 → 戦闘

- データは `src/data/story.ts` の `STORY`。今は試作の1章（id `prototype`）・1区画（id `trial`）に5戦（`CAMPAIGN`、id `battle1`〜`battle5`）だけ
- 章・区画・戦闘には変わらない名前（id）を付ける。セーブはこの名前で場所を覚える（名前を変えても id は変えない。並べ替えても壊れない）
- 戦闘ごとに持つもの：敵、勝った時の星の砂、通常アイテム、ギアの報酬の候補、ボスかどうか（`src/data/campaign.ts`）

| 2 | スライム、フロストバット | |

## 2. 進み具合

- 周回の状態（`run.progress`）は「章・区画・区画の中の何戦目・何日目」。ロジックは `src/core/progress.ts`
- 何日目は1から始まり、物語の流れの「日が変わる」出来事で進む（段階23。上の 0.）
- 勝った後の出来事は4つ：同じ区画の次の戦闘へ／次の区画へ／次の章へ／最後まで終わった。戦闘のない区画は飛ばす。今は1区画なので、ボスに勝つと「最後まで終わった」
- 「次の区画へ」「次の章へ」の時の画面は、今は次の戦闘と同じ（星図に戻るだけ）。M1 以降で作る
- 戦闘のシードは「周回のシード＋最初から数えて何戦目か」。周回のシードは、始めるたび・やり直すたびに新しくする（URL の `?seed=数字` やデバッグメニューで固定している時は変えない）

## 3. 画面の移り変わり

起動（素材の読み込み）→ タイトル →「はじめる」→ 物語の流れ（会話・日常・探索 ⇄ 戦闘・仮の画面・日の扉…）→「つづく」→ タイトル

試作の5戦（デバッグメニューの「試作の5戦を最初から」）：星図（ムーブメント・武器）→「戦闘Nへ」→ 戦闘 → 勝利 →「星図へ」→ … → ボス → 結果画面 → タイトル。探索の戦闘は、同じ戦闘の画面を「探索から来た戦闘」として使う（`docs/design/explore.md` の 3.）。探索のチェックポイントから育成の画面（星図・武器）を開くと、星図の下のボタンが「探索へ戻る」になる（段階26。戻り先はセーブしない。`src/scenes/run.ts` の `setHubReturn`）

- タイトルの右上の「クレジット」で、素材とライブラリの一覧（素材台帳から作る）。`?debug=1` の時は各素材に「仮／本番」と入手元も出す
- 勝利の表示：星の砂 +N（合計）、素材・アイテム、武器のレベルアップ、ギアを選べるか、次の戦闘の名前。ボスは報酬なし
- ギアの報酬は、星図を開いた時に選ぶ（まだ受け取っていない報酬は、勝った戦闘の id で覚える）
- 負けた時の結果画面：「この戦闘からやり直す」（育成はそのまま、新しいシード）／「最初から」（育成もリセット）／「タイトルへ」
- 最後まで終わった時の結果画面：「クリア！」と、壊した部位・手に入るはずの素材とギア（表示のみ）、「タイトルへ」

## 4. セーブと中断・再開

- 物語の流れ（出来事が変わった時、会話の場面を読み始めた時、覚えた値が変わった時）と、戦闘の外（星図・ムーブメント・武器）を自動でセーブする。戦闘の途中で閉じた時は、その戦闘の前（星図）から再開する。戦闘中のセーブは M2 で作る
- セーブは1つだけ（自動のセーブ）。保存するもの：版の番号、保存した日時、シード（固定中か）、進み具合、星図、ムーブメント、まだ受け取っていない報酬、武器・素材・欠片、今の出来事、物語で覚えた値、探索の状態、章の中で引き継ぐつながりゲージ
- いつ保存するか：星図・ムーブメント・武器の画面を描き直す時（中身が前と同じなら書き込まない）、勝って報酬を受け取った時、ブラウザが裏に回った時。最後まで終わったらセーブを消す
- タイトル：セーブがあれば「つづきから」（下に章と出来事の名前と、保存した日時）と、2回押しの「はじめから」。読めないセーブは消さずに別の場所へ移し、「セーブを読めませんでした」と出す。直す手順がない古い版（版1・2）は、壊れているのではないので、知らせずに消す。URL の `?seed=` は、つづきからでも優先する
- **データの形が変わっても読めるように**：版の番号（今は5）が古いセーブは、移行の手順を順に通して今の版に直してから読む。今より新しい版は読まない。読む時に、今のデータにない名前（星図のマス、ギア、素材・アイテム、欠片、武器、進化先、章・区画・戦闘）は捨てるか最初の場所に置き換え、足りないキャラや武器は初めの状態で補い、ギアは今の盤に置き直す（置けないものは外す）
- **セーブの形を変える時の手順**：`SAVE_VERSION` を1上げ、`MIGRATIONS[古い版]` に直す手順を足し、古い版のセーブを読むテストを足す
- 保存の窓口は `src/save/storage.ts` の1か所（今は localStorage）。アプリにする時は、ここだけ差し替える。保存できない時も遊びは止めない
- ロジックは `src/core/save.ts`、周回との橋渡しは `src/scenes/run.ts`

| 版 | 段階 | 中身 |
| --- | --- | --- |
| 1 | 段階11 | 何戦目か（`stage`）、報酬は戦闘の番号 |
| 2 | 段階13 | 進み具合（章・区画・何戦目・何日目）、報酬は戦闘の id。版1の `stage` は試作の章・区画のその番号に、報酬の番号 n は `battle{n+1}` に直していた |
| 3 | 段階23 | 今の出来事（`event`）と、物語で覚えた値（`vars`）。版1・2は引き継がない（直す手順を置かない） |
| 4 | 段階25 | 探索の状態（`explore`）。版3は探索の途中ではないもの（`null`）として直す |
| 5 | 段階26の調整3 | 章の中で引き継ぐ連携技のつながりゲージ（`linkGauge`：章の id と量）。版4はゲージなし（`null`）として直す。今の流れにない章のものは捨て、量は0〜100におさめる |

## 決定の記録

- 段階13：「何戦目か」だけだった周回の状態を、章・区画・何戦目・何日目にした（M1 から物語・探索・日常が入るため）
- 2026-10-08 段階23：物語の流れ（章 → 出来事）を足した。今の出来事は、戦闘の場所（`progress`）とは別に `run.event` で持つ（戦闘の場所は試作の5戦と段階25の探索で使うため、形を変えずに残した）。何日目は出来事から決めて `progress.day` とそろえる。会話は場面ごとに出来事にした（閉じても読んでいた場面から続くように）。版1・2のセーブは、開発者と決めたとおり引き継がない
- 2026-10-08 段階23：試作の5戦の最後（ボス）に勝つとセーブを消す仕組みはそのまま。デバッグで試作の5戦を遊ぶと、物語の進み具合もリセットされる（「試作の5戦を最初から」が最初からやり直すため）
