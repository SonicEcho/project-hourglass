# 設計書の一覧と、文書の決まり

段階14（2026-10-07）で、試作の仕様書（`docs/SPEC.md`）を、今の仕組みを書いた「設計書」と、作業の一覧に分けた。

## 文書の役割

| 文書 | 役割 | 書き換えるか |
| --- | --- | --- |
| `docs/design/battle.md` | 戦闘のルール | 今の仕組みに合わせて上書きする |
| `docs/design/growth.md` | 育成（星図・ムーブメント・武器） | 同上 |
| `docs/design/run.md` | 物語の流れ・周回・画面の移り変わり・セーブ | 同上 |
| `docs/design/tech.md` | 技術・テスト・自動対戦の測定・デバッグ・公開 | 同上 |
| `docs/design/dialogue.md` | 会話の画面と、台本の書き方・進め方（段階22） | 同上 |
| `docs/design/daily.md` | 昼の日常（屋台めぐり）と、小さな遊び（射的・金魚すくい）（段階24） | 同上 |
| `docs/design/explore.md` | 探索（区画の地図、宝箱、敵の印、チェックポイント、戦闘とのつなぎ）（段階25） | 同上 |
| `docs/design/return.md` | コマ集めと、時間を返す（コマ、探索の画面の残り、返す画面、返した時間のセーブ）（段階28） | 同上 |
| `docs/design/tips.md` | 初めての人向けの説明（出す場面、覚え方、読み返し）（段階30） | 同上 |
| `docs/milestones/M0.md` など | マイルストーンごとの作業の一覧（段階ごとの依頼内容と、スマホで確かめること）、完成の基準 | 段階を足す・進み具合を書く |
| `docs/ROADMAP.md` | マイルストーン全体の道のり | 方針が変わった時 |
| `docs/CONCEPT.md` | ゲーム全体の構想ノート（背景）。ここにあって設計書にない要素は、まだ作らない | 構想が変わった時 |
| `docs/STORY.md`・`docs/NAMING.md` | 物語、名前と用語 | 決まった時 |
| `docs/data/` | データの一覧表（キャラ・敵・スナップ・ギア・武器など）。`src/data` から自動で作る。手で書き換えない | `npm run data:tables` で作り直す |
| `docs/ART.md` | 絵と音の方向性（絵柄、探索の形、色の決まり、AI の画像サービス、絵柄の指示文） | 決まった時 |
| `docs/ASSETS.md` | 絵・音の素材を手に入れる時の決まりと、素材台帳（`src/data/assets.ts`）の書き方 | 決まりが変わった時 |
| `docs/HANDOFF.md` | 新しいセッションへの引き継ぎメモ（最初に読む）。今の状態と次の作業だけを短く | 作業のたび（短く保つ） |
| `docs/HISTORY.md` | 段階ごとの歩みと、以前に挙がった候補の記録（経緯を調べる時だけ読む） | 段階をマージしたら1行足す |
| `docs/SPEC.md` | 試作（段階1〜14）の記録。段階ごとの経緯と、当時の決定 | 書き足さない |

探索・物語・時間を返す仕組みなどの設計書は、その仕組みを作る時（M1 以降）に足す。

## 書き方の決まり

- **設計書には「今の仕組み」だけを書く**。仕組みを変えたら本文を上書きし、なぜ変えたかは、その設計書の最後の「決定の記録」に、日付・段階・理由を1〜2行で残す
- **数値の正は `src/data`**。数値を表で見たい時は `docs/data/` の一覧表（自動で作る）を見る。設計書には、ルールに関わる数値（手札5枚、弱点1.5倍など）と目安（勝率など）だけを書き、キャラ・スナップ・敵ごとの細かい数値の表は写さない（二重に書くと食い違うため）。代わりに、どのファイルにあるかを書く
- **用語とキャラ名は `docs/NAMING.md`・`docs/CONCEPT.md` に合わせる**（ハルト、星図、星の砂、ムーブメント、ブリッジ、狂い、ギア、スナップ、アルバム、延長、記憶の欠片、時分解）。コードの識別子は古いまま（`navi`、`card`、`fragment`、`oneMore` など）で、対応は `docs/SPEC.md` の段階10の表
- **段階の番号は続けて使う**。段階は、そのマイルストーンの文書に「依頼する内容」と「スマホで確かめること」を書いてから作る
- 仕様と違う判断をした時や、書かれていないことを決めた時は、関係する設計書に書き足す
