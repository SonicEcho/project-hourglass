# 設計書：戦闘

今の戦闘のルール。数値の正は `src/data`（ルールの数値は `src/data/constants.ts`）。この文書の数値は、ルールに関わるものと目安だけ。ロジックは `src/core/battle.ts` ほか（Phaser を読み込まない）。

## 1. ラウンドの流れ

1. **計画**：ラウンドの始めに手札を5枚まで補充する。生きている仲間全員の行動を1人ずつ選ぶ（選ぶと次の仲間へ。仲間の枠をタップすれば選び直せる）。全員選んだら「実行」
2. **実行**：仲間と敵の行動を、「行動の速さ」の高い順に1つずつ実行する
3. **ラウンドの終わり**：防御が解ける。次のラウンドへ

- 1人が1ラウンドに行うのは、スナップ1枚、コンボ1つ、魔法・スキル1つ、基本行動（通常攻撃・防御）のどれか1つ。連携技は2人分の行動を使う
- **行動の速さ = 速さ ÷ 行動の重さ**。重い行動ほど後回し。敵の行動の重さは1.0。同じ値なら仲間が先、その次は速さの高い順
- 防御は行動の速さに関係なく、ラウンドの最初に効く。先制（クイックステップ・スタートダッシュ）はその次（先制が複数あれば行動の速さ順）
- 単体攻撃の対象が自分の番までに倒れていたら、残っている敵に自動で向け直す。回復の対象が倒れていたら何も起きない
- 自分の番の前にHPが0になった仲間の行動は取り消し。確保していたスナップは手札に残る
- 戦闘の局面（`phase`）：plan（計画）／execute（実行）／extra（追加行動を選ぶ）／ended（勝敗がついた）

## 2. 手札とアルバム

- パーティ共通の山札（アルバム、20枚）を戦闘の始めにシャッフルする。中身は `src/data/cards.ts`
- ラウンドの始めに手札を5枚まで補充する。使わなかったスナップは残る（取捨選択とコンボ集めのため）。手札の上限はない（ドローなどで5枚を超えてよい）
- 計画でスナップを割り当てると「確保」され、他の仲間には使えない（画面に「○○が使う」）。実行した時に捨て札へ
- 山札が尽きたら捨て札をシャッフルして山札に戻す。両方空なら引ける分だけ引く
- スナップはMP不要。使用者の能力値で計算する

## 3. コンボ

手札に決まった組み合わせがそろうと、1人の行動としてまとめて使える大技。材料はすべてその仲間に割り当てられ、使うと捨て札へ。MP不要、バトンの倍率も乗る。定義は `src/data/combos.ts`。

| コンボ | 材料 | 効果の要点 |
| --- | --- | --- |
| エレメントバースト | ファイアチップ＋アイスチップ＋サンダーチップ | 敵全体。敵ごとに一番効く属性を自動で選ぶ |
| トリプルソード | ソード×3 | 敵単体に3回。耐性を無視 |
| ブレイククラッシュ | ブレイクアーム×2 | 敵単体。部位へのダメージ3倍 |
| ヒールサークル | リカバー×2 | 味方全体を回復 |

- 連続攻撃の途中で敵が倒れたら残りは当たらない。途中で部位が壊れたら残りは本体に当たる

## 4. 魔法・スキルと基本行動

- 魔法・スキルはキャラ固有で、MPを払えば使える（`src/data/skills.ts`）。星図で増える（`growth.md`）
- 基本行動：通常攻撃（物理・重さ1.0。武器の進化で属性が付くことがあり、その時は魔力で計算）、防御（そのラウンドの間、受けるダメージ半分。ラウンドの最初に効く）

## 5. ダメージと回復

```
ダメージ = 威力 × (物理なら攻撃 / 属性・魔法なら魔力) ÷ 対象の防御 × 乱数(0.9〜1.1) × 相性 × その他の倍率
相性：弱点 1.5 ／ 通常 1.0 ／ 耐性 0.5
回復量 = 威力 × 魔力 ÷ 20（乱数なし。最大HPを超えない。HPが0の仲間は回復できない）
```

- 属性は物理・火・氷・雷。ボスの「歪みの咆哮」は属性のない魔法（魔力で計算し、相性の影響を受けない）
- 倍率（相性、バトン、防御、キャラの特性）はすべて掛けてから最後に切り捨てる。最低1ダメージ
- プレビューでは、まだ判明していない弱点は通常として計算する（耐性はそのまま）

## 6. 弱点・ダウン・延長・バトンタッチ

- 弱点を突くと、ダウンしていない敵をダウンさせる。弱点を突いて倒した敵はダウンしない
- **割り込み**：ダウンした敵は次に来る自分の行動を立ち上がりに使い、行動しない。まだ動いていない敵をダウンさせれば、そのラウンドは行動できない
- **ダウンの歯止め**：立ち上がった敵は、次に自分が行動するまでダウンしない
- **延長（Extend!）**：敵をダウンさせた仲間は、その場で1枚引いてから、もう1回行動を選べる（追加行動）。まだ割り当てていない手札やコンボも使える。1回の行動で何体ダウンさせても延長は1回。追加行動は見送ってもよい
- **連鎖**：追加行動で、まだダウンしていない別の敵をダウンさせると、さらに延長
- **バトンタッチ**：延長の代わりに選べる。自分以外の生きている仲間が、その場で追加行動を選ぶ。受けた仲間の追加行動はダメージ・回復量が1.25倍（その1回で使い切る）。同じ連鎖の中で、渡してきた仲間には渡し返せない
- 追加行動は選んだらすぐ実行する（行動の速さは関係ない）。計画していた本来の行動は、そのまま後で行う
- 見つけた弱点は、敵の上にアイコンで常に表示する（一度突くか、部位破壊で露出すると判明）

## 7. 連携技

2人の行動をまとめて使う大技。発動する時の爽快感を大事にするため、強くして、使える回数を「つながりゲージ」でしぼる（段階26の調整2。開発者が案Aを選んだ）。定義は `src/data/links.ts`、ゲージの数値は `src/data/constants.ts` の `LINK_GAUGE_*`。

| 連携技 | 2人 | 効果 |
| --- | --- | --- |
| アフターグロウ | ハルト・あかり（1章から） | 敵全体に、敵ごとに火か氷の効く方で威力70（弱点があれば弱点を突く。耐性無視。ダウン中の敵には2倍）。その後、味方全体を回復（威力25） |
| クロスドライブ | ハルト・みお | 敵全体に物理・威力80（耐性無視。ダウン中の敵には2倍）。その後、手札を2枚引く |

- **つながりゲージ**（パーティで1本。0〜100）：仲間が弱点を突く（1体ごとに +12）、敵をダウンさせる（+10）、バトンタッチ（+10）、部位を壊す（+20）、仲間が敵の攻撃を受ける（1人ごとに +4）で貯まる。連携技そのものでは貯まらない
- **章の中で引き継ぐ**（段階26の調整3）：探索から来た戦闘は、前の戦闘で残ったゲージから始まり、勝てば残りを次へ持ち越す。負けた時は戦う前の量に戻る。章が変わると0に戻る（区画を出ても0にしない。それまでの頑張りが無駄にならないように）。セーブに残る（`run.linkGauge`。版5）。試作の5戦は戦闘ごとに0から
- ゲージが満タンの時だけ、計画で選べる（1ラウンドに1つ）。使うとゲージは0に戻る。満タンになると「連携技 READY!」と出る。探索の画面の上にも「連携技：つながり ◯%」と出す
- 目安：1-1 の雑魚戦4つで、撃てる時に撃つと約1.2回。温存すれば、ボス戦を満タンで始められる（「雑魚戦で使うか、ボスまで取っておくか」を選べる）。ボス戦の中で新しく満タンになるのは、多くて1回ほど（自動対戦で、弱点と角を狙う方針の測定）
- **体勢が崩れた敵には2倍**（`downBonus`）・**必ず最初に動く**（段階26の調整4・5）：連携技はラウンドの最初（防御の次）に動く。体勢が崩れた敵（ダウン中か、立ち上がったばかりでまだ行動していない敵。`isOffBalance`）には2倍で当たる
  - 狙い方：敵をダウンさせた次のラウンドに連携技を計画する。先にダウンさせた敵は、そのラウンドの番で立ち上がるが、次のラウンドの始めは体勢が崩れたまま。連携技は敵が動く前に当たる（ボスも、怒って攻撃してくる前に当てられる）
  - 画面：立ち上がったばかりの敵に「体勢崩れ」と出す。ゲージが満タンで、計画の時に体勢が崩れた敵がいると「★ 連携技のチャンス！」と出す。プレビューは倍率を入れた数字
  - 目安（1-1 の仮のボス。HP840）：体勢が崩れていない時に撃つと1回約100〜150、崩れた体勢なら約200（HPの約25%）。ダウン中の倍率と威力は、勝率と爽快感を見て調整していく（開発者と決めた）
- 計画で2人分の行動を使って選ぶ（2人とも生きている時）。ダメージ・回復は2人の攻撃・魔力の平均で計算し、計画した1人目の特性を使う
- 組める連携技が2つある仲間（試作の5戦のハルト）は、「連携技」のボタンを押すたびに切り替わる
- 追加行動では使えない
- 画面：コマンドの「連携技」のボタンに「つながり ◯%」と、貯まった分だけ光る帯。満タンで技の名前が金色に光る。使う時は専用のカットイン（2人の名前の帯 → 技名 → 白く光る）
- デバッグメニュー：「つながりゲージを満タンにする」

## 8. サポートスナップ

- ドロー（2枚引く）・サーチ（山札の上から3枚を見て1枚を手札へ、残りは山札の一番下へ）・クイックステップ（仲間1人のこのラウンドの行動が先制になる）
- 計画の途中でその場で使い、すぐ効果が出る。誰の行動枠も使わない。1ラウンドにチーム全体で1枚まで。追加行動では使えない

## 9. 部位破壊と大技

- 部位を持つ敵（今はボスだけ）は、本体HPとは別に部位ごとのHPを持つ。単体攻撃は部位を狙える（全体攻撃は本体だけ）
- 部位を狙うと、部位に「ダメージ × 部位倍率（ブレイク系は2）」、本体に「ダメージ × 0.5」（相性は本体のもの）
- 部位HPが0で破壊。その部位を使う行動が封じられ、隠れた弱点が露出することがある。壊した部位は、その部位の素材を必ず落とす（段階27b。`growth.md` の 6-3）
- **大技（ため）**：大技を選んだ敵は、まず力をためる（そのラウンドは攻撃しない）。次の自分の行動で放つ。止め方：ダウンさせる／その大技が使う部位を壊す／防御でしのぐ。予告の案内には、その時に本当に使える止め方だけを出す
- **怒り**：ためをダウンで崩された敵は怒る。立ち上がった次の行動では、ためずにすぐ攻撃する（大技を選んでも、ためずに放つ）。立ち上がりの歯止めがあるので、その攻撃まではダウンしない。怒っている間は、予告の帯に「怒っている！」と出す（段階26の調整）
- 使える行動が1つも残っていない敵は何もしない

**1-1 の区画のボス「金魚鉢のぬし」**（段階27。`src/data/festivalEnemies.ts`）：部位破壊と大技の予告を、ここで覚えてもらう。最初は弱点がない。
- ポイの腕：壊すと「ポイすくい」（強い単体攻撃）を封じる
- 金魚鉢：壊すと「金魚の渦」（全体・大技）を封じ、弱点「氷」が露出する。ここから、あかりの氷でダウン → 次のラウンドの始めに連携技（体勢が崩れた敵に2倍）、の流れが作れる
- 大技「大波」（全体・物理）はどの部位も使わない。ためている間に、ダウンさせる（金魚鉢を壊した後）か防御でしのぐ
- 行動は使えるものからランダム、HPが半分を切ってからは2回に1回、全体攻撃を選ぶ。速さ9（ハルト12・あかり10より遅い）

**試作のボス「歪みの獣」**（試作の5戦。`src/data/enemies.ts`）：部位は右腕（壊すと叩きつけを封じる）と角（壊すと歪みの咆哮を封じ、弱点「雷」が露出）。大技は薙ぎ払い（全体・どの部位も使わない）と歪みの咆哮（全体・角）。行動は使えるものからランダム、HPが半分を切ってからは2回に1回、全体攻撃を選ぶ。

## 10. キャラの特性（育成からの効果）

戦闘ロジックは星図・ムーブメント・武器を知らない。育成の効果は、キャラの能力値と「キャラの特性」（`PassiveEffect`）として渡され、戦闘はそれを読む。同じ特性は足し算で重なる。

| 特性 | 効果 |
| --- | --- |
| 属性の割増し | その属性のダメージ +◯% |
| 部位の割増し | 部位へのダメージ +◯% |
| コンボの割増し | そのキャラが使うコンボのダメージ・回復量 +◯% |
| バトンの割増し | バトンを受けた時の倍率に足す |
| 延長で引く枚数 | 延長の時に引く枚数 +◯ |
| MP節約 | 魔法・スキルのMP消費 −◯（最低1） |
| スタートダッシュ | 1ラウンド目、そのキャラの行動が先制 |
| 再生 | ラウンドの始めに最大HPの◯%回復 |
| 狂い | ラウンドの始めに最大HPの◯%を失う（HPは1未満にならない） |

- ラウンドの始めの順番：狂いで減る → 再生で回復（1ラウンド目も）

## 10-2. 2人の時（段階26）

1章はハルトとあかりの2人で戦う（パーティは物語の章が決める。`growth.md` の 5.）。ルールは3人の時と同じで、次だけが変わる。

- 行動順と仲間の枠：いる2人だけ。枠は画面の幅を2等分して並べる（パーティの並びの順。1章はハルト → あかり）
- 連携技：組む全員がパーティにいるものだけ使える（`usableLinks`）。1章はアフターグロウ（ハルト・あかり）だけ。クロスドライブはハルトとみおなので出ない
- バトンタッチ：渡せる相手はもう1人だけ
- アルバム：3人の時と同じ20枚、手札も5枚まで。雷の魔法を持つ仲間はいないが、サンダーチップは誰でも使えるので、エレメントバーストも組める（2人だと1ラウンドの行動が少ないので、手札を選ぶ幅が広い方がよいと判断した。段階27の測定で見直す）
- 敗北：パーティの全員のHPが0

## 10-3. 敵の落とし物（段階27b）

- 倒した敵は素材を1つ落とす（表から確率で。体勢が崩れた敵を倒すと、珍しい素材とレアが出やすい）。部位を壊すと、その部位の素材を必ず。ボスは倒すと決まった素材を必ず。確率と素材は `growth.md` の 6-3・6-4、数値は `src/data/constants.ts` の `DROP_RATES`
- 落とし物はシード付きの乱数で決まる（同じシードなら同じ）。戦闘中、珍しい素材・部位の素材・レアが出ると敵の上に名前を出す。レアは「レア！」と効果音（仮に宝箱の音）。勝利の表示は、珍しい素材に ◆、レアに ★ を付け、レアがあれば「★ レア！」の帯

## 11. 勝敗

- 敵を全滅させると勝利。パーティの仲間（3人、1章は2人）のHPがすべて0で敗北。HPが0の仲間は行動を選べず、行動順から外れる（蘇生の手段は今はない）
- 戦闘の始めは、毎回HP・MPが全回復した状態
- 勝った後・負けた後の流れは `run.md`

## 12. 画面と操作（縦持ち 390×844）

上半分に「読む情報」、親指の届く下半分に「触る操作」を集める。

| 領域（上から） | 表示するもの |
| --- | --- |
| 行動順 | このラウンドの順番の顔アイコン。左上にラウンド数。未決定は薄い色と「?」、防御は「防」、先制は「先」、大技のためは「大技」。選んでいる行動での自分の予告位置は黄色い枠と「ここ」 |
| 敵と部位 | 敵（最大3体）とHPバー、判明した弱点、ダウン、ため。ボスは本体を大きく描き、下に部位のパネル |
| 状況・プレビュー | 誰を選んでいるか、予想ダメージ・回復量、WEAK／耐性、決め方 |
| 仲間（3人。1章は2人） | 名前、HP・MP、決めた行動（「▶ソード→スライム」） |
| コンボの帯と手札 | 使えるコンボ（金色）と「あと1枚」。手札5枚（名前、属性、重さ） |
| コマンド | 魔法・スキル、バトンタッチ、連携技、その他（通常攻撃・防御・追加行動を見送る） |
| 下のボタン | 選んでいる最中は「キャンセル／決定」、それ以外は「実行」 |

- 操作：行動を選ぶ → 対象をタップでプレビュー → 同じ対象をもう一度タップ（または「決定」）で決める → 次の仲間へ
- 重さは数値の代わりに「軽い／普通／重い／超重い」の4段階で見せる（区切りは `WEIGHT_LABELS`）
- 長押し（0.5秒）で詳細：スナップ、スキル、コンボの帯、敵、部位、行動順のアイコン、仲間の枠（育成の効果）、連携技のボタン
- 魔法・スキルの一覧は、3つまで1列、4つ以上は2列、6つを超えるとページ切り替え（`src/ui/skillLayout.ts`）
- 演出：行動名の帯 → 数値、WEAK!、DOWN、Extend!、BATON TOUCH!、COMBO!、部位破壊、撃破。演出中はどこをタップしても早送り
- タップできる部分は最低 44×44

## 13. 数値の目安

- 測り方は `npm run measure`（`tech.md` の「自動対戦の測定」）。試作の5戦の表と、1-1 の縁日の表（段階27）が出る
- **1-1 の縁日**（段階27。ハルトとあかり、出会う順に雑魚戦4つ → ボス。星図はでたらめ、素材は全部時分解して武器へ、つながりゲージは引き継ぐ）。2つの方針で測る
  - 弱点をねらう方針（弱点を突く、弱点が隠れた部位を先に壊す、ためには防御、連携技は体勢が崩れた敵がいる時）：雑魚戦はどれも1回目でほぼ100%・1.5〜3.5ラウンド（気持ちよく倒せる）、ボスは1回目で8〜9割・6〜7ラウンド・連携技1回ほど（考えれば勝てる）
  - ほぼでたらめな方針：雑魚戦の前半は約100%、3つ目は約9割、4つ目は7〜8割、ボスは1〜3割（考えないと負ける。チェックポイントからやり直せば、ほぼ全員がボスまで勝ち切れる）
  - 2026-10-09 の測定（段階27b の後、150回）：ねらう方針でボス 93%（6.2ラウンド）、でたらめな方針でボス 14%（やり直し込みで 93% が勝ち切る）。段階27 の時（ボス HP1800）から、武器の伸びが控えめになったぶん、ボスを HP1500・攻撃23・魔力21 に下げた
  - この目安は段階27で決めたたたき台。開発者が遊んだ手応えで見直す
- 試作の5戦（手をほぼでたらめに選ぶ）の1回目の勝率：戦闘1・2 は約100%、戦闘3 は約9割、戦闘4 は約7〜8割、ボスは約3割を目安にしてきた（2026-10-09 の測定ではボス 58%。試作なので調整しない）

## 決定の記録

試作（段階1〜13）の経緯は `docs/SPEC.md` の「実装時の決定事項」。段階14以降で戦闘のルールを変えたら、ここに日付・段階・理由を1〜2行で足す。

- 段階6：1人ずつ手番が回る CTB をやめて、ラウンド制にした（手札とコンボの組み立てを主役にするため）
- 段階5（調整3回目）：ボスの大技に「ため」を入れた（攻略の流れが成立していなかったため）
- 2026-10-09 段階26：1章は2人で戦う。連携技は組む仲間がそろっている時だけ出す。アルバムと手札の数は3人の時と同じにした（段階27で砂嵐とボスを測る時に見直す）
- 2026-10-09 段階26の調整：ためをダウンで崩された敵は、立ち上がった次の行動で、ためずに攻撃する（怒り）ようにした。開発者の確認で「ため → ダウン → 立ち上がり → またため」がくり返され、2ラウンドに1回弱点を突くだけでボスが何もできなかったため。自動対戦では、2人の仮のボス 42%→38%、試作の5戦のボス 35%
- 2026-10-09 段階26の調整2：連携技を、つながりゲージが満タンの時だけ使える大技にした（開発者の依頼「発動する時の爽快感を大事にしたい」。案A）。クロスドライブの威力を50→110にし、ダウン中の敵に1.5倍。1章で使えるよう、ハルトとあかりの「アフターグロウ」を足した。自動対戦（育成あり・手はほぼでたらめ）では、試作の5戦のボスが35%→59%（でたらめな手でも、連携技に2人分の行動を使わなくなったため）。2人で戦う仮のボスは38%
- 2026-10-09 段階26の調整3：つながりゲージを、章の中で戦闘をまたいで引き継ぐようにした（開発者の案。区画を出ても0にしない）。そのぶん貯まる量を減らした（弱点 20→12、ダウン 15→10、バトン 15→10、部位破壊 25→20、攻撃を受ける 5→4）。1-1 を通す自動対戦（弱点と角を狙う方針、150回）で、雑魚戦4つで撃てるのは約1.2回、温存すればボス戦を満タンで始められる。仮のボスの勝率は、温存しても 39%→41% ほど
- 2026-10-09 段階26の調整4：連携技は必ずラウンドの最初（防御の次）に動き、ダウン中の敵には2倍にした（開発者の案。「ダウンさせてから撃つ」を狙えるように。重い行動のままだと、撃つ頃には敵が立ち上がっていた）。威力は下げた（クロスドライブ 110→80、アフターグロウ 100→70）。1-1 を通す自動対戦（弱点と角を狙う方針）で、撃てる時に撃つと仮のボスの勝率 48%（撃たないと 39%）。仮のボスの弱点は角を壊して出る雷だけで、1章の2人はサンダーチップでしか突けないので、ボスをダウンさせる機会が少ない。段階27のボスは、2人で弱点を突ける作りにする
- 2026-10-09 段階26の調整5：連携技の2倍を「ダウン中」から「体勢が崩れた敵（ダウン中・立ち上がったばかりでまだ動いていない）」に広げた。開発者の確認で「★ 連携技のチャンス！」が出なかったため（1-1 の雑魚はこちらより遅く、先にダウンさせるとその番で立ち上がるので、次のラウンドの始めにダウン中の敵がほぼいなかった）。1-1 を通す自動対戦で、チャンスは1回の通しで約1回、狙って撃つと仮のボスの勝率 59%（撃たないと 39%、満タンですぐ撃つと 53%）
- 2026-10-09 段階27：1-1 の縁日の砂嵐4種（金魚・水風船・お面・わたあめノイズ）とボス「金魚鉢のぬし」を作った。弱点は2人が突ける火・氷・物理を中心にし（わたあめだけ雷）、ボスは金魚鉢を壊すと弱点（氷）が出る作りにした（ダウン → 連携技の流れのため）。数値は 13. の1-1 の測定で決めた（ボス HP1800（段階27b で1500）、社への道の砂嵐は ×1.2）
