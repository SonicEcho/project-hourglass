# 設計書：会話と台本

会話の画面と、台本の書き方・進め方（段階22）。物語の中身は `docs/STORY.md`、M1 の脚本は `docs/script/M1.md`。

## 1. 台本

- 台本は、脚本（`docs/script/M1.md`）とほぼ同じ書き方の文字で `src/data/scriptM1.ts` に書く。読み取りと進め方は `src/core/script.ts`（Phaser を読み込まない。テストは `tests/core/script.test.ts`）
- 1つの台本の文字に、場面（`# id 名前`）をいくつも書く。場面の id は、物語の流れのデータ（段階23）とデバッグメニューが使う
- 台詞を直す時は、脚本と台本の両方を直す

| 書き方 | 意味 |
| --- | --- |
| `あかり〔笑顔〕「……」` | 台詞と表情。表情を書かなければ前のまま |
| `担任（声）「……」` | 立ち絵を出さない人の台詞。`（電話）` は名前の札に「（電話）」を付ける。かっこの中は「声」「電話」だけ |
| `〈語り〉……` | 名前の札のない語りの文（砂が流れる。プロローグの語り。語り手はりく） |
| `〈地の文〉……` | ハルトの心の中の文 |
| `（ノート）……` | 紙や札に書いてある文。かっこの中は見出し |
| `@命令 引数` | 演出（下の表） |
| `? 選択肢の文 -> 行き先` | 選択肢。続けて書いた行が1つの選択肢になる |
| `* 行き先` / `-> 行き先` | 行き先の印 / そこへ飛ぶ |
| `@end` | 場面の終わり（書かなければ最後の行の後で終わる） |
| `// …` | メモ（読み飛ばす） |

| 演出 | 意味 |
| --- | --- |
| `@bg id` | 背景（`src/data/dialogue.ts` の `BACKDROPS`）。同じ絵を夜などに使い回す時は、`tint` で色をかける（時計屋の店内の夜など） |
| `@bgm 名前` / `@bgm stop` | BGM（`SCRIPT_BGM`。本番の曲ができるまで、仮の2曲で代わりに流す） |
| `@se 名前` | 効果音（`SCRIPT_SE`。`sand` は音のファイルを使わず、その場で作る砂の音） |
| `@cast 名前 …` | 画面に出す人（3人まで。`CAST`）。何も書かなければ全員下げる |
| `@fade out` / `in` / `white` | 暗転 / 明転 / 白く光る |
| `@shake` | 画面を揺らす |
| `@cg id` / `@cg off` | 1枚絵（`CGS`）。出している間は立ち絵を隠す |
| `@wait ミリ秒` | 待つ |
| `@set 名前 値` | 値を覚える（本文の `{名前}` に入る。覚えていなければ「？」） |
| `@caption 文` | 章の扉などの大きな文字 |
| `@logo 題名　副題` | 題字（段階32b 調整3。章の扉の「RESTOPIA　思い出だけの理想郷」）。金の線が左右へ伸び、題名の文字が広い字間から1つずつ寄ってきて光り、副題が出て、線から砂がこぼれる。演出の途中（1.8秒）はタップで先へ進めない |
| `@note 文` | まだ作っていない遊びの所の仮の案内（「開発メモ」の札で出す） |
| `@act 名前 動き` | 立ち絵の芝居（`ACTOR_MOTIONS`：hop 跳ねる、bounce 弾む、nod うなずく、shake 震える、sink 沈む、rise 戻る、step 前へ出る、sway 揺れる） |
| `@emote 名前 印` | 頭の上の感情のふきだし（`EMOTES`：！ ？ ！？ … ♪ 汗） |
| `@zoom 倍率` | 背景・立ち絵・1枚絵だけを、顔のあたりを中心に寄せる（本文の枠とボタンは動かさない）。`@zoom 1` で戻す。場所（背景）が替わると戻る |
| `@mono on` / `off` | 背景・立ち絵・1枚絵の色を抜く（時計が止まった時など） |
| `@noise ミリ秒` | すり切れた時間のノイズで、画面を少しの間乱す |
| `@game 名前 成功 失敗` | 小さな遊び（段階24。shooting 射的、goldfish 金魚すくい）。会話の画面の上半分に遊びを重ねて出し、成功なら「成功」、失敗なら「失敗」の行き先の印へ進む。遊び方は `docs/design/daily.md` の 3. |
| `@clock show 時:分` / `hide` / `tick` / `tick many` / `stop` | 時計（段階22 調整12）。show は時計の寄りを出し（立ち絵は隠す。秒針が止まっていなければ動かし始める）、hide で戻す。tick は秒針の音を鳴らし始め、寄りが出ていれば針も進める。many は店じゅうの時計（ずれた音を重ねる）。stop で止める（many の時は音が1つずつ消える）。秒針の音は音のファイルを使わず、その場で作る（`playTick`）。数値は `CLOCK` |

- 進め方：`runScript` が、次に止まる所（台詞・選択肢・終わり）と、その前の演出の命令をまとめて返す。`@set` と飛び先はその中で済ませる。選択肢は `chooseOption` で行き先へ。受け取った値は書き換えず、新しい値を返す
- 書き間違いは、読み取った時に「台本の◯行目」を付けて止める。テスト（`tests/dataRefs.test.ts`）が、行き先・人・表情・背景・1枚絵・音がそろっていること、本文が60文字までであること、どの台詞にも選択肢のどれかでたどり着けることを確かめる

## 2. 会話の画面（`src/scenes/DialogueScene.ts`）

- 上から、背景、立ち絵（下の端を本文の枠の上の辺にそろえる）、本文の枠。上の端に「戻る」「オプション」「オート」「早送り」「ログ」（オプションの窓は、タイトルと同じ部品 `src/ui/options.ts`。音量・文字の音・出力先）
- 立ち絵：話している人だけ明るく、ほかは暗くする（重なっても透けないよう、薄くするのではなく暗くする。段階18a）。声だけの台詞・ハルトの心の中の文の時は全員暗く、語りの文の時は誰も暗くしない。1〜3人を並べ、3人の時は 0.72 倍に小さくし、少し外へ広げる（顔が重ならないように）。表情の絵ごとに元の大きさが違っても、表情を替えるたびに同じ高さ（`height`）に測り直す。ゆっくり息をするように、わずかに伸び縮みさせる
- **表情**：台本は、言葉に合う表情で1行ずつ書く（書かなければ前の表情のまま残るので、言葉と顔が合わなくなりやすい）。まだ絵のない表情は、`CAST` の `fallback` に書いた近い表情の絵で代わりに出す（例：あかりの照れ → 笑顔、悲しい → 心配）。絵が届いたら、台帳に足すだけで台本は直さない。テストが、どの表情にも絵か代わりの絵があることを確かめる
- 絵がない物（背景・立ち絵・1枚絵）は、色と名前で仮に描く（立ち絵は図形に名前と〔表情〕、背景は色の帯に「（仮）背景の名前」）
- 文字送り（1文字35ミリ秒。語りの文は55ミリ秒）。タップで全文 → もう一度タップで次へ。折り返しは全文で先に決めてから1文字ずつ出す（途中の文で折り返すと、行の終わりの文字が一瞬はみ出して見えるため）。日本語の禁則処理もする（行の始めに来た句読点・閉じかっこ・小さい仮名・長音は、前の行の終わりにぶら下げる。`src/ui/kinsoku.ts`）。折り返しはこちらで決めるので、表示する時は文字の枠の自動の折り返しを切る
- **切り替わり**：背景と1枚絵は、前の絵に重ねて0.35秒かけて替える。人は少し下からふわっと出て、消える時は薄くなって消える。並びが変わる時は横に歩いて移る。章の扉の黒い幕も、ふわっと出し入れする。早送りの間はすぐ替える
- **背景を見せる間**（段階32b）：背景の絵が替わった時は、次の文を出す前に、本文の枠・名前の札・立ち絵を下げて、背景だけを2秒見せる（`BG_VIEW_MS`。タップで先へ。調整3で 2.5 秒から短くした）。初めて来るレストピアの図書館だけは3.5秒（`BG_VIEW_MS_BY_IMAGE`）。同じ絵は、ゲームを開いている間は最初の1回だけ（探索の途中の短い会話で毎回止まらないように）。早送りの間は見せない。絵のない仮の背景では見せない
- **紙芝居に見えない工夫**（調整2）
  - 立ち絵の芝居：表情が替わった時に、表情に合わせて小さく動く（`FACE_MOTIONS`：驚き → 跳ねる、大笑い → 弾む、得意げ → うなずく、むっ・あせり → 震える、心配・泣き・考える → 少し沈んで、別の表情で戻る、決意 → 前へ出る、デジャヴ → ゆっくり揺れる）。台本の `@act` でも動かせる
  - 感情のふきだし：驚き → 「！」、あせり → 汗のしずくを、表情が替わった時に自動で出す（`FACE_EMOTES`）。ほかは台本の `@emote` で出す。ぽんと出て、1.2秒で消える
  - 背景と1枚絵：背景はゆっくり寄っては戻り（14秒）、1枚絵はゆっくり寄っていく（10秒）。背景に空気を流す（`Backdrop.ambient`：祭りは昇る提灯の灯り、夜は星のまたたき、図書館と時計屋は舞う砂）
  - 演出：寄る（`@zoom`）、色を抜く（`@mono`。時計が止まる場面）、ノイズ（`@noise`。砂嵐や入口が開く場面）
  - 立ち絵は、外の入れ物（出入り・横の移動・大きさ）と中身（芝居の動き）に分けて、動きがぶつからないようにしている
- **文字の音**（試し）：文字が出るたびに、2文字に1回、短い「ポッ」という音を鳴らす（句読点・記号では鳴らさない）。音のファイルは使わず、その場で作る（`playBlip`）。人ごとに高さと音色を変える（`CAST` の `voice`、声だけの人は `VOICE_ONLY`）。高さは、スマホのスピーカーで聞こえる 250〜800Hz にする（テストで確かめる）。音色ごとの聞こえ方の差は `WAVE_GAIN` でそろえる（四角い波はよく響き、三角の波・なめらかな波は小さく聞こえるため）。電話の声はこもった音にする。語りの文・ハルトの心の中の文・紙の文では鳴らさない。オプションの「文字の音」で入り切りでき、設定に保存する（`typeSound`）。音量は効果音の音量に合わせる。出力先（設定の `audioOut`）でワイヤレスイヤホンを選んだ時だけ、ブラウザが教えてくれる遅れ（`audioLatencyMs`。分からなければ50ミリ秒）の分だけ音を先に鳴らし始め、文字はその分あとから出す（Bluetooth は音が0.1〜0.3秒遅れて届く。スピーカーでは早めない）。出力先は、タイトルと会話のオプションで選べる（段階32b 調整3 で、会話の上の「文字音」のボタンをオプションにまとめた）
- 語りの文：名前の札なし、砂色の文字、文字の上を細かい砂が流れる（砂の色はヴィクトの鎖の砂時計と同じ暗い金。`NARRATION_SAND_COLOR`）。ハルトの心の中の文は、名前の札なしの薄い青の文字
- 紙の文：本文の枠を紙の色にし、名前の札に見出し（ノート、札）
- 章の扉：画面を黒くして、真ん中に大きな文字
- **早送り**：読んだ台詞だけ飛ばす。まだ読んでいない台詞に来たら止まり、「まだ読んでいない所で止まりました」と出す。選択肢でも止まる。早送りの間は効果音を鳴らさず、演出を短くする。`?debug=1` の時は、まだ読んでいない台詞も飛ばせる（確かめやすくするため）
- **読んだ印**：場面と、話す人・本文から作る（台本の別の所を書き足してもずれない。本文を直した台詞は、まだ読んでいない扱い）。セーブとは別にブラウザに保存する（`restopia.read`。はじめからやり直しても、読んだ所は早送りできる）
- **オート**：全文が出てから「1.1秒＋1文字45ミリ秒」待って次へ。選択肢で止まる。早送りとオートは、片方を入れるともう片方は切れる
- **ログ**：読んだ台詞と選んだ選択肢を、新しい方から画面に入るだけ出す。タップで閉じる
- 場面が終わったら、続けて見る場面（`queue`）があれば始め、なければ次の画面（なければタイトル）へ。覚えた値（`vars`）は続きの場面に引き継ぐ。物語の流れ（段階23）とつなぐ時は、終わった時に値を受け取れるようにする
- デバッグメニュー：「M1 を通しで読む」、場面を選んで開く、読んだ印を消す

## 決定の記録

- 2026-10-10 段階32b 調整3（開発者が通しで遊んだ感想）：上の「文字音」のボタンを「オプション」にし、音量・文字の音・出力先をまとめた（タイトルと同じ窓 `src/ui/options.ts`。項目を後から足せる）。祭の人混みの音を、場面の途中で1回鳴らすのをやめ、屋台の並ぶ背景（`BACKDROPS` の `ambienceSe`）が出ている間、小さく鳴り続ける環境音にした（4秒の音を、高さを少し変えながら約2.2秒ごとに重ねる。`startAmbience`、数値は `AMBIENCE`。日常の画面の屋台の並びでも鳴る）。暗転している間に背景・1枚絵・人を替えた時は、ゆっくり重ねずにすぐ替える（プロローグの終わりから章の扉へ移る時に、前の背景が一瞬見えたため）。章の扉の題字を `@logo` の演出にした。背景だけを見せる時間を 2.5 秒から 2 秒にし、図書館だけ 3.5 秒にした
- 2026-10-09 段階31c：台本の効果音を効果音ラボから入れた。語りの文の砂の音（`@se sand`）は、効果音ラボに合う音がなかったので、秒針の音と同じくその場で作る（`playSand`、数値は `SAND_SOUND`）。りくが休みだと知らされた後の教室のざわつきは、祭りの人混み（`crowd`）と分けて `murmur` にした

- 2026-10-09 段階24の後の調整：場面が続く所（1日目の施設 → 教室など）がいきなり切り替わる、という感想を受けて、場面の切れ目では自動で暗転し、次の場面の最初の文で明転するようにした（台本で暗転している時はそのまま）。会話を終えて別の画面へ移る時も、暗転してから移る

- 2026-10-08 段階22（調整12の直し2）：時計屋の秒針の音が多すぎて何の音か分かりにくい、という感想を受けて、重ねる音を4つから3つにして小さくし（本物の音を1として 0.35・0.2）、店に入った所に「いくつもの秒針が、少しずつずれて時を刻んでいる」という地の文を足した

- 2026-10-08 段階22（調整12の直し）：秒針が進むたびに下を向いてぶれる、という報告を受けて直した。Phaser は角度を 180度を超えると -180度側に折り返して覚えるので、角度そのものを動かすと、6度進むはずが逆回りにほぼ一周していた。進む前後の折り返さない角度の間を動かし、針に写す形にした

- 2026-10-08 段階22（調整12）：商店街で時計が止まる場面（1-C）が、白黒になるだけで何が止まったのか分からない、という話から、時計の寄り（図形で描いた文字盤と秒針）と秒針の音を足した。白い街の夢・時計屋（店じゅうの時計が1つずつ止まる）・戻った時の「まだ、五時十二分？」にも使う。秒針の音は効果音ラボの音ではなく、文字の音と同じくその場で作る（短い音をくり返すだけなので、作った方が速さや重ね方を自由に変えられる）

- 2026-10-08 段階22（調整11）：あかりの笑顔は歯を見せた明るい顔なので、静かな場面では合わない、という感想を受けて、口を閉じた「微笑み」を足し、静かな台詞（9行）をそちらに替えた。「くろの……なに？」は驚きすぎに見えるので困り笑いにした。微笑みの絵も同じ日に届いた

- 2026-10-08 段階22（調整10）：あかりの足した5つの表情（驚き・照れ・悲しい・真剣・困り笑い）の絵が届き、代わりの表情は誰も使わなくなった（絵のない表情を代わりの絵で出す仕組みは、後から出る人のために残す）

- 2026-10-08 段階22（調整9）：3人並ぶ時に重なりすぎる、という感想を受けて、3人の時の大きさを 0.82 倍から 0.72 倍にし、左右の人を少し外へ（78・312 → 68・322）出した。0.64 倍も試したが、顔が小さくなりすぎるので 0.72 倍にした

- 2026-10-08 段階22（調整8）：ハルトの立ち絵を、あかり・りくと同じ構図（縦長、頭の上から胸の真ん中まで）の9つの表情に作り直した。正方形だった M0 の絵に合わせて低くしていた高さ（300）を、ほかの2人と同じ 450 にし、代わりの表情は使わなくなった

- 2026-10-08 段階22（調整7）：りくの笑顔の時だけ体が大きく見える、という報告を受けて調べた。笑顔の絵（ChatGPT）だけ元の大きさが 1024×1536 で、ほかの表情（Gemini、843×1264）と違い、最初の表情の大きさで決めた倍率のまま絵を差し替えていたのが原因。表情を替えるたびに倍率を測り直す形にし、笑顔の絵もほかと同じ大きさに縮めた

- 2026-10-08 段階22（調整6）：ところどころ立ち絵の表情と言葉が合っていない、という感想を受けて、表情を増やし（あかり・ハルトは5つずつ、ほかの人も）、台本の表情を全場面で付け直した（54行）。足した表情の絵は段階31a で作り、それまでは近い表情の絵で代わりに出す
- 2026-10-08 段階22（調整5）：りくの音はよく聞こえるのに、あかり・担任は小さく、ハルトは聞こえない、という感想を受けて、低すぎた高さ（ハルト210Hz・担任150Hz など）を 250Hz 以上に上げ、音色ごとの大きさを補正した
- 2026-10-08 段階22（調整4）：文字の音のずれは Bluetooth イヤホンのせいだった（開発者のスマホで確認：早めない時はスピーカーでちょうどよくイヤホンで遅い、早めた時はイヤホンでちょうどよくスピーカーで早い）。どちらを使っているかはブラウザから分からないので、「出力先」を遊ぶ人が選ぶ形にした（初期値はスピーカー）
