# 設計書：探索

段階25。区画の地図を歩き、宝箱を開け、敵の印に触れて戦い、チェックポイントで記録する。数値の正は `src/data`。

## 1. 区画のデータ

- `src/data/areas.ts` の `AREAS`（区画）と `AREA_BATTLES`（区画の戦闘）。ロジックは `src/core/explore.ts`、画面は `src/scenes/ExploreScene.ts`
- 物語の流れ（`docs/design/run.md` の 0.）の「探索」の出来事が、`area` で区画を指す
- 区画が持つもの

| もの | 中身 |
| --- | --- |
| 地図の絵 | 台帳の id（縁日は `map.festival`）。1マス 32（`AREA_TILE`） |
| 歩ける場所の文字の地図 | `#` は通れない、`S` 出発点、`P` チェックポイント、ほかは通れる（縁日は段階18b の地図をそのまま使う） |
| 宝箱 | マスと中身（素材・アイテム）。タップした時だけ開く |
| 敵の印 | 行き来する道の折り返しの点と、触れた時の戦闘 |
| ボスの印 | マスと戦闘（区画の奥。動かない） |
| 話せる人 | 写しの人々。マスと会話の場面 |
| 途中の会話のきっかけ | 敵に n 回勝った時／チェックポイントに初めて着いた時／ボスに触れた時（会話の後でボス戦）／ボスに勝った時（会話の後で区画を出る）。どれも1回だけ |

## 2. 歩き方と出来事

- 画面をタップすると、その場所まで最短の道で歩く（壁なら近くの通れるマスへ）。カメラは仲間について動く
- 宝箱は、タップすると隣まで歩いてから開け、中身が本当に持ち物に入る（`run.armory`）。上を通り過ぎただけでは開かない（段階26の時の調整）。開けた宝箱は暗くなる
- チェックポイント（青い輪）に着くと記録する（最後に記録したチェックポイントを覚える）。初めて着いた時は会話（1-1 では「少し休もう」）
- チェックポイントに立ち止まっている間、下に育成の画面への入口（1章は「星図・武器」。章のパーティで開いているものだけ）。星図の下のボタンは「探索へ戻る」になり、同じチェックポイントへ戻る（段階26）
- 敵の印（赤い菱形）は決まった道を行き来する。触れると戦闘。勝てば同じ場所に戻り、その印は消える。負けたら、最後に記録したチェックポイント（なければ出発点）へ戻る。倒した敵と開けた宝箱はそのまま
- 戦闘や会話から戻った直後の 1.8秒（`AREA_GRACE_MS`）は、敵の印に触れても戦闘にしない
- 話せる人・宝箱・ボスの印をタップすると、隣まで歩いてから話す・開ける・戦う。ボスの隣を通った時も、ボスの前の会話になる
- ボスに勝ち、その後の会話を見たら、区画を出て物語の次の出来事（時間を返す）へ
- HP と MP：戦闘ごとに全回復して始まる（試作の5戦と同じ）。なので、チェックポイントで回復する仕組みは作らない（段階26で決めた。戦闘をまたいでHPが減ったままになる形は、M2 以降に探索の手応えを見て考える）

## 3. 戦闘とのつなぎ

- 戦闘の画面に「探索から来た戦闘」を渡す（区画の戦闘の id、勝った時と負けた時に戻る画面）。試作の5戦の進み具合は変えない
- 勝った時：星の砂（戦闘の `reward`＋部位破壊）、素材とアイテム、武器の経験値を受け取って「探索へ戻る」。ギアの報酬は出さない（1章はムーブメントが閉じているため。段階26。ムーブメントを開ける M2 で、報酬の出し方を決める）
- 戦う仲間は、物語の今の章のパーティ（1章はハルトとあかりの2人。`docs/design/battle.md` の「2人の時」）
- 連携技のつながりゲージは、章の中で戦闘をまたいで引き継ぐ（`docs/design/battle.md` の 7.）。探索の画面の上に、今の量を出す
- 敵は 1-1 の縁日の砂嵐（金魚・水風船・お面・わたあめノイズ）と、区画のボス「金魚鉢のぬし」（段階27。`src/data/festivalEnemies.ts`、組み合わせは `AREA_BATTLES`。数値の決め方は `docs/design/battle.md` の 13.）。倒すと素材を落とす（コマは段階28）
- 戦闘のシードは「周回のシード＋区画の戦闘の id から作った数」

## 4. セーブ

- 探索の状態（いるマス、最後に記録したチェックポイント、開けた宝箱、倒した敵、見た途中の会話、ボスに勝ったか）を `run.explore` に入れ、歩くたび・出来事のたびにセーブする（セーブの版4）。閉じても、いた場所から続く
- 読む時は今の区画に合わせて整える（通れないマスなら出発点、知らない宝箱・敵・会話は捨てる、知らない区画なら探索の途中ではないことにする）
- 区画を出たら `run.explore` を空にする

## 5. デバッグ

- `?debug=1` の時だけ、右上の「マス目」で通れないマスを赤く見せる
- デバッグメニュー（探索の途中の時）：「探索：敵の印を全部倒したことにする」「探索：ボスの手前へ移る」。「次の出来事へ飛ばす」「出来事を選んで飛ぶ」は、探索を終えたことにしてから飛ぶ
