段階25。区画の地図を歩き、宝箱を開け、敵の印に触れて戦い、チェックポイントで記録する。数値の正は `src/data`。

## 2. 歩き方と出来事

- 画面をタップすると、その場所まで最短の道で歩く（壁なら近くの通れるマスへ）。カメラは仲間について動く
- 宝箱は、タップすると隣まで歩いてから開け、中身が本当に持ち物に入る（`run.armory`）。宝箱のマスは通れない（上を歩けない。`areaGrid` が宝箱のマスをふさぐ）。開けた宝箱は暗くなる
- チェックポイント（青い輪）に着くと記録する（最後に記録したチェックポイントを覚える）。HP・MP が減っていれば全回復する（段階32b 調整3）。初めて着いた時は会話（1-1 では「少し休もう」）
- チェックポイントに立ち止まっている間、下に育成の画面への入口（1章は「星図・武器」。章のパーティで開いているものだけ）。星図の下のボタンは「探索へ戻る」になり、同じチェックポイントへ戻る（段階26）
- 敵の印（赤い菱形）は決まった道を行き来する。触れると戦闘。勝てば同じ場所に戻り、その印は消える。負けたら、最後に記録したチェックポイント（なければ出発点）へ戻る。倒した敵と開けた宝箱はそのまま
- 戦闘や会話から戻った直後の 1.8秒（`AREA_GRACE_MS`）は、敵の印に触れても戦闘にしない
- 話せる人・宝箱・ボスの印をタップすると、隣まで歩いてから話す・開ける・戦う。ボスの隣を通った時も、ボスの前の会話になる
- ボスは、ボスが抱えているコマを足せば返せる数になるまで眠っていて、戦えない（段階32b 調整3。`bossReady`）。眠っている間は暗い色で「z z」と出し、タップすると「ぬしは、まだ眠っている。先にほかの砂嵐からコマを集めよう（あと◯つ）」。1-1 は砂嵐を全部倒した時に目を覚ます
- ボスに勝ち、その後の会話を見たら、区画を出て物語の次の出来事（時間を返す。`docs/design/return.md`）へ。探索の状態は返し終えるまで残す
- HP と MP（段階32b 調整3）：区画の中の戦闘は、前の戦闘で残った HP・MP から始まる（勝った戦闘の終わりの量を持ち越す。倒れたまま勝った仲間は HP 1）。チェックポイントに着くと全回復、負けてチェックポイントへ戻る時も全回復。区画を出ると全回復（次の区画は新しい探索の状態から）。画面の下の帯に、仲間の今の HP・MP を出す（全回復の時は薄い色）。3人の時は1行に入らないので、仲間ごとの列に「名前 HP」「MP」の2行で出し、帯を少し高くする（段階38）

## 2-2. 部屋をつなぐ（段階47a）

- **部屋の形**：正方形（24×24マス。ChatGPT に 1024×1024 で頼む）と縦長（24×43マス。1024×1536）の2種類。横長は作らない
- **出入口**：辺の真ん中にだけ置き、幅は4マス（`EXIT_WIDTH`。`exitCells`）。正方形・縦長とも、上下左右の真ん中が候補。使わない出入口は、絵では壁や木でふさぎ、文字の地図でも `#` にする。出入口の位置がそろっているので、どの部屋とどの部屋もつなぎ替えられる（砂の底で組み立てられる）
- **部屋の移り方**：出入口のマスに着くと、短く暗転して、つながった部屋の出入口の内側（同じ並びのマス。`entryCells`）に出る（`passDoor`）。入った直後は、戦闘から戻った時と同じ間（`AREA_GRACE_MS`）だけ敵に触れても戦闘にしない。カメラの範囲は部屋ごと。画面は開き直す（`ExploreScene` を restart）
- **閉じた出入口**：開ける印をまだ倒していないと「この先は、まだ通れない。近くの番人を倒すと開く」などと出て止まる（ボスの部屋から入口への近道、砂嵐を倒すと開く扉）
- **全体の地図**：部屋が2つ以上の区画だけ、右上に小さく、入った部屋とつながりを出す（今いる部屋は黄色。入っていない部屋は出さない）。位置は最初の部屋から、つなぎの向きで隣に置く（`roomPositions`）。タップで大きく見せるのは、部屋の多い区画ができてから決める
- **区画の大きさの目安**：物語の1回目は10〜15分。部屋は4〜6つで、そのうち1〜2つは行き止まりの寄り道（宝箱や、逃げる敵）。チェックポイントは今と同じく2つ
- **部屋の絵がない時**：マス目（通れる所を市松の色）で描く。先に部屋の割り振りと文字の地図で遊べる形を作り、絵は後から `image` を足す（段階39b の 2-2）
- **書き間違いの検査**（`checkArea`・`checkRoom`）：部屋の大きさ、使える出入口がふさがっていないか、ない出入口へのつなぎ、つなぎのない出入口（片方だけ）、同じ出入口に2つのつなぎ、開ける印がない、どこからも行けない部屋、出発点からボスまで歩けるか（閉じた出入口も、いつか開くので通れるものとする。`reachableCells`）

## 2-3. 敵の動き（段階47b）

| 種類 | 動き | ねらい |
| --- | --- | --- |
| 見回り（`patrol`。今までの形） | 決まった道を回る。3点以上なら輪 | 道の上の障害物 |
| 追ってくる（`chase`） | 4マス以内に来ると「！」を出して追いかけ、7マスより離れるとあきらめて道へ戻る。仲間より遅い（1マス 420ミリ秒。仲間は 140）ので逃げ切れる | 緊張感。避けるか戦うかを選ばせる |
| 番人（`guard`） | 分かれ道や出入口に立って動かない（少し大きく、「番人」の札）。閉じた出入口の開ける印にすると、倒すまで先へ通さない。1回目の物語だけに置き、狩りでは出さない | 区切りと、手ごたえのある戦い |
| 逃げる（`flee`） | 4マス以内に来ると、仲間から一番遠くなる隣のマスへ逃げる（光っている）。どこへ行っても近づくなら、その場にとどまる＝行き止まりに追いこむと捕まえられる。仲間と同じくらい速い（1マス 150ミリ秒） | やり込み（狙って探す楽しみ）。珍しい素材を落とす敵にする |

- 数値は `src/data/areas.ts` の `ENEMY_MOVES`。次の1歩は `src/core/explore.ts` の `enemyNext`（乱数を使わない。同じ様子からは同じ1歩）。画面は1歩ごとに行き先を決めて動かす
- **印の見た目**：敵の絵（`ENEMY_ART`。戦闘の最初の敵の絵）を小さくして出す。絵のない敵は今までどおり赤い菱形

## 2-4. 周回・狩り（段階43）

返し終えた区画に入り直して、砂嵐とぬしと戦って素材を集める。日数を使わない（`docs/CONCEPT.md`）。中身は `docs/milestones/M2.md` の段階43の詳細。

- **記憶の薄れ**（段階57）：同じ記憶を続けてたどるほど実入りが減り、1日4回まで（`docs/design/economy.md` の 5-4）
- **呼び名**（2026-10-16 開発者と決めた）：遊ぶ人に見せる名前は「**記憶をたどる**」（拠点のボタン、探索の上の帯「記憶をたどる：素材を集める」、区画を選ぶ窓「どの記憶をたどる？」）。思い出の世界に入る設定に「狩り」は合わないため。設計書とコードの中では、短く「狩り」（`hunt`）と呼んだままにする

- **入口**：レストピアの拠点（段階50。昼の日常の時計屋の「時計屋の奥へ（レストピア）」から入る。`docs/design/economy.md` の 4.）の「記憶をたどる」。区画を選ぶと、探索の画面を狩りとして開く（`ExploreData` の `hunt`）。段階43では時計屋から直接入っていた
- **入れる区画**：返した記録（`returned`）にあって、狩りの中身（区画の `hunt`）を書いた区画（`huntableAreas`）。今は 1-1・1-2・2-1・2-2
- **狩りの中身**（区画の `hunt`。`src/core/hunt.ts`）：採取の場所（`gathers`。マスと素材）と、部屋ごとの敵の表（`tables`。区画の戦闘の id。同じ id を重ねると出やすい）
- **狩りの区画**（`huntArea`）：入るたびに1回目の区画から作り直す。番人・話せる人・途中の会話・宝箱を除き、閉じた出入口を開け、採取の場所を宝箱の形（通れないマス、隣から開ける）で置く。敵の表を書いた部屋の砂嵐は、入るたびに表から戦闘を選ぶ（乱数は、周回のシードと狩りの回数から作った `salt`）
- **ぬし**：はじめから起きていて、入るたびに1回挑める（部位を壊すと落とす素材が進化の鍵なので）。勝つとその回は消えるが、区画は終わらない
- **戦闘**：狩りの戦闘（戦闘の画面の `encounter.hunt`）は、コマ・ぬしのスナップ・勝利のアイテム（1回目の戦闘の報酬）を渡さない。前の章の区画（`areaChapter` で決める）では星の砂と武器の経験値が半分（`huntRewardRate`、`HUNT_OLD_AREA_RATE`。段階49。区画を選ぶ窓にも「星の砂と経験値は半分」と出す）。素材は1回目と同じ。シードは「周回のシード＋区画の戦闘の id から作った数＋狩りの戦闘の回数×104729」（同じ砂嵐と何度戦っても落とす物が変わる）
- **物語の中の意味**（2026-10-16 決まった）：狩りは、ハルトたちが見てきた記憶の砂時計に入ること（`docs/STORY.md` の 2-2）。人の姿がぼんやりして話せず、時間が進まないので、話せる人・会話・日の進みがない。2-3 は取り返すまで入らない
- **画面**：上の帯はコマの代わりに「記憶をたどる：素材を集める」。採取の場所は光る緑のひし形（拾うと暗くなる）。左上は「タイトル」の代わりに「レストピアへ戻る」（拠点に戻る。段階50。段階43では昼の時計屋へ）。HP・MP の持ち越し、チェックポイント（全回復・育成の入口）、負けたらチェックポイントへ、は1回目と同じ
- **セーブ**：狩りの途中の状態（いる所、倒した敵、拾った採取の場所、HP・MP）は `run.hunt` に置き、セーブしない。閉じたら昼の日常から。狩りの回数は物語で覚えた値（`狩り:回数`）に入れるので、セーブの形は変えない
- 書き間違いは `checkHunt`（採取の場所が通れる・チェックポイントや出発点の上でない・中身がある、表の部屋と戦闘がある、作った狩りの区画が `checkArea` を満たす）とテストで止める

## 3. 戦闘とのつなぎ

- 戦闘の画面に「探索から来た戦闘」を渡す（区画の戦闘の id、勝った時と負けた時に戻る画面）。試作の5戦の進み具合は変えない
- 勝った時：星の砂（戦闘の `reward`＋部位破壊）、素材とアイテム、武器の経験値を受け取って「探索へ戻る」。ギアは戦闘では手に入らない（段階38。宝箱と出来事のごほうびで手に入る。`docs/design/growth.md` の 3.）
- 戦う仲間は、物語の今の章のパーティ（1章はハルトとあかりの2人。`docs/design/battle.md` の「2人の時」。2章はみおを入れた3人。段階38）
- 連携技のつながりゲージは、章の中で戦闘をまたいで引き継ぐ（`docs/design/battle.md` の 7.）。探索の画面の上に、今の量を出す
- 敵は 1-1 の縁日の砂嵐（金魚・水風船・お面・わたあめノイズ）と、区画のボス「金魚鉢のぬし」（段階27。`src/data/festivalEnemies.ts`）、1-2 の昭和の砂嵐（ブリキ・黒電話・ラムネ・めんこノイズ）と「自転車のぬし」（段階37。`src/data/showaEnemies.ts`）、2-1 の町工場の砂嵐（歯車・ネジ・真空管・そろばんノイズ）と「旋盤のぬし」（段階39。`src/data/factoryEnemies.ts`）。組み合わせは `AREA_BATTLES`、数値の決め方は `docs/design/battle.md` の 13.。倒すと素材を落とす（コマは段階28）
- 戦闘のシードは「周回のシード＋区画の戦闘の id から作った数」

## 4. セーブ

- 探索の状態（いる部屋とマス、最後に記録したチェックポイントとその部屋、入ったことのある部屋（段階47。セーブの版9。前の版の探索の途中は、最初の部屋にいたことにする）、開けた宝箱、倒した敵、見た途中の会話、ボスに勝ったか、コマ、持ち越す HP・MP）を `run.explore` に入れ、歩くたび・出来事のたびにセーブする（セーブの版4）。閉じても、いた場所から続く
- 読む時は今の区画に合わせて整える（通れないマスなら出発点、知らない宝箱・敵・会話は捨てる、知らない区画なら探索の途中ではないことにする）。持ち越す HP・MP（`vitals`）は、なければ全回復として読む（調整3で足した。なくても読めるので、セーブの版は7のまま）
- 区画を出たら `run.explore` を空にする

## 5. デバッグ

- `?debug=1` の時だけ、右上の「マス目」で通れないマスを赤く見せる
- **試しの区画**（段階47。デバッグメニューの「試しの区画：部屋をつなぐ探索と敵の動き」。`TRIAL_AREAS` の `trial47`）：今ある地図の絵3枚に出入口の道を開けて部屋としてつないだ区画（絵は道の所が壁のまま）。商店街（出発点。追ってくる敵）の上の出入口は、番人を倒すと開く縁日（見回りの敵とボス）へ。左の出入口は、寄り道の町工場（逃げる敵と宝箱）へ。ボスに勝つとタイトルへ戻る（物語の流れは進まない）。探索の途中だった区画は、次に入ると最初から
- デバッグメニュー（探索の途中の時）：「探索：敵の印を全部倒したことにする」（段階37から、倒した砂嵐のコマも手に入れる。ボスが目を覚ます）「探索：ボスの手前へ移る」。「次の出来事へ飛ばす」「出来事を選んで飛ぶ」は、探索を終えたことにしてから飛ぶ
