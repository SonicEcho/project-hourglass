# 設計書：コマ集めと、時間を返す

段階28。盗まれた時間を持ち主に返す、物語の目的であり遊びの中心（`docs/CONCEPT.md` の「ゲームの循環」と「返すことのルール」、`docs/STORY.md` の 2-5）。数値の正は `src/data`。ロジックは `src/core/explore.ts`（コマ）、画面は `src/scenes/ExploreScene.ts`（集める）と `src/scenes/ReturnScene.ts`（返す）。

## 1. コマ

- 盗まれた時間（区画）ごとに、返すのに要るコマの数を持つ（`AreaDef.komaNeed`。1-1「金魚の名前」は8）
- 砂嵐を倒すとコマが手に入る。素材の落とし物とは別で、区画の戦闘ごとに決まった数を必ず（`AREA_BATTLES` の `koma`）。1-1 は雑魚戦4つで 1・2・2・2、ボスで 2（合わせて9。1つ余る）
- 雑魚戦だけでは足りず、最後のコマはボスから（テストで確かめる）。どの順で戦っても同じ
- 集めたコマは探索の状態に入れてセーブする（`ExploreState.koma`）
- コマは返すことだけに使う（素材と別。開発者と決めた）。余ったコマは、返した時に好きな記憶の欠片にできる（1コマで1つ）

## 2. 探索の画面

- 上の帯に「コマ ◯/8（あと◯つで返せる）」。そろったら「そろった！」
- 勝って戻った時の案内に「コマを◯つ手に入れた（あと◯つで返せる）」。勝利の表示にも「コマ +◯」
- 途中の会話（区画のきっかけ）：最初の勝利（最初のコマ）、残りが3つ以下になった時（`komaLeft`。「あと{komaLeft}つで、そろうよ！」）、ボスに勝った時（最後のコマ。「コマがそろった（{komaHave}/{komaNeed}）」）。台本の `{komaHave}` `{komaNeed}` `{komaLeft}` に、その時の数を入れる（物語の値としては覚えない）

## 3. 返す

- 区画のボスに勝ち、最後のコマの会話を見ると、物語の次の出来事「時間を返す」（`kind: 'return'`、`area`）へ。探索の状態は、返し終えるまで残す
- 返す画面：札（蔵書の名前・持ち主・「返却：コマがそろった（8/8）」）と、コマ（返すのに使う分は金色、余りは青）→「返す」→ コマが砂になって昇り、画面が白く光る →「盗まれた時間を、持ち主に返した」→ 余ったコマがあれば、記憶の欠片の種類を選ぶ →「次へ」で、返す場面の会話（夕暮れの時計屋）へ
- 前半なので、返すか残すかの選択肢は出さない（`docs/CONCEPT.md` の「設計上の注意」）
- 返した時間をセーブに残す（`run.returned`。区画の id。セーブの版7）。M2 の「翌日に持ち主に会う場面の型」と、8章の「持ち主たちが待っている」に使う
- 返し終えた時に、探索の状態を片付ける。返す画面の途中で閉じたら、返す画面の最初から
- デバッグで返す出来事へ飛んだ時（探索の状態がない時）は、ちょうどそろったものとして見せる

## 4. 音と絵

- 砂が昇る音は、まだない（今は回復の音で代わり）。本番の音と、返す演出の絵は段階31
