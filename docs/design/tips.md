# 設計書：初めての人向けの説明

段階30。遊び方の説明を、最初にまとめて読ませるのではなく、使う場面になった時に1つずつ出す（`docs/milestones/M1.md` の段階30）。説明の文は `src/data/tips.ts`、どの場面で出すかは `src/core/tips.ts`（Phaser を読み込まない）、窓と覚え方は `src/ui/tipPanel.ts`。

## 1. 出し方

- 使う場面になった時に、まだ見ていない説明を **1つだけ** 窓で出す。同じ時に2つ以上当てはまる時は、`TIPS` の並び順で上のもの。残りは次の場面で出る
- 窓は画面の真ん中に、「はじめての説明」・題・本文と「わかった」。後ろは押せない。説明の通りに操作させる所は作らない（読んで「わかった」で閉じるだけ）
- 出した時に「見た」と覚える（窓を閉じる前にページを開き直しても、もう出さない）
- オート中の戦闘では出さない（オートを使う人は、もう分かっているため）

## 2. 説明と、出る場面

| 説明（id） | 出る場面 |
| --- | --- |
| 戦い方：行動を選んで、実行（`battle_plan`） | 戦闘の計画の始め（最初の戦闘） |
| 弱点とダウン（`battle_weak`） | 弱点が見つかった・敵がダウンした後に、操作を待つ時 |
| 延長（`battle_extend`） | 初めての追加行動 |
| バトンタッチ（`battle_baton`） | 追加行動で、バトンを渡せる仲間がいる時（延長の次） |
| コンボ（`battle_combo`） | 計画の時、誰かの手札でコンボがそろっている |
| 部位破壊と大技の予告（`battle_boss`） | 部位のある敵がいる、または敵が力をためている |
| 連携技（`battle_link`） | 計画の時、つながりゲージが満タン |
| オートと早送り（`battle_auto`） | 雑魚戦の計画の時。ただし「戦い方」を前の戦闘までに見ている時だけ（最初の戦闘には出さない） |
| 探索（`explore_basic`） | 探索の画面を開いた時 |
| チェックポイント（`explore_checkpoint`） | チェックポイントに着いた時（途中の会話が出る時はそちらが先） |
| コマ集め（`explore_koma`） | コマを1つ以上持って、探索の画面を開いた時 |
| 星図（`growth_star`） | 星図の画面を開いた時（試作の5戦のギアの報酬が出る時は、次に開いた時） |
| 武器（`growth_weapon`） | 武器の画面を開いた時 |

- 戦闘で「操作を待つ時」は、戦闘の始め・ラウンドの演出が終わった時・追加行動の演出が終わった時
- 探索で窓を出している間は、自分も敵の印も止める。閉じた後の少しの間は、敵に触れても戦闘にしない（開いた直後と同じ猶予）

## 3. 覚え方と読み返し

- 見た説明の id は、**セーブとは別に** ブラウザに覚える（`restopia.tips`。設定と同じ扱い）。はじめからやり直しても、もう出さない（2回目からは出さない）
- タイトルの「説明」：戦闘・探索・育成のタブで一覧。タップで読める（まだ出ていない説明も読める。題に「まだ出ていない」）。「はじめから出す」（2回押す）で見た説明を忘れ、使う場面でまた出す
- 通しの自動確認（`npm run e2e`）は、最初に全部見たことにして通し、最後に「見た説明を忘れると、星図を開いた時に説明が出る」を確かめる

## 決定の記録

- 2026-10-09 段階30：見た説明はセーブとは別に覚えることにした（段階30の「作る時に決める」）。M1 の「2回目からは出ない」に合い、はじめからやり直した時に同じ説明をまた読まされないため。もう一度出したい時は、タイトルの「説明」の「はじめから出す」
- 2026-10-09 段階30：一度に出す説明は1つにした（続けて何枚も読ませないため）。オートの説明は最初の戦闘には出さない（覚えることが多い最初の戦闘を軽くするため）
