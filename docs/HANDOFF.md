## いまのルールの要点

- **ラウンド制**：ラウンドの始めに3人の行動を1人ずつ「計画」→「実行」で、味方と敵が「行動の速さ＝速さ÷重さ」の順に動く。防御は最初、クイックステップを使った仲間はその次
- **手札**：パーティ共通。ラウンドの始めに5枚まで補充し、使わなかったカードは残る。割り当てたカードは他の仲間に使えない（「○○が使う」）
- **コンボ**：手札の組み合わせで出す大技（エレメントバースト、トリプルソード、ブレイククラッシュ、ヒールサークル）
- **サポートカード**（ドロー・サーチ・クイックステップ）：計画中にその場で使い、行動枠を使わない（1ラウンドに1枚）
- **ワンモア**：弱点でダウン → 1枚引いてその場で追加行動。別の敵をダウンさせると連鎖。まだ動いていない敵をダウンさせると、そのラウンド行動できない（割り込み）。立ち上がった敵は次に動くまでダウンしない。バトンタッチで追加行動を仲間に渡せる（1.25倍）。見送りも可
- **連携技**：主人公とみおの2人分の行動で「クロスドライブ」（耐性無視、カットインあり）
- **ボス**：部位（右腕・角）。大技（薙ぎ払い・歪みの咆哮）は1回「ため」てから放つ。ダウンで解ける。部位破壊で解けるのは、その部位を使う大技（咆哮＝角）だけ
- **成長マップ**：7×9に48マス。共通の記憶ポイントで、各キャラの駒の隣のマスを開け、能力値と魔法・スキルを得る。勝利で4〜7pt、部位破壊1つで+2pt
- **ナビカス盤**：キャラごとの盤（主人公4×4、あかり5×3、みお4×4の四隅なし）にパーツをはめる。能力値パーツはどこでも、効果パーツはコマンドライン（上から2行目）に乗っている時だけ効く。同じ色を隣に置くとバグ（毎ラウンドHP-5%）。最初に6つ、戦闘1〜4の勝利で3つの候補から2つもらう
- **武器**：1人1本。倒した敵が素材を落とし、勝利で通常アイテムももらえる。素材・アイテムを「断片化」すると、元ごとに特徴の違う「記憶の断片」になり、3人共通の持ち物から武器に吸わせる（攻撃値・属性値が上がる）。行動の回数で経験値が貯まり、Lv3 で条件を満たすと3つの進化先から1つに進化（通常攻撃に属性が乗る、など）。進化すると盤のコマンドラインが2マス伸びる。勝つたびに盤のパーツの色が「傾向」として貯まり、進化の条件になる

## 進め方の約束（開発者との取り決め）

- 仕組みは `docs/design/` に従い、作業は `docs/milestones/` の段階単位で進める。仕様と違う判断や、仕様にないことを決めたら、関係する設計書に追記する
- 大きな変更は、いきなり作らず、先に `docs/milestones/` の文書（または設計書）にたたき台を書いて確認してもらってから実装する
- 開発者は、文書の中身をふだん Claude のチャットで確かめる。ただし脚本など長い文書は、チャットには要点と確かめてほしいことだけを短く書き、中身は GitHub で読んでもらう（トークンを節約するため。2026-10-08）
- ユーザーへの文章は、作業中のメッセージも含めてすべて日本語。作業後は「何を変えたか」と「スマホで何を確認すればよいか（具体的な操作手順）」を添える
- 作業ブランチはセッションごとに指定される名前に従う（2026-10-08 の M0 は `claude/m0-foundation-planning-wxvd6p`、M1 のたたき台は `ccr-c67a5453-svebd3`）。PR がマージ済みなら、最新の `main` から作り直してから作業する
- 開発者に「マージしてください」と言われたら、PR を作って `main` にマージする。マージ前に、ブランチの GitHub Actions が成功していることを確かめる。マージ後は `main` の公開が成功したかも確かめ、ブランチを `main` から作り直す。Actions の結果は、決め打ちで長く待たず、30〜60秒ごとに見に行って、終わったらすぐ次へ進む（1回はおよそ2分。2026-10-08）
- 数値の調整は、自動対戦で勝率を測ってから決める。段階12から `npm run measure`（`-- --runs 300 --seed 1` で回数とシードを変えられる）で、戦闘ごとの1回目の勝率の表が出る
