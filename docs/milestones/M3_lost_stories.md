# 依頼（落とし物）をサブストーリーにする（2026-11-15。たたき台。開発者と相談中）

開発者の頼み（2026-11-14）：依頼は単なるお使いにせず、その区画のストーリーか、仲間の誰かの深掘りにつながるサブストーリーにする（`docs/design/economy.md` の 5-3）。
進め方（2026-11-15 開発者と決めた）：1区画ずつ、筋（誰の話か・何が分かるか・最後に何が手に入るか）を先に短く書いて見せ、決まってから脚本と組み立てに入る。お使いに近い「集める」2つ（1-2 のベル・2-2 の四曲目）から作り直す。

## 1. 共通の形（案）
今の「探し物」（記憶をたどると光る所が1つ出る）を広げて、**記憶の中で3つの手がかりをたどる**形にする。

1. **受ける**（拠点の落とし物の棚）：今の持ち主の小さな心残りを、ひとことで知る
2. **たどる**（記憶をたどる区画）：光る所が順に3つ出る。触れると、写しの声（会話の場面）が聞こえ、次の光る所が出る。順番は決まっている（1つ目を見ないと2つ目は出ない）。狩りのついでに回れるよう、どれも狩りの区画の中に置く
3. **届ける**（今の持ち主の会話）：3つの声で分かったことを届ける。持ち主の今が少し変わる
4. **ごほうび**：今までどおり（ギア・スナップ・欠片・星の砂）。最後の1つは、話に出てきた物にちなんだ物にする

- 素材を集めるだけの依頼（「取り出す」）はなくす。素材は光る所の近くの採取で自然に拾える程度にする
- 写しとは話せない（`docs/STORY.md` の 2-2）ので、手がかりは「残っていた声」で聞く。今の「親方のひとこと」と同じ見せ方
- 仲間の深掘りは、たどる途中の仲間のひとことで少しだけ見せる（その仲間の山場の章より前は、伏線にとどめる）

## 2. 1-2「二度鳴るベル」（ふみ）の筋（案）
- **心残り**：ふみさんは、あの日の帰り道で、きよしさんがベルを二度鳴らしていた気がする。でも、なぜ二度だったのかが思い出せない
- **たどる**（昭和63年の商店街の記憶）
  1. 自転車屋の前：写しのきよしさん「ベル、もう一つ付けてくれんか。……いや、一つでええ。二度鳴らせばええんや」
  2. 坂の手前の角：写しのきよしさん（ひとりで練習している声）「ちりん、ちりん。……よし。これで『つかまれ』や。あいつ、まだふらつくやろからな」（退院の日のために、自分で決めた合図だった）
  3. 時計屋の前：若い見習いの声「きよしさん、ベル、油さしておきました。二度鳴らしても、ちゃんと鳴りますよ」……「おう、すまんな、じん坊」（**早瀬の深掘り**。20歳の見習いの早瀬。名前は「じん坊」とだけ呼ばれ、この時は誰だか分からない。4-2 で早瀬が加わった後に気づける伏線）
- **届ける**：ふみさんは「つかまれ」の合図だったことを思い出す（今の会話を広げる）。「あの人、照れ屋だから、口では言わないの」。最後に、ふみさんが「そういえば、時計屋の見習いさんが、いつもあの人の自転車をいじってくれてたわね」とだけ言う
- **ごほうび**：今のまま（HPギア・欠片）に、新しい戦闘のスナップを1枚（ベルにちなんだ「呼びかけ」の札。案）
- **4章の後のひとこと**（案）：早瀬が仲間になった後、拠点でこの依頼の記録を見ると、早瀬が「……ベルの油さしなら、覚えがある」とだけ言う

## 3. 2-2「書きかけの四曲目」（けんた）の筋（案）
- **心残り**：けんたさんのセットリストの四曲目「ラストチャイム」は、名前だけ書いて消してある。どんな曲になるはずだったのか、もう誰も覚えていない
- **たどる**（平成18年の文化祭の記憶）
  1. 部室：写しのだいち「四曲目の歌詞、サビだけ書いた。『終わりのチャイムが鳴っても』……続き、けんたが書けよ」
  2. 屋上への階段：写しのさき「メロディ、鼻歌で録っといた。……弦、切れても弾けるくらい、簡単にしといたから」
  3. 校門：写しのけんた（ひとりの声）「……『また明日』って、言わなくていい曲にしたいんだ。明日がなくても、ちゃんと終われる曲」
- **みおの深掘り（伏線）**：校門の声を聞いた後、みおが一瞬だけ黙り、「……また明日、か」とつぶやいて、すぐ「なんでもない！」と先へ走る（`docs/STORY.md` のみおの伏線「帰り道や交差点の前で、一瞬だけ足が止まる」に合わせる。7章まで理由は明かさない）
- **届ける**：けんたさんに3つの声を届ける。だいちのサビ、さきの鼻歌、自分が言っていたこと。けんたさん「……全部、そろってたんだな」。今の会話の「だいちとさきに、連絡してみるか」につなげる（返した持ち主のその後の、閉店後の店での演奏の曲が「ラストチャイム」になる）
- **ごほうび**：今のまま（スナップ・欠片・シェルクラック）。スナップは歌にちなんだ札にする（案）

## 4. 決めること（開発者と）
1. 共通の形（光る所を3つ順にたどる）でよいか。3つは多い・少ないか
2. 1-2 で、見習いの「じん坊」（若い早瀬）を出してよいか（4-2 より前に早瀬の過去を少し見せることになる）
3. 2-2 のみおの伏線の強さ（つぶやき1つ）でよいか
4. 「取り出す」（素材を集める）をなくしてよいか
5. ごほうびのスナップを、話にちなんだ新しい札にするか（新しく作る）、今ある札のままにするか
