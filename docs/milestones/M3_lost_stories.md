# 依頼（落とし物）をサブストーリーにする（2026-11-15。たたき台。開発者と相談中）

開発者の頼み（2026-11-14）：依頼は単なるお使いにせず、その区画のストーリーか、仲間の誰かの深掘りにつながるサブストーリーにする（`docs/design/economy.md` の 5-3）。
進め方（2026-11-15 開発者と決めた）：1区画ずつ、筋（誰の話か・何が分かるか・最後に何が手に入るか）を先に短く書いて見せ、決まってから脚本と組み立てに入る。お使いに近い「集める」2つ（1-2 のベル・2-2 の四曲目）から作り直す。

## 1. 共通の形（案）
今の「探し物」（記憶をたどると光る所が1つ出る）を広げて、**記憶の中で3つの手がかりをたどる**形にする。

1. **受ける**（拠点の落とし物の棚）：今の持ち主の小さな心残りを、ひとことで知る
2. **たどる**（記憶をたどる区画）：光る所が順に3つ出る。触れると、写しの声（会話の場面）が聞こえ、次の光る所が出る。順番は決まっている（1つ目を見ないと2つ目は出ない）。狩りのついでに回れるよう、どれも狩りの区画の中に置く
3. **届ける**（今の持ち主の会話）：3つの声で分かったことを届ける。持ち主の今が少し変わる
4. **ごほうび**：今までどおり（ギア・スナップ・欠片・星の砂）。最後の1つは、話に出てきた物にちなんだ物にする

- 素材を集めるだけの依頼（「取り出す」）はなくす。素材は光る所の近くの採取で自然に拾える程度にする
- 写しとは話せない（`docs/STORY.md` の 2-2）ので、手がかりは「残っていた声」で聞く。今の「親方のひとこと」と同じ見せ方
- 仲間の深掘りは、たどる途中の仲間のひとことで少しだけ見せる（その仲間の山場の章より前は、伏線にとどめる）

## 2. 1-2「二度鳴るベル」（ふみ）の筋（案）
- **心残り**：ふみさんは、あの日の帰り道で、きよしさんがベルを二度鳴らしていた気がする。でも、なぜ二度だったのかが思い出せない
- **たどる**（昭和63年の商店街の記憶）
  1. 自転車屋の前：写しのきよしさん「ベル、もう一つ付けてくれんか。……いや、一つでええ。二度鳴らせばええんや」
  2. 坂の手前の角：写しのきよしさん（ひとりで練習している声）「ちりん、ちりん。……よし。これで『つかまれ』や。あいつ、まだふらつくやろからな」（退院の日のために、自分で決めた合図だった）
  3. 時計屋の前：若い見習いの声「きよしさん、ベル、油さしておきました。二度鳴らしても、ちゃんと鳴りますよ」……「おう、すまんな、じん坊」（**早瀬の深掘り**。20歳の見習いの早瀬。名前は「じん坊」とだけ呼ばれ、この時は誰だか分からない。4-2 で早瀬が加わった後に気づける伏線）
- **届ける**：ふみさんは「つかまれ」の合図だったことを思い出す（今の会話を広げる）。「あの人、照れ屋だから、口では言わないの」。最後に、ふみさんが「そういえば、時計屋の見習いさんが、いつもあの人の自転車をいじってくれてたわね」とだけ言う
- **ごほうび**：今のまま（HPギア・欠片）に、新しい戦闘のスナップを1枚（ベルにちなんだ「呼びかけ」の札。案）
- **4章の後のひとこと**（案）：早瀬が仲間になった後、拠点でこの依頼の記録を見ると、早瀬が「……ベルの油さしなら、覚えがある」とだけ言う

## 3. 2-2「書きかけの四曲目」（けんた）の筋（案）
- **心残り**：けんたさんのセットリストの四曲目「ラストチャイム」は、名前だけ書いて消してある。どんな曲になるはずだったのか、もう誰も覚えていない
- **たどる**（平成18年の文化祭の記憶）
  1. 部室：写しのだいち「四曲目の歌詞、サビだけ書いた。『終わりのチャイムが鳴っても』……続き、けんたが書けよ」
  2. 屋上への階段：写しのさき「メロディ、鼻歌で録っといた。……弦、切れても弾けるくらい、簡単にしといたから」
  3. 校門：写しのけんた（ひとりの声）「……『また明日』って、言わなくていい曲にしたいんだ。明日がなくても、ちゃんと終われる曲」
- **みおの深掘り（伏線）**：校門の声を聞いた後、みおが一瞬だけ黙り、「……また明日、か」とつぶやいて、すぐ「なんでもない！」と先へ走る（`docs/STORY.md` のみおの伏線「帰り道や交差点の前で、一瞬だけ足が止まる」に合わせる。7章まで理由は明かさない）
- **届ける**：けんたさんに3つの声を届ける。だいちのサビ、さきの鼻歌、自分が言っていたこと。けんたさん「……全部、そろってたんだな」。今の会話の「だいちとさきに、連絡してみるか」につなげる（返した持ち主のその後の、閉店後の店での演奏の曲が「ラストチャイム」になる）
- **ごほうび**：今のまま（スナップ・欠片・シェルクラック）。スナップは歌にちなんだ札にする（案）

## 4. 決めること（開発者と）
1. 共通の形（光る所を3つ順にたどる）でよいか。3つは多い・少ないか
2. 1-2 で、見習いの「じん坊」（若い早瀬）を出してよいか（4-2 より前に早瀬の過去を少し見せることになる）
3. 2-2 のみおの伏線の強さ（つぶやき1つ）でよいか
4. 「取り出す」（素材を集める）をなくしてよいか
5. ごほうびのスナップを、話にちなんだ新しい札にするか（新しく作る）、今ある札のままにするか

## 5. 決まったこと（2026-11-16 開発者と）
- **狩りがなくなったので、砂の底に合わせる**：たどる所は砂の底。その区画の帯の奥に、光る「声のかけら」が埋まっている。掘り当てると写しの声（短い会話の場面）が聞こえ、次の潜りで次のかけらが埋まる。3つそろうと「見つけた」。理由づけ：返した時間からこぼれ落ちた砂に、写しの声のかけらが残っている
- **素材を集める依頼（取り出す）はなくす**。全部「声をたどる」
- **4つの依頼の筋**：1-1・1-2・2-1・2-2（下の 6.）。伏線（あかりのヘアピン、じん坊＝若い早瀬、親方といさむ、みおのつぶやき）もこの形で
- **ご褒美は物より「関係」と「話」**（ご褒美の渋滞を避ける。ギアは4章で 43、スナップは 90 と、設計書の目安を超えている）：
  - 仲間の絆（深掘りした仲間の絆の点が進む）
  - 仲間の新しいひとこと（届けた後、落とし物の棚で、その話にちなんだ仲間の台詞が読める）
  - 武器の寄り道③の鍵（届けた依頼の数を条件にする。段階221）
  - 記憶の欠片を少し
- **今の依頼のギア・スナップは、交換所・物語の宝箱・砂の底に配り直す**：HPギアは交換所（2章から。記憶の欠片10）、アーマーピアスは 2-1 の銭湯の路地の宝箱（1章はまだムーブメントが開いていないので、1-2 には置けない）、シェルクラックは砂の底（短期記憶の層の珍品のレアギア）。MPセーブ（いさむの工場の出来事・4-2 の宝箱）、スナップ「速写」（交換所）・「連写」（2-1 の宝箱・返した時）は、ほかでも手に入るので、依頼から外すだけにした（スナップの数も少し減る）。物語の宝箱に移した物は、取りこぼしても砂の底の「懐かしい物」で出る
- 声のかけらは、1回の潜りで1つだけ埋まる（その区画の帯の奥の空洞。ほかの光る物と同じ置き方）
- スナップが目安の2倍ある件は、後で別に相談する
- 依頼のない区画（2-3・3-1・3-2・大正の祭りの夜・4-1・4-2）に依頼を足すかは、4つを遊んでから決める

## 6. 4つの依頼の筋（決まった形）
- **1-1「金魚のヘアピン」（ゆうま）**：心残り＝縁日の夜、ひなのが何かをなくして泣いていた。声＝①屋台で写しのゆうま「ひなの、これ似合う。……百円？ 足りる」②迷子の時、写しのひなの「お兄ちゃんにもらったの、なくしちゃった」③写しのゆうま（ひとり）「……来年また買ってやるよ。来年も、二人で来たらな」。届ける＝ゆうまは「来年」が来なかったことに気づき、今年の夏祭りにひなのを誘う。あかりの伏線＝自分の金魚の髪留めに触れて「わたしのも、金魚……どこで買ってもらったんだっけ」。絆＝あかり
- **1-2「二度鳴るベル」（ふみ）**：2.のとおり（ベルを二度＝「つかまれ」の合図。じん坊＝20歳の早瀬）。ひとこと＝早瀬が仲間の時「……ベルの油さしなら、覚えがある」
- **2-1「親方のひとこと」（いさむ）**：心残り＝親方は「いい仕事だ」の後、何か言いかけていた。声＝①作業場で写しの源三（ひとり）「あいつの削り、俺の若い頃より筋がいい」②銭湯の前で写しのすみ「父ちゃん、褒めてあげなよ」源三「……褒めたら、止まっちまう」③屑箱の前で源三「欠けた方も、捨てられねえ。最初の一枚は、一生に一枚だ」。届ける＝（組み立てで調整：本筋の 11日目に、すみが「俺より上手くなる」と欠けた歯車を渡し、いさむがみおに「いい仕事だ」と言う場面がもうあるので、重ねない）依頼で分かるのは、親方が一度しか褒めなかった理由。いさむ「止まらんかったぞ、親方。五十年。……一度で、足りた」、みおに「褒められても、止まるなよ」。③の後半に源三「一度だけ言ってやる。一度で、足りるだろ」を足した。絆＝みお
- **2-2「書きかけの四曲目」（けんた）**：3.のとおり。みおの伏線＝「……また明日、か」「なんでもない！」。絆＝みお


## 7. 残りの区画の依頼（たたき台。2026-11-17。開発者の確認待ち）
開発者の声：依頼はもう少し全体的に増やしたい（`docs/milestones/M3_side_events.md`）。祭りの夜・4-2 にも入れる。
- **祭りの夜は、終章まで入れられない**：落とし物は、時間を返した区画の棚に出る。祭りの夜は終章まで返さない（`docs/script/3-matsuri.md`）。祭りの夜の依頼は終章で作る
- そのため、**小夜子の武器の寄り道③は 3-2 の依頼で、早瀬の寄り道③は 4-2 の依頼で開く**（`docs/milestones/M3_detours.md`）
- 形は 6. と同じ：砂の底の、その区画の帯で声のかけらを3つ（1回の潜りで1つ）→ 棚から届ける → 仲間のひとこと・絆・欠片少し。本筋の山場（返す時に分かること）とは別の、小さな心残り

- **2-3「グローブの内側」（こうじ）**：心残り＝最後の試合の後、ベンチに置き忘れたグローブ。声＝①パン屋の厨房で写しのまさる（ひとり）、こうじのグローブの内側に油性ペンで名前を書く「……名前の横に、もう一行」②写しのこうじ「名前、書くなよ。恥ずかしい」写しのまさる「わっはっは、もう書いた」③写しのまさる（ひとり。夕方のベンチ）「読むのは、お前が大人になってからでいいぞ」。届ける＝こうじが物置から古いグローブを出す。内側に「打てなくてもいい。毎晩、見てたぞ」。こうじは、そのグローブをそうたに渡す。ひとこと＝みお「グローブ、わたしも名前、書いてもらおうかな」。絆＝みお（同じ少年野球のチーム）
- **3-1「二つめのお弁当」（ちよ）**：心残り＝駅で、母はお弁当を二つ買っていた。声＝①駅の売店で写しの母（ひとり）「……二つ、ください」②写しのちよ「母さん、なんで二つ」写しの母「一つは、夜に食べなさい」③写しの母（ひとり。汽車が出た後のホーム）「夜は、さみしいから。……さみしい時に、温かい物があるように」。届ける＝ちよは、汽車の夜に膝の上にあった、まだ温かいお弁当を思い出す。のぼるに電話して、母の卵焼きの味を聞く。ひとこと＝あかり「卵焼き、ちよさんに教わろうかな」（寄り道「あかりのお弁当」とつながる）。絆＝あかり
- **3-2「外れた第二ボタン」（しおり）**：心残り＝卒業式の日、とうやの学生服の第二ボタンが、ひとつだけなかった。声＝①校舎の裏で写しのとうや（ひとり）、第二ボタンを外して握る ②写しのしおり「とうや、ボタン、一個ないよ」写しのとうや「……取れた」③踏切で写しのとうや（ひとり）「渡せなかったな。……まあ、いいか。持ってりゃ、忘れないし」。届ける＝しおりは手紙を書かない。「持ってれば忘れないなら、それでいいや」と笑う（言わないことを選ぶ人を責めない。3-2 の芯）。ひとこと＝小夜子「言わずに持っておくもの、わたくしにもありますわ」。絆＝小夜子。**小夜子の武器の寄り道③を開く**
- **4-1「鈴の鳴る方」（たいち）**：心残り＝シロの首輪の鈴が、いつの間にかなくなっていた。声＝①写しのたいち（ひとり）「シロ、鈴うるさいって言って、ごめん」②写しのおじいちゃん「鈴はな、たいちが迷子にならんように、シロが鳴らしとったんだ」③川の浅瀬で、鈴の音（写しのたいち「……シロ？」）。届ける＝砂の底で見つけた鈴の音を伝える。たいちは、物置の首輪を片付けずに、鈴を付け直して部屋に置く。ひとこと＝あかり「鈴の音、迷子にならないための音、なんだね」。絆＝あかり
- **4-2「花輪の名札」（ジン＝早瀬）**：心残り＝開店の日、名前のない花輪がひとつだけ届いていた。声＝①写しのしずえ（ひとり）、花輪の札に「近所の者より」と書く ②写しのじん「この花輪、誰からだ」写しのしずえ「……近所の方から、って書いてありますよ」③写しのしずえ（ひとり。閉めた店の前）「お店が続きますように。……わたしが、一番のお客さん」。届ける＝早瀬は、名前のない花輪がしずえからだったと知る。「一番の客は、ずっと、あいつだった」。ひとこと＝早瀬「……花輪の札なら、店の奥に掛けてある」。**早瀬の武器の寄り道③を開く**。絆＝みお（届ける場面に一緒にいる。みお×早瀬は寄り添う間柄。`docs/CONCEPT.md` の連携技）
- 声の場面に出る写しの人（写しのまさる・写しのこうじ・写しのちよ・ちよの母・写しのとうや・写しのしおり・写しのたいち・写しのおじいちゃん・写しのじん・写しのしずえ）は、今の台本の人を使う。新しい絵は要らない（ちよの母・おじいちゃんの写しは、今の台本の通りに）
