# スナップの一覧のたたき台（2026-11-04。開発者と相談中）

`M3_battle_review.md` の 11.「スナップを大量に増やすための仕組み」の 1。ネタ切れせずに80枚まで作れるかを、作る前に紙の上で確かめる。数値は入れない（重さと強さは「軽い・ふつう・重い」と「小・中・大」の目安だけ）。
仕組みはラウンドの戦闘のまま（順番はフィルムの帯で1列に見える）。

## 1. 決まり（たたき台）

### 1-1. 属性を6つにする（風と光を足す）
`docs/NAMING.md` で保留にしていた「風（欠片：爽快）」と「光（欠片：希望）」を足す。属性ごとに、**弱点を突いた時のおまけ**を変える。弱点を突くとダウンするのは今と同じで、それに属性ごとのおまけが付く。属性を選ぶ理由が「効くかどうか」だけでなくなる。

| 属性 | 弱点を突いた時のおまけ | 得意な場 |
| --- | --- | --- |
| 物理 | 部位に1.5倍 | なし |
| 火 | **やけど**（ラウンドの終わりに少しダメージ。2ラウンド） | 晴れ |
| 氷 | **こおり**（次のラウンド、順番が一番後ろ） | 雨 |
| 雷 | **しびれ**（次の行動の威力が半分） | 雨 |
| 風（新） | **吹き飛ばし**（ためを崩す。予告を1つ後ろへ） | 風 |
| 光（新） | **あばく**（隠れた弱点を1つ見つけ、次の予告を見せる） | 晴れ |

仲間の属性の受け持ち（案）：小夜子に風、早瀬に光を足す（今は2人とも属性がかぶっている）。ノア・りくは6章で決める。

### 1-2. 状態（新しく足す）
| 状態 | 中身 | 消え方 |
| --- | --- | --- |
| やけど・こおり・しびれ | 上の表 | 時間で消える |
| ねむり | 行動しない | ダメージを受けると起きる |
| 閉じこめ | 次の行動を飛ばす（ぬしは、順番が一番後ろへ） | 1回で消える |
| 攻撃↑↓・防御↑↓・速さ↑↓ | 2ラウンド | 時間で消える |
| ぬれ | 次に受ける雷・氷が1.5倍 | 1回で消える |
| かばう・反撃 | 仲間の状態 | 1ラウンド |
| 踏みとどまり | 1回だけ HP1 で残る | 1回で消える |

### 1-3. 場（天気。新しく足す）
戦場に「晴れ・雨・風・夜」のどれか（ふつうは、なし）。スナップや敵の技で変わり、3ラウンド続く。得意な属性が1.3倍。思い出の場面に合わせて、始めから場がある戦闘も作れる（夏の縁日は夜、4-1 の川は晴れ、など）。

### 1-4. 時代の印（新しく足す）
スナップごとに時代の印（昭和・平成・大正、どれでもない「今」）。**同じラウンドに同じ時代の札を2枚目・3枚目と切ると、威力が上がる**（1.2倍・1.4倍）。アルバムを「昭和で固める」「ばらして、何でも使う」と組む悩みができる。敵から奪うスナップは、その敵の時代の印になる。

### 1-5. 手に入れ方
- **敵のコマ（案2）**：その敵を「よく倒す」と落とす。よく倒すとは、弱点で倒す・部位を壊して倒す・3ラウンド以内に倒す、のどれか（敵ごとに1つ。長押しの説明に出す）。同じ敵から何度でも手に入る（アルバムに入れられるのは4枚まで）
- **ぬしのコマ**：ぬしを倒すと必ず1枚
- **返した時のスナップ**：話ごとに1枚（メモ 19）
- 今の14枚は、そのまま残す

## 6. 数えてみる（ネタが続くか）

全部で **80枚**（今の14・敵のコマ56・返した時10）。

| つまみ | 触れる枚数（1枚で2つに触れる物は両方に数える） | 足りているか |
| --- | --- | --- |
| ダ（ふつうのダメージ・回復） | 28 | 多い。ここだけで差を出すのは、これ以上はむずかしい |
| 状（状態） | 18 | 十分。状態の種類を足せば、まだ増やせる |
| 順（順番） | 15 | 十分。今の帯で見せやすい |
| 札（手札と山札） | 13 | 十分。時代の印で、まだ増やせる |
| 属（属性・弱点） | 9 | 中くらい。風・光を足した分で増えた |
| 場（天気） | 8 | 中くらい。天気を足せば増やせる |
| 予（予告） | 6 | 少なめ。敵の予告がいつも見えるようになれば、もっと作れる |
| 控（控え） | 5 | 少なめ。控えが戦闘に出るようになれば増やせる |

分かったこと：
- 状態・順番・手札の3つのつまみがあれば、80枚でも、使い方の違う札を作れる。ダメージだけの札は今の半分ほどに減らせる
- 予告・場・控えは、仕組みを足すと、まだ作れる余地が大きい（6章以降の分）
- 部位は、ぬしだけにあるので札にしにくい。雑魚にも小さな部位を持たせるか、決める必要がある

## 7. 決めたいこと

1. 属性を6つ（風・光を足す）にするか。属性ごとの「弱点を突いた時のおまけ」（やけど・こおり・しびれ・吹き飛ばし・あばく）でよいか
2. 状態・場（天気）・時代の印を入れるか。全部入れると覚えることが増えるので、章ごとに少しずつ出す（1章は状態だけ、2章で場、3章で時代の印、など）か
3. 敵のコマの手に入れ方（よく倒すと落とす）でよいか
4. アルバムは20枚のままでよいか（80枚から20枚を選ぶ）
5. 雑魚にも部位を持たせるか

## 8. 開発者の指摘と、直しの案（2026-11-04）

### 8-1. 状態が多すぎる
指摘：状態は多すぎると、ややこしさの方が目立つ。
- 状態は**3つだけ**にする：やけど（火）・こおり（氷）・しびれ（雷）。どれも属性の弱点を突いた時のおまけとして付き、2ラウンドで消える。1体に付く状態は1つまで（新しい物で上書き）。フィルムの帯の顔に小さな印で出す
- 攻撃・防御の上げ下げは、状態にしない。「このラウンドだけ」の効き目にする（ラウンドの終わりに必ず消えるので、覚えなくてよい）

**3. 手放す ＝ 捨てた時の効き目**
ラウンドの始めに、手札から好きなだけ捨てて引き直せる（行動を使わない）。捨てた写真は、その札の「手放した時の効き目」を出す（小さい）。
- 例：リカバー＝捨てると、仲間1人の MP が少し戻る。ソード＝捨てると、次に使う物理の札の現像を1段進める。サーチ＝捨てると、次の敵の予告を1つ見る
- 引き直しの駆け引き（いらない札を捨てて、ほしい札を探す）に、「何を捨てると得か」が加わる

**手札のそろい**（あとで足してもよい）
ラウンドの始めの手札に、同じ「写っている人」や「時代」の写真が3枚あると、そのラウンドだけ小さな役が付く（例：あかりの写真が3枚なら、あかりの技の MP が0）。残す札を選ぶ理由が、もう1つ増える。

**敵は、手札に手を出す**
- 露光（光るノイズ）：手札の1枚の現像を1段戻す
- すり切れ：手札の1枚を「色あせ」にする（このラウンド使えない。捨てるのはよい）
- 切り取り（カイ）：手札の焼き付けの写真を1枚奪う。枠の刃を壊すと戻る
- ぬしのお題：「焼き付けの写真で、とどめを刺す」など

### この案のよいところ
- 今の仕組み（手札5枚・補充・アルバム20枚）を、そのまま土台にする。新しい場所や画面は要らない（手札の写真に、現像の段の印を付けるだけ）
- 1枚の札に、育ち方 × 使った時 × 手放した時の3つの面があるので、80枚でも札ごとの違いがはっきり出る。順番の操作に頼らない
- 「残す・使う・引き直す」という、今ある駆け引きが、札ごとに違う形になって深くなる
- 写真・現像・焼き付け・色あせ・インスタント写真と、スナップ（写真）の設定とそのまま結びつく。構想ノートの「スナップの焼き付き」（使い込んだ札が魔法として定着する）にもつなげられる

### 気になるところ
- 札ごとに3つの効き目を覚えるのは大変。手札の札には今の段の効き目だけを大きく出し、長押しで、ほかの段と手放した時の効き目を見せる
- 1章は「育つ」と「一定」だけ、2章で「色あせる」「手放す」、3章で「化ける」、のように少しずつ出す

## 15. 開発者の答え 7 と、コンボを中心にする案（2026-11-04）

開発者：期限の案も、長い戦闘でしか生きない気がする。今すでにあるコンボの仕組みはどうか。

### 今のコンボ
手札に決まった札がそろうと、1人の行動でまとめて使える大技（`src/data/combos.ts`）。今は4つだけ（エレメントバースト・トリプルソード・ブレイククラッシュ・ヒールサークル）。手札は5枚で、使わなかった札は次のラウンドに残るので、「材料を残して集めるか、今1枚で使うか」の駆け引きが、もう入っている。画面にも、手札の上に「あと1枚」の帯が出る。

### 案：コンボを、札の幅の中心にする（思い出のつながり）
ロックマンエグゼのプログラムアドバンスのように、**札の組み合わせそのものを、たくさん用意する**。札1枚ずつに凝った効き目を足すより、組み合わせで新しい技が生まれる方が、80枚から何十通りもの違いが出る。

**1. 2枚のコンボを中心にする**
- 今の3枚のコンボは、そろうまでに時間がかかり、雑魚戦では使いにくい。2枚でそろうコンボを中心にし、3枚は大技（ぬし・ボス向け）にする
- 2枚なら、1〜2ラウンドの雑魚戦でも、手札にあればすぐ使える。短い戦闘でも生きる

**2. レシピは2種類**
- **思い出のつながり**（名前で決まる）：決まった2枚で、物語にちなんだ技になる。例：「金魚すくい」＋「打ち上げ花火」＝「夏祭りの夜」、「二人乗り」＋「サヨナラ打」＝「夕暮れの帰り道」。重なる思い出の絵に写っている人どうしの札を組むと、その2人の思い出の技になる（例：ハルトとあかりの写真2枚＝「二人の帰り道」）
- **型のコンボ**（印で決まる）：どの札でも、印がそろえば出る。例：火の札＋風の札＝「火の粉を巻き上げる」（全体）、同じ時代の札3枚＝「時代の重ね撮り」。名前のコンボを知らなくても、遊んでいるうちに出る

**3. 見つける楽しさ**
- まだ見つけていないコンボは、アルバムの「つながり帳」に「？？？」で並ぶ。手札に初めてそろった時に、名前と絵が出る（「新しいつながりを見つけた！」）
- ヒントは、つながり帳の「？？？」の横に一言（例：「夏の思い出と、夜空の思い出」）
- 新しい区画で新しい札が手に入るたびに、前の札との新しいコンボも見つかる。最後まで、組み合わせが増え続ける（エグゼが飽きなかった理由の1つ）

**4. アルバムを組む悩み**
- 20枚のアルバムに、どのコンボの材料を入れるか。材料を多く入れるほどそろいやすいが、1枚で使う札が減る
- 同じ札は4枚まで（今のまま）

### よいところ
- 今ある仕組み（手札5枚・残る札・コンボの帯・アルバム20枚）を、そのまま広げるだけ。新しい操作は要らない
- 「何を残すか」が、「どのコンボを狙うか」になる。今ある駆け引きが、そのまま深くなる
- 2枚のコンボなら、雑魚戦の短い戦闘でも生きる
- 思い出どうしがつながって技になる、という形が、話の主題（思い出・つながり）と合う。絵（重なる思い出）とも結びつく

## 16. コンボと現像を両方入れる（2026-11-04。開発者の案）

開発者：コンボの仕組みと、現像が進む仕組みの2つを採用するのはどうか。要素が多すぎるか。

考え：多すぎにはならない。2つとも「手札に残す」という、今ある1つの判断を深くする物で、別々の判断を増やさないため。
- **役わりが分かれる**：雑魚戦（1〜3ラウンド）は、2枚のコンボがすぐ効く。ぬし・ボス（6〜10ラウンド）は、残して現像を進め、焼き付けた札やコンボで大きく返す。前に決めた「ぬしは特別な決まり、ボスはふつうの戦闘の楽しさ」とも合う
- **かみ合う**：コンボの材料を集めて残している間に、材料の現像も進む。焼き付けた材料で組むと、コンボも強くなる（「焼き付けのコンボ」。あとで足してもよい）
- **手札が詰まりにくい**：現像だけだと、育てる札で手札が詰まる（期限が要った）。コンボは2〜3枚を一度に使うので、手札が空き、新しく引ける。期限は要らない
- **覚えることを減らす工夫**：
  - 現像で変わる札は、一部だけにする（80枚のうち2〜3割）。ほとんどは今までどおり変わらない
  - 札の段は、写真の下の小さな点（●○○）で見せる。変わる札だけに点が付く
  - コンボを使うと、材料は撮りたてに戻る
- **章ごとに出す順（案）**：1章 コンボ（今ある）→ 2章 2枚のコンボと、現像（育つ札だけ）→ 3章 色あせる・化ける札、つながり帳 → 4章 型のコンボ、焼き付けのコンボ
