## 1. 今の様子
- スナップは **90種類**（4章まで）。目安は「5章の終わりで約30、終章で約45＋やり込み約8」（`docs/design/economy.md` の 3.）
- 内訳
  - **敵のスナップ 45**：敵1種類に1枚。★3で早く勝つと、ときどき手に入る（段階165）。目安を決めた時（段階55）にはなかった
  - **それ以外 45**：はじめから10・ぬし11・宝箱22・時間を返す8・交換所10・砂の底3・なんでもない1（重なりあり）
- 区画ごとに増える量：敵のスナップが約5、それ以外が約4。**このままだと終章で約170**になる（区画は終章まで約18）
- スナップの絵は **14枚**。90種類で使い回している（1枚の絵を最大21種類が使う）

### まとめ
- いちばん困るのは「**この先も区画ごとに9枚ずつ増え続ける**」ことと「**似た物が多く、絵も足りないので、1枚ずつの印象が薄い**」こと。今の90は、アルバムの絞り込みとライブラリの「手に入る所」で、まだ扱える
- A は今を守れるが、先で困る。C は戦い方の土台を削るので向かない。D は判断の先送り
- **おすすめは B**：敵のスナップは「その敵らしい、変わった仕組みの物」を区画に2枚（雑魚1・ぬし1）だけ残す。似た働きの物は残した方にまとめる。これからの区画も「ぬし1・敵2・宝箱1・返す1」の5枚を上限にする
- B にする時は、目安の文書（`docs/design/economy.md` の 3.）も「終章で約110（区画5枚×約18＋砂の底など）」に直す
