### 試して分かった好み
- 好き：敵の予定が見えて、それに合わせて並べる。「サポート → アタック → フィニッシュ」の流れ（効果を読まなくても選べる）。決められた時間の枠に攻撃を詰めていく（連続の試し。開発者の好み）
- 苦手：分類や状態が多い。条件が読まないと分からない。円の上の順番（文字盤）。自動で次々流れる実行
- 方針：要素を増やさず、仕組みを真似ずに、カードゲームのような戦略性（1枚では弱く、組むと強い）。今の効果に合わせて敵の縛りを作る安直な案は避ける。「時間の使い方」は、本来ギアの効果であるべき

## 2. 検証で繰り返し起きたこと

1. **勝ち筋が「弱点 → ダウン」の1本に戻る**（本番の戦闘：弱点をねらう方針で93〜100%。調整5：勝ち筋の中心は弱点のダウン。調整14：シャッター決着96%。調整16：つながりの多くはパノラマ → 弱点 → フィニッシュ）。弱点だけが大きな倍率で、しかも一度分かれば毎回同じだから。新しい仕組みは、弱点の道に乗る物（パノラマ・ハイライト）だけが生き残った
2. **後で効く物は、短い戦闘で死ぬ**（段階155の現像・ため、調整7の状態、調整13〜16のサポート）。雑魚戦は1〜2ラウンドなので、「今の行動を1回あきらめて、後で得をする」が元を取れない。雑魚戦を短くしたいという W2 と、後で効く仕組みは両立しない
3. **足すと分かりにくくなり、引くと戻る**（調整3〜5、調整10〜12）。印・共鳴・型・状態・特徴を足すたびに「分かりにくい」となり、名前と数を減らして戻った。スマホでは、覚える物の数に上限がある
4. **見えない物は遊べない**（文字盤の順番、続けて流れる実行、札の文に書いた条件）。楽しさは「見えて、追える」ことが前提
5. **変化は敵から生まれる**（調整3〜6・12）。勝ち方が変わったのは、敵の特徴・組み合わせ・型を変えた時。札を増やしても、敵が同じなら同じ解き方になる
6. **仲間の違いが薄い**（調整16の連続：1ラウンドで一番動く仲間が59%。よく使う行動の上位は、いつでも使える軽い技）。仲間の違いは属性と数字だけで、役目の違いがない
7. **時間の予算が効くのは、枠が足りない時だけ**（調整6：1ラウンドに使う時間は10のうち6.7、全員が入らないラウンドは0%。調整16の連続で、初めて「枠に詰める」悩みが生まれた）

## 3. 根幹に求める条件

2.の繰り返しを避けるために、根幹の仕組みが満たすべき条件：

- C1 **勝ち筋が1本に固まらない**：大きな倍率の源を、弱点だけにしない。複数の源が、組み方によって入れ替わる
- C2 **そのラウンドの中で報われる**：雑魚戦が1〜2ラウンドでも、組み合わせの見返りが同じラウンドに出る
- C3 **決まりは少なく、1つの決まりから幅が出る**：覚える物を増やさず、組み合わせで遊びが増える
- C4 **つながりが見える**：並べている時に、どこがつながるかが帯の上で見える。札の文を読まなくても分かる
- C5 **敵が組み方を変えさせる**：敵の予定と特徴が、つながりを切ったり伸ばしたりする
- C6 **仲間ごとに役目が違う**：誰に何をさせるかが悩みになる。1人に寄らない
- C7 **短く、手数が少ない**：雑魚戦は1ラウンドに数手。でも考えることはある
- C8 **時間の話と結びつく**：フィルム・写真・時計の言葉で説明できる

## 4. 根幹の案：「持ち時間の帯」と「つながり（連写）」

### 4-1. 決まりは3つだけ
1. **敵の予定は見えている**（今のまま）：全員の行動が、1本の時間の帯（左から右）に並ぶ
2. **仲間はそれぞれ自分の持ち時間を持つ**：3人それぞれが、短い持ち時間（例：6マス）の中に、札と技を重さの分だけ詰める（連続の試しの「枠に詰める」楽しさを、1人ずつにする）。全員の行動は時刻の順に動く
3. **つながり（連写）**：仲間の行動が、**間に敵の行動をはさまずに続く**と、つながる。つながるほど、1つずつの威力が上がる（例：1つ目は等倍、2つ目は1.5倍、3つ目は2倍…）。敵が1回でも動くと、そこで切れる

### 4-2. この3つで何が起きるか
- **組むと強い**（C2・C3）：1枚ずつは弱い。でも、3人の帯の行動を、敵の行動の隙間に、時刻をそろえて詰めると、つながって大きくなる。遊戯王の「1枚では弱く、組むと強い」を、札の条件文でなく、帯の並べ方で作る
- **敵の予定が組み方を変える**（C5）：敵の行動の時刻が、つながりを切る「壁」になる。押す（敵の予定を後ろへずらす）・ダウン（その敵の行動を消す）は、壁をどかして、つながりを伸ばす手段になる。敵の特徴（割り込み・2回行動・予定隠し）は、そのまま「壁の位置が変わる」「壁が増える」になる
- **弱点は道の1つ**（C1）：弱点のダウンは、壁（その敵の次の行動）を消す手段の1つで、倍率の源ではなくなる。壁の消し方は、押す・ダウン・倒す・速さで先に詰める、と何通りもある。大きな倍率の源は「つながりの長さ」で、長さの作り方は手札と敵で毎回変わる
- **偏らない**（C6）：持ち時間は1人ずつなので、1人に集められない。誰の帯に何を入れて、どの時刻にそろえるかを考える
- **見える**（C4）：3人の帯を縦に重ねて見せれば、同じ時刻の列がつながりとして見える（帯の上に「×1.5」「×2」）。敵の行動は赤い縦線で、そこで切れるのが一目で分かる
- **短い**（C7）：1人あたり2〜3手で、1ラウンドに6〜8手。雑魚戦は、つながりがうまくいけば1ラウンド、ふつうは2ラウンド

### 4-3. 今ある物の役目（足さずに、置き直す）
| 今ある物 | 根幹の案での役目 |
| --- | --- |
| サポート | つながりの「起点・つなぎ」。軽く（重さ0〜1）、ダメージは小さいが、つながりの数に入る・壁をどかす（押す・ダウンを作る） |
| アタック | つながりの「中身」。ふつうの威力。属性で弱点を突けば、壁（その敵の行動）を消せる |
| フィニッシュ | つながりの「締め」。つながりの長さで大きく伸びる（例：つながり倍率がもう一段乗る）。長くつないだ最後に置きたい |
| シャッター（総攻撃） | つながりが一定（例：5）に達したら撮れる、つながりの締めの大技。全員ダウンの条件はやめる（弱点の一本道に戻らないため） |
| 連携技 | 2人の帯をまたいで、同じ時刻に置く大技。2人分の行動として、つながりを2つ進める |
| 仲間の技 | その仲間の役目そのもの（下の 4-4）。いつでも使えるが、軽い詰め物にはしない（重さ1の軽い行動と押すは札だけ。調整16の「詰め物が毎回同じ」を避ける） |
| 敵の特徴 | 壁の数・位置・強さを変える。今の15個のうち、壁と関わる物（割り込み・2回行動・予定隠し・足止め・かばう・バリア）が中心になる |
| 状態（スロー・クラックなど） | 多くは外す。残すなら「このラウンドの間」だけ効く物に（2.の 2 のとおり、後で効く物は死ぬ） |

### 4-4. 仲間の役目（持ち時間の使い方で分ける）
- ハルト：重い一撃とフィニッシュ。帯の後ろで締める役
- あかり：属性と回復。弱点で壁を消す役
- みお：軽い行動と押す。壁をどかして隙間を作る役
- 持ち時間の長さや、つながりの数え方の違い（例：みおの行動はつながりを2つ進める）は、開発者の「時間の使い方はギアの効果であるべき」に合わせ、育成（ギア・ムーブメント）で足す

### 4-5. 戦闘の種類ごとの使い方（開発者の方針どおり）
- 雑魚戦：この根幹そのまま。短く、敵の組み合わせで毎回違う
- ぬし：その思い出の別の決まり（案5）。根幹の帯は使うが、勝ち方が違う
- ボス：根幹を突きつめる。壁の多い・形の変わる相手

## 5. やめる物・残す物

- **残す**：敵の予定が見える／左から右の1本の帯／重さと時刻／押す・ダウン／敵の特徴と決まった組み合わせと型／サポート → アタック → フィニッシュ／総攻撃の気持ちよさ／専用の札と連携技／早く勝つほど良い報酬／弱点は当てて分かる
- **やめる**：1人1回（全員で1本の時間を分ける形も）／全員ダウンでシャッター／弱点だけが大きな倍率／数ラウンド続く状態の大半／条件文で強くなる札の大半（多重露光・焼き付けなどの「直前が◯◯なら」）／いつでも使える重さ1の技

## 6. 心配な所

- 帯が4本（仲間3＋敵1）になり、スマホの縦の画面に収まるか。文字盤の失敗（読み取れない）をくり返さないよう、先に絵で確かめる
- つながりの倍率が、また「一番長くつなぐ」という1本道にならないか。壁の位置が敵ごとに変わるので、つなぎ方は毎回変わるはず。自動対戦で確かめる（最初の一手のばらけ方、使われる札の散らばり）
- 今の本番の戦闘（`src/core/battle.ts`）とは大きく違う。本番に入れるなら、1〜4章の敵と数値を作り直す大きな仕事になる（186戦）
