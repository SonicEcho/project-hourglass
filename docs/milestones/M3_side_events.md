# 寄り道の依頼（サブイベント）のたたき台（2026-11-17。開発者と相談中）

開発者の声：依頼はもう少し全体的に増やしたい。がっつり物語に関係しなくてよいので、サイドストーリーのような物（テイルズ オブ ヴェスペリアのサブイベントのような物）がほしい。

## 1. 目指す手ざわり
- **短い**：1話は1〜3分。会話が中心で、たまに砂の底や探索で何かを探す
- **軽い**：笑える話、ちょっと切ない話、仲間の意外な一面。物語の大事なことは入れない（見なくても本編は分かる）
- **つながる**：同じ人の話が、章をまたいで2〜4話続く（「あの人、その後どうなった？」が楽しみになる）
- **町が生きて見える**：昼の町・レストピア・記憶の中に、顔なじみが増えていく
- 物語の軸（`docs/STORY.md` の 2-0）に合わせる：失くすのは思い出。体の時間が減る書き方はしない

## 3. 起き方と遊び方（案）
- 昼の町に、新しい印「**？（寄り道）**」を出す。**昼に選べる回数は使わない**（絆と小話の「2つ選ぶ」は今のまま）
- 拠点に「**寄り道の帳面**」：受けている寄り道・次はどこで何が起きるかの一言・見逃した話の読み返し（町の小話と同じ考え）
- 探す物がある話は、砂の底か探索で見つける（今の落とし物の声のかけらと同じ作り）
- ご褒美は控えめ：絆の足し・仲間のひとこと・記憶の欠片・素材少し。連作の最後だけ、ギアかスナップ（スナップの数の相談 `docs/milestones/M3_snap_count.md` と合わせる）。ライブラリに「寄り道の記録」を足し、見た話を集める楽しみにする

## 4. 話の候補（2〜4章。まずは 12 ほど）

### 町の頼まれごと
1. **商店街のくじ引き（3話。2章〜4章）**：※福引の係のおじさん。「特賞が出ない」と嘆く → みおが手品の腕で疑い出す → 実は特賞の札を入れ忘れていた。最後は、みんなで1回ずつ引く（ハルトだけ毎回ティッシュ）
2. **駄菓子屋の看板猫（2話。3章〜4章）**：※駄菓子屋のおばあさん。猫がいなくなった → 見つけたら、あかりの施設の子どもたちが匿っていた

### 仲間の寄り道

5. **あかりのお弁当（2話）**：料理を練習するあかり。味見役のハルトの感想が、毎回ずれている
6. **小夜子の知らない言葉（3話。3章から）**：大正から来た小夜子が、今の言葉（「エモい」「スマホ」など）を一つずつ覚える。使い方が少しずつおかしい
