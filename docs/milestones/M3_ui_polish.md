## 2. 進め方の案
- **A（おすすめ）：先に「見た目の決まり」を1枚決めてから、よく見る画面から順に当てる**
  1. 決まり：テーマ（例：真鍮の時計と古い写真。砂時計・歯車・フィルムの飾り）、色（画面ごとの差し色は残し、地・枠・文字の色はそろえる）、ボタン・箱・一覧の行・タブの形
  2. 決まりを部品（`src/ui`）に入れる → 全部の画面が少しずつそろう
  3. よく見る画面から作り込む：拠点 → 戦闘 → 会話 → 星図・武器・ムーブメント → 砂の底 → 一覧（アルバム・ライブラリ・落とし物・交換所）→ タイトル
  4. 要る絵（枠の飾り・アイコン・背景の模様）は、まとめて絵の依頼文を出す
- B：画面を1つずつ、その画面だけで作り込む（早く変わって見えるが、画面ごとにまたずれやすい）
- C：絵（枠・ボタンの素材）を先に頼み、届いてから当てる
