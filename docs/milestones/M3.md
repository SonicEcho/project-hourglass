## 作業の進め方

- M2 の終わり（段階77〜86）と同じ：**1話ずつ「脚本 → 確かめてもらう → 遊べる形に」**。話の形は「気づく → 記憶に入る3晩 → 返す → その後」（`docs/STORY.md` の 2-16）。脚本は `docs/script/` に話ごとに書く
- 段階は、この文書に「依頼する内容」と「スマホで確かめること」を書いてから作る。脚本の段階は、確かめが済むまでゲームの台本を変えない
- 新しい仕組み（小夜子の加入と編成、スナップ昇格、返すか残すかの選択など）は、作る段階で `docs/design/` に書き足す
- 絵と音は、色の札・文字の地図・使い回しの曲で先に作り、開発者の素材が届いたら入れる（M2 と同じ）
