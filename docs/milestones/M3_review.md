## A. 物語の土台

### A1. 「盗まれても誰も困らない」という前提と、各話の描き方を合わせる

- **問題**：`docs/STORY.md` の 2-6 は「時間を盗まれても、過去の人が困ることはない（大前提）」とし、未来の人も局長も悪人ではない形にしている。ところが 2-16 の決まり1「今の痛みを先に見せる」で書き直した各話では、盗みがはっきり人を傷つけている（1-1：ゆうまが名前を忘れて「金魚くらいで泣くなよ」と言い、兄妹が2年話せない。1-2：ふみが夫の顔と声を思い出せない）。遊ぶ人は「保管局は人の人生を壊している」と受け取る。すると、5章の局長の「誰も困らない」という誇りが、ただの無知か開き直りに見えてしまう。「本当の悪はヴィクトだけ」も、7〜8章の「アーカイバーも被害者」への共感も弱くなる
- **直し方の案**
  - **案A（おすすめ）：取り込む**。2-6 の大前提を「時間保管局は、誰も困らないと信じている（本当は困っている人がいる）」と書き直す。5章で、局長に、1章から返してきた持ち主たちのその後を見せる場面を置く。局長が初めて被害を知って揺らぐ（局長の欠点「頑固さと仕事への誇り」がそのまま生きる）。6章のハルトの罪悪感も重くなる
  - 案B：被害を弱める。各話の「今の痛み」を、盗みのせいではない別の理由にずらす（1-1 から書き直しが要り、各話の芯が弱くなる）
- **決めること**：案A か案B か。案A なら、局長が被害を知る場面を 5章のどこに置くか
- **直す所**：`docs/STORY.md` の 2-6・2-9（5章）・2-10（局長はないので 2-6 の局長の項）、`docs/CONCEPT.md` の同じ所。4〜5章の脚本を書く前に
- **いつ**：4章の脚本の前（3章の段階 93〜96 と並べて、文書だけ先に直す）

### A3. 各話の型を崩す話を入れる

- **問題**：1-1〜3-1 の6話がすべて「忘れた一瞬 → 誤解やすれ違い → 3晩で見る → 返す → 翌日に和解や涙」。1話ずつは良いが、6話目には先が読める

- **問題**：ハルトの台詞 529 のうち **82% が「……」で始まる**（あかり 34%、みお 24%）。平均 14字（あかり 18字、みお 20字）。表情は「通常」が 57%。「……」の重みがなくなり、本当に言葉に詰まる場面が効かない。1章で決めた持ちネタ（朝に弱い、料理と裁縫が妙にうまい、「一番いい瞬間」が分かる勘）が台本にほとんど出ない
- **直し方の案**
  - 「……」で始まる台詞を半分以下にする。残すのは、詰まる・ためらう・言いよどむ場面だけ
  - 各話に、ハルトから話しかける台詞・提案する台詞を2〜3か所足す
  - 持ちネタを、昼の場面に1話1回は出す（施設の朝、弁当、ボタン付けなど）
  - 決め所の本音（「弟と妹が、十二人いる。血は、つながってないけど」のような台詞）は、今の強さのまま残す
  - 書き方の決まり（`docs/script/M1.md` の 0.）に「ハルトの『……』は、詰まる時だけ」を足す
- **直す所**：`src/data/scriptM1.ts`〜`scriptM3.ts` と、元の脚本（`docs/script/`）。1-1 から順に
- **確かめ方**：台詞の数え方を小さなスクリプトにして、直す前と後の割合を記録する（目安：「……」始まり 40% 以下）
- **いつ**：1つの段階として、1章・2章・3章の順に（3章の新しい脚本は、段階93 から最初からこの決まりで書く）

### B2. ノアの出番を増やす

- **直し方の案**

  - 2章の「遠くから見ている」を、1場面から2〜3場面に増やす（白い人影、棚の上の足音）
  - 3章の口論（段階95）で、ノアの人柄（合理主義、早送りしたがる、猫に好かれる）を1つは見せる
- **決めること**：2-8 の「章に1回」を「章に1回の会話＋ひとりの場面」に広げてよいか
- **直す所**：`docs/STORY.md` の 2-8・2-10（ノア）、1〜2章の台本、3章の終わりの脚本
- **いつ**：3章は段階95。1〜2章へ足すのは B1 と一緒に

### B3. あかりの表情と場面を広げる

- **問題**：あかりの表情は「微笑み」「心配」「驚き」が多く、「泣き笑い」が 33回（全員で 102回）。泣き笑いが感情の決め手として使われすぎている。持ちネタ（方向音痴、怖がりなのにホラー映画を見たがる、写真3万枚、お母さんっぽい小言）が日常に出る場面が少ない。7章の「離れる → 取り戻す」が刺さるには、ふだんのあかりをもっと好きにさせたい
- **直し方の案**
  - 泣き笑いを全員分見直し、各話の決め所（1話に2〜3回）以外は、別の表情（照れ、さみしげ、微笑み）に替える
  - あかりの持ちネタを出す絆の出来事・小話を、1〜3章の昼に足すか、今ある場面に混ぜる（`docs/STORY.md` の 2-12 の「あかり」の一覧から）
- **直す所**：`src/data/scriptM1.ts`〜`scriptM3.ts`、`src/data/daily.ts`
- **いつ**：B1 と同じ段階で

### B4. カイの台詞を、カイらしい言葉に

- **問題**：「ガキが三人か」「遅い。……全部、遅い」「無理だろうがな」と、どこかで聞いたライバルの言い回しが続く。ほかの人物の台詞が生活の匂いのする言葉なので、カイだけが浮く
- **直し方の案**：カイの仕事（一番楽しい瞬間を、枠で切り取る）から言葉を作る。シャッター・枠・露光・ピントの比喩、「一番いい瞬間」を見る目の自慢など。ハルトのシャッターの勘（2-11 の伏線）と響き合うが、正体に結びつける言い方はしない（2-15 の決まり）
- **直す所**：`src/data/scriptM2.ts` の `d7_kai`・`d7_taken`・2-3 の4晩目、3章のリベンジの脚本（段階95）
- **いつ**：段階95 の脚本の時に、2章の分も一緒に

### B5. 人物ごとに、文の長さと口調の差をつける

- **問題**：1行1文の短い台詞は、スマホで読みやすい。ただ全員が短いので、読み味が似通う
- **直し方の案**：書き方の決まり（`docs/script/M1.md` の 0.）に、人物ごとの文の長さと口癖の目安を足す（例：みおは勢いで長め、小夜子は古い言い回しでゆったり、いさむ・まさるは方言と短い言い切り、ノアは結論から）。新しい脚本から守る
