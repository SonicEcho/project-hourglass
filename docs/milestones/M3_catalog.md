# ゲーム全体の一覧（2026-11-07。たたき台 2。開発者と相談中）

`docs/milestones/M3_battle_migration.md` の 7.：星図・スナップ・武器の成長など、ゲーム全体で限りがある物は、継ぎはぎにせず先に全部決めてから、章ごとにどこまで出すかを決める。①一覧を先に全部（名前・役目・おおよその強さ・出す章）②細かい数字は、その章を作る時に自動対戦で測って決める。

名前はすべて仮（決める時に `docs/NAMING.md` の写真・映像・時間の言葉にそろえる）。強さは「威力 ≒ ダメージ」（調整17の目安。雑魚1体の HP は約70〜170）。

## 0. 前提（決まったこと）
- 戦闘の根幹は、並べてつなぐ戦闘の調整17（`docs/milestones/M3_battle_rethink.md` の 14.）
- **札の分類（2026-11-07。映像の言葉に）**：
  - **アクション**（攻撃と回復。時間の帯に置く）
  - **エフェクト**（重さ0でアクションや技に添える。前の「サポート」）
  - **クライマックス**（ラウンドの最後の行動・添えられない。前の「フィニッシュ」）
  - スペシャル（仲間の専用の札）・コンボ（クライマックス扱い）
- 技（星図で覚える魔法・スキル）は全部 MP を使う（通常攻撃だけ MP なし）。消費アイテムはなくし、回復はアクションの札で
- 属性は物理・火・氷・雷の4つ。**6章で光と影を足す**（ノアとりくの属性。1〜5章の敵には光・影の弱点を付けない）
- 連続攻撃はいつでも全段。中断ありの札（邪魔されると不発）は数枚まで
- **スナップは8章までに約120種類**（デッキ構築の幅のため）。**アルバムの枚数は章ごとに広げる**：1〜2章 20枚、3〜5章 25枚、6章から 30枚

## 10. スナップの絵（2026-11-07）
`docs/ART.md` の 5-7（スナップは技の絵ではなく、その技を思わせる誰かの大事な一瞬の写真）をそのまま使い、分類ごとに写す思い出を分ける。
| 分類 | 写す思い出 |
| --- | --- |
| アクション・エフェクト・クライマックス | 仲間どうしの思い出。1〜2章はハルトとあかり、仲間が加わる章から、その仲間と一緒の一瞬が増える |
| スペシャル | その仲間自身の大事な一瞬 |
| 敵のスナップ | その砂嵐の元になった物が、持ち主の時間の中にあった一瞬（例：鳩時計ノイズ → 持ち主の家で鳩時計が鳴っていた夕方） |
- 絵は約130枚。章を作る時に、その章で出す札の分だけ作る（それまでは仮の絵）

## 11. 敵のスナップをネタ切れさせない作り方（2026-11-07）
敵の技をそのまま札にすると、ほとんどがただのダメージになり、ネタ切れする。次の2つで作る。
1. **敵の性質から作る**：かばう → 味方の代わりに受ける／分裂 → 当たると威力半分でもう2回／割り込み → 敵の予定の前に割り込む／巻き戻し → このラウンドに受けたダメージを回復／逃げ足 → 次の行動が1マス早まる／リーダー → このラウンド味方全員が少し強い
2. **アクションにエフェクトを1つ組み込む**：「連写＋押す」「ワイドショット＋ハイライト」「速写＋アタック+20」など。形の違うアクション約10 × エフェクト約15 ＝ 150通り。1枚で2枚分の働きなので、敵からもらう特別な札になる
- 似た敵（分裂で出る小さい水風船など）は札を出さない
- 敵の性質の一覧を、スナップの次に作る（性質が決まらないと、1.が作れない）

## 12. 敵の性質（2026-11-08。たたき台）
名前は、よくあるゲームの言葉にする（調整12で開発者と決めた）。決まり：
- **答え方が2つ以上ある**性質にする（1枚の札でしか解けない縛りにしない。調整16の前に開発者が「安直な縛りは避けたい」）
- 1つの区画で使う性質は2〜3つまで。決まった組み合わせ（エグゼの編成）で、性質どうしが助け合う組を作る
- 新しい性質は章ごとに少しずつ（7.の柱C「章ごとに新しいできること」）。前の章の性質も、組み合わせを変えて出し続ける

### ボスとぬし（性質とは別の仕組み）
- **部位破壊**（残す）：壊すと、その部位を使う大技が予定から消える。隠れた弱点が出る（今の本番と同じ）
- **ため**（性質と同じ）と**段階**（HP が減ると、予定の型と性質が変わる）
- **ぬしは思い出の再演**：その思い出の場面の決まりで戦う（区画を作り直す時に、ぬしと一緒に作る。例：金魚鉢のぬし「ポイが破れる前に」）
- **ボス**（カイ・イリス・ヴィクトなど）は、ふつうの戦闘を突きつめる：性質を3〜4つ持ち、段階で入れ替わる
