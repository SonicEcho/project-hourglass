# ゲーム全体の一覧（2026-11-07。たたき台 2。開発者と相談中）

`docs/milestones/M3_battle_migration.md` の 7.：星図・スナップ・武器の成長など、ゲーム全体で限りがある物は、継ぎはぎにせず先に全部決めてから、章ごとにどこまで出すかを決める。①一覧を先に全部（名前・役目・おおよその強さ・出す章）②細かい数字は、その章を作る時に自動対戦で測って決める。

名前はすべて仮（決める時に `docs/NAMING.md` の写真・映像・時間の言葉にそろえる）。強さは「威力 ≒ ダメージ」（調整17の目安。雑魚1体の HP は約70〜170）。

## 0. 前提（決まったこと）
- 戦闘の根幹は、並べてつなぐ戦闘の調整17（`docs/milestones/M3_battle_rethink.md` の 14.）
- **札の分類（2026-11-07。映像の言葉に）**：
  - **アクション**（攻撃と回復。時間の帯に置く）
  - **エフェクト**（重さ0でアクションや技に添える。前の「サポート」）
  - **クライマックス**（ラウンドの最後の行動・添えられない。前の「フィニッシュ」）
  - スペシャル（仲間の専用の札）・コンボ（クライマックス扱い）
- 技（星図で覚える魔法・スキル）は全部 MP を使う（通常攻撃だけ MP なし）。消費アイテムはなくし、回復はアクションの札で
- 属性は物理・火・氷・雷の4つ。**6章で光と影を足す**（ノアとりくの属性。1〜5章の敵には光・影の弱点を付けない）
- 連続攻撃はいつでも全段。中断ありの札（邪魔されると不発）は数枚まで
- **スナップは8章までに約120種類**（デッキ構築の幅のため）。**アルバムの枚数は章ごとに広げる**：1〜2章 20枚、3〜5章 25枚、6章から 30枚

## 10. スナップの絵（2026-11-07）
`docs/ART.md` の 5-7（スナップは技の絵ではなく、その技を思わせる誰かの大事な一瞬の写真）をそのまま使い、分類ごとに写す思い出を分ける。
| 分類 | 写す思い出 |
| --- | --- |
| アクション・エフェクト・クライマックス | 仲間どうしの思い出。1〜2章はハルトとあかり、仲間が加わる章から、その仲間と一緒の一瞬が増える |
| スペシャル | その仲間自身の大事な一瞬 |
| 敵のスナップ | その砂嵐の元になった物が、持ち主の時間の中にあった一瞬（例：鳩時計ノイズ → 持ち主の家で鳩時計が鳴っていた夕方） |
- 絵は約130枚。章を作る時に、その章で出す札の分だけ作る（それまでは仮の絵）

## 11. 敵のスナップをネタ切れさせない作り方（2026-11-07）
敵の技をそのまま札にすると、ほとんどがただのダメージになり、ネタ切れする。次の2つで作る。
1. **敵の性質から作る**：かばう → 味方の代わりに受ける／分裂 → 当たると威力半分でもう2回／割り込み → 敵の予定の前に割り込む／巻き戻し → このラウンドに受けたダメージを回復／逃げ足 → 次の行動が1マス早まる／リーダー → このラウンド味方全員が少し強い
2. **アクションにエフェクトを1つ組み込む**：「連写＋押す」「ワイドショット＋ハイライト」「速写＋アタック+20」など。形の違うアクション約10 × エフェクト約15 ＝ 150通り。1枚で2枚分の働きなので、敵からもらう特別な札になる
- 似た敵（分裂で出る小さい水風船など）は札を出さない
- 敵の性質の一覧を、スナップの次に作る（性質が決まらないと、1.が作れない）

- **2026-11-10 開発者と決めた**：敵のスナップは、その敵の**性質**（ぬしは思い出の再演の決まり）を、こちら向けにした札にする（12.の表の「敵のスナップにすると」の列）。技をそのまま札にすると（物理30を2回・敵全体に雷など）、先の章のふつうのアクションとかぶるため。性質のない 1-1 の敵だけは技から作った

## 12. 敵の性質（2026-11-08。たたき台）
名前は、よくあるゲームの言葉にする（調整12で開発者と決めた）。決まり：
- **答え方が2つ以上ある**性質にする（1枚の札でしか解けない縛りにしない。調整16の前に開発者が「安直な縛りは避けたい」）
- 1つの区画で使う性質は2〜3つまで。決まった組み合わせ（エグゼの編成）で、性質どうしが助け合う組を作る
- 新しい性質は章ごとに少しずつ（7.の柱C「章ごとに新しいできること」）。前の章の性質も、組み合わせを変えて出し続ける

## 14. 敵の種類と、強いバージョン（2026-11-08。開発者と決めた）
- 性質は、敵の種類をまたいで使い回す部品。同じ性質でも、弱点・予定の型（何を・いつ・誰に）・攻撃の属性・HP・組み合わせの中の役目で、別の敵になる。1体の性質は、序盤は1つ、後半や強い敵は2つ
- **基本の種類：約70種類**（今の4章までの56種類 ＋ 5〜7章の時代の新しい敵 約15種類。砂嵐はその時代の物から生まれるので、時代の違う章には新しい敵が要る）
- **強いバージョン：約30種類**。少し違う見た目で描き直す（色違いではなく新しい絵）。HP と攻撃を上げるだけでなく、予定の型を1つ変えるか、性質を1つ足す。出す所：ぬしの前の強い組み合わせ／8章の最後の収集（それまでの章の砂嵐が強くなって戻る）／狩り
- どの区画でも、同じ敵を違う編成・違う予定の型で出す（組み合わせと型）
- **敵のスナップ**：基本の種類から約40種類。**強いバージョンからは「改」の札**（約30種類）。改は上位ではなく別の形にする：強いバージョンで変わった所（足した性質や予定）を札にも足し、重さなどで釣り合わせる。例：めんこ乱れ打ち（全体に物理）→ めんこ乱れ打ち・金（全体に物理。重さ +1、かたい・バリアに強い）。基本の札が要らなくならないように

### 17-2. 武器の受け持ち：通常攻撃の形
新しい戦闘では、通常攻撃だけが MP なしで使える。そこで、**武器が育つと、通常攻撃の形が変わる**ことにする。星図は技（MP を使う）、アルバムはスナップ、武器は通常攻撃とその人の得意、と受け持ちを分ける。
- 例：ハルトの刃の系統は通常攻撃が 物理1回 → 2回 → 3回。みおの手品の系統は通常攻撃に「押す1」。早瀬の時間の系統は、通常攻撃で敵の予定を1マス後ろへ（最後の段だけ）
- 通常攻撃が変わるのは、どの系統も 1回目・3回目・最後 の3回（ほかの回は能力値と効果）

## 18. ムーブメントのギア（2026-11-08。たたき台。同じ日に「付け替えの良さを活かす」形に書き直した）
今のムーブメント（`docs/design/growth.md` の 3.、`src/data/navi.ts`）：仲間ごとに盤を1枚。ギアは色付きのブロック（1〜4マス。回して置ける）。能力値ギアはどこでも効き、効果ギアは盤の「ブリッジ」（左から2列目の縦の帯）に乗っている時だけ効く。同じ色のギアが辺で接すると「狂い」（1つにつき、ラウンドの始めに最大HPの5%を失う）。色は赤（銅）・青（鋼）・緑（青銅）・黄（真鍮）。ギアは宝箱と出来事のごほうびで手に入る（戦闘では手に入らない）。2章から開く。今あるギアは能力値6・効果10。

### 18-0. 方針（開発者：ギアは星図や武器と違い、キャラごと・場面ごとに付け替えられるのが特徴。その良さを活かしたい）
- **広く効く物は星図と武器、狭く強い物はギア**。星図と武器は外せない投資なので、いつも効く物しか置けない。ギアは外せるので、相手を選ぶ物・場面を選ぶ物・損もある物を受け持つ
- 効果ギアを4つの役目に分ける：①いつも効く ②**対策**（敵の性質に強い）③**条件**（場面を選ぶ）④**両刃**（得と損）
- 付け替える理由（区画の予告）と、付け替えの手間を減らす仕組み（組み合わせの保存）を一緒に入れる。どちらかが欠けると、付けっぱなしになる

### 18-2. 色の意味
| 色（金属） | 得意 | 属性 |
| --- | --- | --- |
| 赤（銅） | 攻め：部位・重い一撃・かたい・バリア・ボス | 火・影 |
| 青（鋼） | 技：MP・エフェクト・長回し・見抜く | 氷 |
| 緑（青銅） | 守り：回復・軽減・反撃や爆発を防ぐ | 光 |
| 黄（真鍮） | 時間と手札：押す・予定・スナップ・コンボ・数の多い敵 | 雷 |
- 同じ方向を強くしたいほど同じ色が並び、狂いやすい。強くしたい方向と狂いの悩みがぶつかる
- 武器の進化の「傾向」は、その系統の得意の色にそろえる（あかりの歌＝緑、みおの手品・早瀬の時間・ノアの予測・りくの行動順＝黄。17-6）

### 18-3. 付け替えを活かす仕組み
| 仕組み | 中身 |
| --- | --- |
| **区画の予告** | 区画の入口とチェックポイントの看板に「この先に多い性質」を出す（例：「この先：かたい・バリア・ため」。1つの区画の性質は2〜3つまで、12.の決まり）。ボスの前のチェックポイントには、ボスの性質を出す。狩りで入る区画にも出す |
| **組み合わせの保存** | 仲間ごとに盤の並べ方を3つまで、名前を付けて保存（例：「雑魚用」「ボス用」「かたい用」）。1回押すだけで切り替える。ほかの仲間の盤で使っているギアがあれば、「○○の盤から外して付ける」と確かめる。並べ方を考えるのは遊ぶ人のまま（段階100b でおまかせ配置をやめた決定とぶつからない） |
| **ギアの数を少なく** | 対策・条件・両刃のギアは、1種類につき1〜2個しか手に入らない（いつも効くギアは3個まで）。誰の盤に乗せるかを、並び（7人から3人）ごとに決めることになる |
| **負けた時の手がかり** | 負けた画面に「この敵の『かたい』には アーマーピアス が効く」のように1行。持っていないギアなら「どこかの宝箱にあるらしい」 |
| **ギアの図鑑** | どの性質に効くかを、ギアの説明と、敵の図鑑の両方に出す（敵の性質 → 効くギア、ギア → 効く性質） |

### 18-14. 決めていないこと（仮で進める）
- 構想ノートの「装備から習得（ギアを付けて戦うと、本人が覚える）」は、まだ入れない。付け替えの良さとぶつかる（覚えたら外してよくなる）ので、入れるなら対策・条件・両刃のギアは覚えられない形にする
- 星図の「ギア獲得」の星は作らない（星図は技と能力値に絞る）
