# スナップとコンボの一覧（たたき台 2。2026-11-05）

`M3_snap_catalog.md` の 15・16 で決めた形（**コンボを札の幅の中心にする** ＋ **現像**）で、80枚を書き直した物（試しの3枚を足して83枚）。数値は入れない（強さは小・中・大、重さは軽い・ふつう・重い）。
- 状態は、やけど（火）・こおり（氷）・しびれ（雷）の3つだけ（9.）。属性を6つにするか（風・光）はまだ決めていないので、この一覧は今の4つ（物理・火・氷・雷）で作り、風・光が入るとよい札に「（風）」「（光）」と書いた
- 絵は「重なる思い出」（8-2 の案A）。敵の物が絵に出てこなくても、情景が近ければよい
- 試しの5枚（2-4 の3枚と、フラッシュ・金魚すくい）と、5つの2枚コンボは、段階155 で試しの戦闘に入れた（デバッグメニュー「試し：コンボと現像」）

## 1. 決まり（たたき台）

- **現像**：手札に残したままラウンドを越すと、段が1つ進む（撮りたて ● → 現像 ●● → 焼き付け ●●●）。使うと撮りたてに戻る。現像で変わる札は、全体の2〜3割
  - 育つ：残すほど強い／色あせる：撮りたてが一番強い／化ける：焼き付けで別の効き目
- **コンボ**：決まった材料が手札にそろうと、1人の行動で使える大技。材料はすべて捨て札へ
  - **2枚のコンボ**を中心にする（雑魚戦でも使える）。3枚のコンボは大技
  - **思い出のつながり**：決まった2枚（物語にちなむ名前）
  - **型のコンボ**：印がそろえば、どの札でも（火の札2枚、同じ時代の札3枚など）
  - **焼き付けのコンボ**（4章から）：材料が両方とも焼き付けなら、強い版になる
- **つながり帳**：見つけていないコンボは「？？？」とヒント。初めてそろうと名前と絵が出る（3章から）

- 2枚のコンボの相方がある札：80枚のうち約50枚。1枚で使うだけの札は約30枚（サポート・順番・予告の札が多い）
- コンボ：48通り（思い出のつながり34・今の4・型の10）。章ごとに、新しい札と、前の札との新しいつながりが増える

## 5. 決めたいこと
1. 属性を6つ（風・光を足す）にするか（上の一覧の「（風）」「（光）」の札）
2. 敵の札の手に入れ方（よく倒すと落とす）でよいか
3. アルバムは20枚のままでよいか
4. コンボの数は、48通りくらいでよいか（多すぎ・少なすぎ）
