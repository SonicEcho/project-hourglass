# 砂の底を掘る（2026-11-15 開発者と決めた。試作から）

見本：`docs/sketches/sand_bottom_dig_mock.png`。

## 1. 決めたこと（2026-11-15）
- 依頼（落とし物）と、クリア後のやり込みと、それだけでずっと遊べる遊びを、1つの寄り道「砂の底を掘る」にまとめる。戦闘やギア・アルバムとは別の、手を動かす遊び（横から見た地面を掘り進む）
- 深いほど珍しい物が出て、危険も増える。砂時計の砂が落ちきる前に帰る。かばん（砂時計の中）に入る数は決まっていて、何を持ち帰るかを選ぶ（`docs/design/economy.md` の 6. の「持ち帰りの取捨選択」）
- **砂嵐（敵）との戦闘も起きる**（開発者の案）。敵は見える形で地面の中にいて、避けるか倒しに行くかを選べる。戦闘はいつもの戦闘。HP・MP は潜っている間ずっと持ち越す
- 狩り（記憶をたどる）を、砂の底に置き換える方向（区画の地図をくり返し歩くより、毎回ちがう地面を掘る方が、くり返しの遊びに向いている）。ただし、いきなり狩りを外さず、**まず試作を作り、開発者がスマホで遊んで楽しいと確かめてから**置き換える
- 物語の1回目の区画の地図をどうするか（一枚絵の限界）は、砂の底とは分けて、後で決める

## 2. 試作1（段階207）で作る物
- デバッグメニューの「砂の底（試作）」から入る。周回の途中なら、今の仲間と育ち具合で潜る
- **地面**：横15マス、深さ50マス。シードから作る。上から 平成の層（2-2・2-3・4-2 の時代）→ 昭和の層（1-2・2-1）→ 大正の層（祭りの夜）。マスは 砂（掘れる）・固い土（2回掘る）・岩（掘れない）・空洞。空洞に宝箱と砂嵐の巣がある。深い層ほど岩と砂嵐が多い
- **動き**：画面をタップすると、その方向へ1マス進む（砂なら掘ってから進む）。上下左右
- **砂時計**：入った時に砂が決まった量ある。1マス歩くと1、掘ると3、戦闘は10減る（時間ではなく、手数で減る。落ち着いて考えられるように）。「上へ戻る」は、今の深さの分だけ減る。足りないまま戻ると、かばんの中の半分を失う
- **かばん**：10個まで。宝箱を開けると中身（その層の時代の素材。深いほど珍しい物）を入れる。いっぱいなら、何かを捨てて入れ替えるか、持たない
- **砂嵐**：砂嵐の巣のマスに入ると、その層の区画の砂嵐といつもの戦闘。勝つと巣は消え、星の砂・経験値・素材（いつもの戦闘の報酬）を受け取る。負けると地上へ戻され、かばんの半分を失う。HP・MP は潜っている間ずっと持ち越す
- **帰る**：地上に戻ると、かばんの中身を受け取る。いちばん深く潜った深さを覚える（試作では周回の中だけ。セーブしない）
- 潜っている途中はセーブしない（狩りと同じく、閉じたら潜る前から）

- → 段階207 で作った（`src/core/dig.ts`・`src/data/sandBottom.ts`・`src/scenes/SandBottomScene.ts`）。砂嵐の戦闘は、狩りと同じ扱い（戦闘中の印なし・ぬしのスナップなし）に、HP・MP を掘っている状態から持ち越す印（`dig`）を足した。勝った後のボタンは「砂の底へ戻る」、負けた時は「地上へ戻る」

### S1（段階209）の中身
- 拠点（レストピア）のタイルに「砂の底」。潜っても日は進まず、昼の回数も使わない。デバッグの入口も残す
- いちばん深く潜った深さを、セーブに残す（物語で覚えた値 `vars` の `dig:deepest`）。結果の画面に「新記録」
- 層を深くする（平成 24・昭和 26・大正 28 マス）。砂時計の砂は章ごとに増える（1章 100・2章 140・3章 180・4章 220。仮）
- 歩く（空洞の移動）は砂を使わない。掘る（砂・固い土・鉱脈・砂粒・崩れる砂）は3
- 空洞に稀に砂嵐が湧く：1手ごとに少しの割合で、自分から少し離れた空洞のマス（すぐ隣でない所）に、その深さの層の砂嵐が1体。同時にいる数には上限
- 十字のボタンを大きく（押しやすい大きさ）。長押しすると続けて進む
- 自分と砂嵐が、マスからマスへなめらかに動く（動いている間は次の手を受け付けない。長押しの続けて進むは、動き終わってから次へ）
- → 段階209 で作った。潜った回数もセーブに残し（`vars` の `dig:count`）、地面のシードをずらす（開き直しても同じ地面にならない。乱数はシードから決まるまま）。拠点のタイルの絵は、届くまで地面の切り取りの一枚絵

### S2（段階210）の中身
- **ブロックの絵はコードで描く**（UI と同じく、まず絵は頼まずにコードで描き、気に入らない所だけ後で絵にする。`docs/ART.md` の 5-9 の決め方）。層ごとの色はそのまま、質感を描く
  - 砂：細かい粒と薄い地層の筋／崩れる砂：明るく、さらさら流れる筋／固い土：ひびと小石／岩：角ばった石の塊に光と影／鉱脈：岩肌に金色の結晶／砂時計の砂粒：光る粒／空洞：奥の暗い土の壁
  - 同じ種類でも柄を3通り混ぜる（マスの位置で決まる。毎回同じ見た目）
  - 掘れる土と空洞の境目に影（空洞の天井の下は暗く、土の上の面は明るい縁）
  - 宝箱（木と金具）・層の番人（赤い目の砂の塊）・動く砂嵐（渦巻く砂。くるくる回る）・地上（夕暮れの空）も描き直す
- **二頭身のハルトが歩く・掘る**：横から見た動き。スコップを持つ。右向きの絵を、左へ行く時は左右を返す
  - 動きの絵は4行×3列の1枚：1行目 歩く（左足・立ち・右足）、2行目 横を掘る（振りかぶる・振る・当たる）、3行目 下を掘る、4行目 上へ登る（上を掘る）
  - 絵は頼む（`docs/ART_QUEUE.md` の T。保存名 `dig_hero.png`）。**届くまでは、コードで描いた仮の二頭身**（同じ4行×3列の形なので、届いたら差し替えるだけ）
- **掘る時の動き**：その場でスコップを振り、ブロックが揺れて崩れ、かけらが飛ぶ。それから掘った所へ歩いて進む（砂嵐も、歩き出すのに合わせて動く）。固い土の1回目は、ひびが入るだけで進まない。空洞は歩く動きだけ
- 掘る人を選ぶ（S3）ので、仲間の動きの絵も同じ形にする。S2 ではハルトだけ
- → 段階210 で作った。二頭身のハルトの絵も同じ日に届き、入れた（`public/assets/sprites/dig_hero.webp`、台帳の id `sprite.dig_hero`）。届いた絵はコマごとに体の位置と足もとが少しずれていたので、`scripts/dig_sprite.py` で背景を抜き、髪の真ん中と足もとをそろえた（跳ぶコマは浮いたまま）。歩く行は 立ち・左足・右足 の順で届いたので、立ちをはさんで足を交互に出す。仮の絵（コードで描いた物）は、絵が読めない時の代わりに残す
- 開発者の声（2026-11-15）：はじめ仮の絵が出た。絵を待つのは拠点の入口だけで、デバッグの入口などからは待たずに開いていた。砂の底の画面の中で、掘る人の絵がまだなら読み込みを待ち、読めたら描き直すようにした

### S4（段階212）の中身（2026-11-15 開発者と決めた）
**層の分け方の検討**：時代ごと（平成・昭和・大正の3層）は少なすぎ、区画ごと（10を超える）は多すぎ。時代を細かく分けても（7層）、章が進むと上や途中に層が差し込まれ、時代の順がばらばらになる。そこで、**層は時代でなく、物語で返した順（章ごと）に積む**。深いほど後の章。新しい層はいつもいちばん下に増え、並びは入れ替わらない。層の名前は、物理学・心理学寄りの実在の言葉にした（昔の時刻・地質年代・年縞の案も出したが、開発者の好みで）

**層（心の層。上から）**：章の層の中は、区画ごとの帯（12マス）に分け、帯ごとに色・素材・敵が変わる。章の層の境目（2つ目の層から）に番人

その下の**時間の層**（クリア後。S8）：時間の遅れの層・事象の地平面の層・特異点の層（いちばん底。裏ボスの置き場所は S8 で決める）

**開き方**

- 砂時計の砂は章ごと（2章 140・3章 260・4章 400。仮）。開いている層の底まで行って探れるくらい

**S4 では作らない**：ぬしの巣（層の奥の空洞のぬし。部位で進化の鍵）・稼ぎ（前の章の層は星の砂と経験値が半分）は S5（狩りを外す）。時間の層は S8
