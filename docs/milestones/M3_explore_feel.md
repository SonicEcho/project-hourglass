# M3 探索の地図の手触りと見た目（2026-11-20〜）

開発者の声（2026-11-20）：「ダンジョンマップの完成度が気になる。動きづらいうえに、どこまで移動できるか分かりづらい。一枚絵なので細かいレイヤーがなくチープに見える。もっとワクワクするダンジョンにしたい」。戦闘の見直し（`M3_battle_tension.md`）と同じく、**小さく試し、スマホで遊んで確かめながら決める**。

## 1. 今の作り（調べて分かったこと）

- **操作**：画面をタップすると、その場所まで最短の道で歩く（`ExploreScene` の `tapCell`）。道は上下左右の4方向だけ（`src/core/grid.ts` の `DIRS`）なので、斜めに行きたい時も階段のようにカクカク曲がる。1マス 140 ミリ秒で、マスごとに止まりかけるように動く。押したまま引っ張って歩く操作はない（ドラッグは無視）
- **行ける範囲**：歩ける所は見えない文字の地図で決まっていて、画面には出ない（デバッグの「マス目」だけ）。通れない所をタップすると、黙って近くの通れるマスへ歩く。行き先の印もない
- **見た目**：部屋ごとに見下ろしの1枚絵（`public/assets/maps/`。ChatGPT で 1024×1024 か 1024×1536）。重ねているのは、屋根や木の下（`^` のマス。段階118・121）と陰（段階121）だけ。光・空気・動く物がなく、絵が止まって見える。仲間は立ち絵の小さな絵が、すべるように動く（歩く動きがない）。敵の印は小さなざらざらの絵
- 画面の上（題・案内の帯）と下（HP・MP の帯）で、地図が見える所が縦に約 2/3

## 2. 課題

| 課題 | 中身 |
| --- | --- |
| A. 動きづらい | タップした所まで歩くだけ。4方向のカクカクした道。行き先が見えない。思った所と違う所へ歩くことがある |
| B. どこまで行けるか分からない | 歩ける所と飾りの絵の区別が画面にない。通れない所をタップしても何も言わない |
| C. チープに見える | 1枚絵が止まっている。光・影・空気の動きがない。手前に重なる物が少ない。仲間が歩かない |
| D. ワクワクが足りない | 部屋に入った時・宝箱・コマを持つ敵・出入口に、見せ場の演出が少ない |

## 3. 案

| 案 | 課題 | 中身 | 絵の頼み |
| --- | --- | --- | --- |
| A1. 押したまま歩く | A | 指を置いて引っ張ると、その向きへ歩き続ける（指を置いた所が中心の見えないスティック）。タップで歩くのも残す | なし |
| A2. 斜めになめらかに | A | 道を8方向にして、曲がり角を減らす。止まらずに続けて動く | なし |
| A3. 行き先の印 | A・B | タップした所に波紋、歩く道に点線。行けない所をタップしたら「×」 | なし |
| B1. 歩けない所を沈める | B | 歩けない所を少し暗く・色を落とし、歩ける所との境目をやわらかくぼかす（屋根の切り抜きと同じ仕組み） | なし |
| B2. 足元から光の波 | B | 部屋に入った時と立ち止まった時に、足元から歩ける所に沿って光が広がって消える | なし |
| C1. 光と空気 | C | 街灯・提灯・窓に、ゆらぐ光（加算合成のにじみ）。部屋ごとの空気の粒（雪・ホタル・夕日のちり・砂嵐の粒）。画面の端を暗くして、記憶の中らしく端が砂のようにほどける | なし（光の場所はデータで書く） |
| C2. 仲間の足元の影と歩く揺れ | C | 足元に丸い影、歩くと小さく弾む | なし |
| C3. 仲間の歩く絵 | C | 4方向の歩くコマ | 要る（`docs/ART_QUEUE.md` に足す） |
| C4. 手前の物を増やす | C | 屋根の仕組みを広げて、柱・木・看板などを仲間の上に重ねる（文字の地図に印を足す） | なし |
| D1. 部屋に入った時の見せ方 | D | 部屋の名前を映画の字幕のように出し、カメラを少し引いてから寄る | なし |
| D2. 見せ場の物を光らせる | D | 宝箱・コマを持つ敵・まだ入っていない出入口に、ゆっくり光る輪や粒 | なし |

## 4. 進め方の案

1. **段階262：動かしやすく**（A1＋A2＋A3）
2. **段階263：行ける所を見せる**（B1＋B2）
3. **段階264：光と空気**（C1＋C2。まず1つの部屋で試し、よければ全部の部屋に）
4. **段階265：見せ場**（D1＋D2）
5. C3（歩く絵）と C4（手前の物）は、264 の後に必要か決める

どれも絵の頼みなしで作れる（C3 を除く）。
