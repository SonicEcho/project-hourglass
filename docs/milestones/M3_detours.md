## 2. 気になる所
1. **③「日常の小さな遊び」は、数える物がない**。射的・金魚すくいはプロローグだけの遊びで、くり返せない。トランプタワー・時計の修理の遊びもない。→ 段階220 で決めたとおり、③を「依頼（落とし物）」の寄り道に置き換えるのが自然
2. **③の名前と言い伝えが、遊びの話のまま**（射的の剣・金魚の杖など）。依頼の寄り道にするなら、名前と一文を「届けたこと」の話に書き直すか
3. **依頼の数が足りない**。依頼は今4つ（1-1・1-2・2-1・2-2）。小夜子（3章から）・早瀬（4章から）の区画には依頼がない
4. **④は戦い方の記録が要る**（部位を全部壊して勝った回数など）。今のセーブには記録がない。③とは別の段階にする
5. 早瀬だけ②がなく①が2本（「低いまま」の道がない）。今はこのままでよいか
6. `docs/design/economy.md` の章ごとの量の表では「1〜2章は寄り道1、3章で2…」だが、今は①②が最初から開いている（実害はない。表を今に合わせて直す）

## 3. 段階221 の案（③を依頼の寄り道に）
- 条件は「届けた依頼の数」だけ（素材の鍵は使わない）。数は、加わるのが遅い仲間ほど多く：ハルト・あかり 2、みお 3、小夜子・早瀬 4（今の4つで全部届く。依頼を足したら上げる）
- 効果は一覧（17-6）のまま（露出 +・回復・押す距離 +1・予定を1つ多く見る）。今ある特性の組み合わせで作る
- 名前と言い伝えは、依頼の話に書き直す（例：ハルト「届け物の剣」…）
- ④は段階222 以降（戦い方の記録を足してから）

## 4. 決まったこと（2026-11-16 開発者と）
- ③は「日常の小さな遊び」をやめ、**決まった依頼を届けると開く**寄り道にする（素材の鍵は使わない）。名前と言い伝えは依頼の話に書き直す（効果は一覧のまま）
- 組み合わせ（段階221）：ハルト「合図の剣」（写しの剣から。依頼「二度鳴るベル」。当てると露出）、あかり「約束の金魚の杖」（癒しの杖から。依頼「金魚のヘアピン」。ラウンドの始めに HP 3% 回復）、みお「四曲目のカード」（トリックカードから。依頼「書きかけの四曲目」。押す距離 +1）
- 小夜子・早瀬の③は、その章（3章・4章）に依頼を足すまで、言い伝えだけ（一文は依頼の話に書き直した）。2-1「親方のひとこと」は、今は寄り道に使っていない（早瀬の③に使う案もある。4章の依頼と一緒に決める）
- ④は③の後に、段階222 で作る（戦い方の記録をセーブに足してから）
- 早瀬の②がない件・`docs/design/economy.md` の章ごとの量の表は、今のままにする（表は段階221 で今に合わせて注を足した）
