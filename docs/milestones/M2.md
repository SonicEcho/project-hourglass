## 段階47の詳細：部屋をつなぐ探索と、敵の動き

開発者の案（2026-10-15）：「今の探索の地図は縦に一直線。もっとダンジョンのようにしたい。敵も同じように」。さらに「やり込みを大事にしていて、最後は前の区画に戻って素材集めやレベル上げをする」。チャットで相談して、次の形をたたき台にし、開発者が確かめて決めた（2026-10-15。下の「決まったこと」）。作った時に、仕組みを `docs/design/explore.md` に移す。

### ねらいと、この形にした理由

- **絵の限界に合わせる**：地図の絵は ChatGPT で作る。縦長の絵1枚に入り組んだ道を頼むと、道が途中で切れたり、左右対称に寄ったりする（1-1 の縁日の地図は左右対称）。そこで、1枚の絵は簡単な部屋（広場1つ、路地1本、行き止まりの裏庭など）にして、ダンジョンらしさ（分かれ道・行き止まり・寄り道・近道・ぐるりと回る道）は**部屋のつなぎ方（データ）**で作る
- **やり込みに使い回す**：部屋は区画から切り離した「部品」として作る。物語の区画は部品を手で並べ、段階43（周回・狩り）では同じ部屋に入り直し、砂の底（`docs/CONCEPT.md` の「クリア後のやり込み」。いろいろな時代の部品で階を自動で組み立てる）では同じ部品を乱数で並べる。描いた絵が何度も働く
- **タイルを並べる形にはしない**：今の1枚絵の雰囲気がなくなり、ChatGPT はタイルの絵柄をそろえるのが苦手なため

### 47a 部屋とつなぎ

- **部屋（部品）**：`src/data/rooms.ts` の `ROOMS` に、部屋ごとに、地図の絵、歩ける場所の文字の地図、出入口、時代の札（`era`。砂の底で組む時に使う）を書く。宝箱・敵・話せる人・チェックポイントは区画の側に「どの部屋のどのマス」で書く（同じ部屋でも、区画や狩りで中身を替えられるように）
- **区画**：`AreaDef` に `rooms`（使う部屋）と `links`（出入口のつなぎ。「部屋Aの右」⇔「部屋Bの左」）と、出発する部屋を足す。今の 1-1・1-2 は「部屋が1つだけの区画」として、見た目も遊び方も変えずに新しい形へ移す
- **部屋の形**：2種類にする。正方形 24×24マス（ChatGPT に 1024×1024 で頼む。画面の横2つ分・縦1つ分くらい）と、縦長 24×43マス（今の地図と同じ。1024×1536）。1マス32のまま
- **出入口の決まり**：出入口は辺の真ん中にだけ置き、幅は4マス。正方形の部屋なら上下左右の4か所、縦長の部屋は上下と、左右の真ん中の4か所が候補。使わない出入口は、絵では壁や木でふさぐ。出入口の位置がそろっていれば、どの部屋とどの部屋もつなぎ替えられる（砂の底で組み立てられる）
- **部屋の移り方**：出入口のマスに着くと、短く暗転して、つながった部屋の出入口の内側に出る。入った直後は、戦闘から戻った時と同じ間（`AREA_GRACE_MS`）だけ敵に触れても戦闘にしない。カメラの範囲は部屋ごと
- **閉じた出入口**：条件で開く出入口（例：ボスに勝つと、ボスの部屋から入口の部屋への近道が開く。チェックポイントの先の扉が、砂嵐を倒すと開く）。1回目の帰り道を短くし、段階43の狩りでも、奥の部屋へすぐ行けるようにする
- **全体の地図**：右上の小さな地図に、入った部屋とつながりを出す（迷わないように。入っていない部屋は出さない）。タップで大きく見せるかは作る時に決める
- **区画の大きさの目安**：物語の1回目は10〜15分（`docs/CONCEPT.md` のプレイ単位）。部屋は4〜6つで、そのうち1〜2つは行き止まりの寄り道（宝箱や、逃げる敵）。チェックポイントは今と同じく2つ
- **セーブ**：`run.explore` に今いる部屋を足す（セーブの版9）。前の版の探索の途中は、部屋が1つの区画として読む
- **ロジックとテスト**：部屋のつなぎ・移り方・閉じた出入口は `src/core/explore.ts` に置き、テストを足す。`checkArea` で、つなぎの書き間違い（ない出入口、片方だけのつなぎ、ふさがった出入口、どこからも行けない部屋）を止める

### 47b 敵の動き

- 敵の印に、動き方の種類（`move`）を足す。数値（気づく距離など）は `src/data` に置く

| 種類 | 動き | ねらい |
| --- | --- | --- |
| 見回り（今の形） | 決まった道を回る。2点の往復だけでなく、3点以上の輪も使う（`patrolRoute` は今でも輪を扱える） | 道の上の障害物 |
| 追ってくる | 近く（例：4マス）に来ると「！」を出して追いかけ、離れる（例：7マス）とあきらめて見回りに戻る。仲間より遅い（今の敵は1マス420ミリ秒、仲間は140ミリ秒）ので、逃げ切れる | 緊張感。避けるか戦うかを選ばせる |
| 番人 | 分かれ道や出入口に立って動かず、倒すまで先へ通さない。1回目の物語だけに置き、狩りでは出さない | 区切りと、手ごたえのある戦い |
| 逃げる | 時々出る、珍しい敵。近づくと逃げ、行き止まりに追いこむと捕まえられる。珍しい素材を落とす | やり込み（狙って探す楽しみ） |

- **印の見た目**：敵の絵（`ENEMY_ART`）を小さくして、種類ごとに見分けられるようにする（欲しい素材の敵を選んで戦えるように）。絵のない敵は今の赤い菱形。追ってくる途中は「！」、番人は少し大きく、逃げる敵は光らせる
- **動きはロジックに置く**：今は画面の側で、決まった道を動きのアニメーションでなぞっている。追う・逃げるは1歩ごとに行き先を決めるので、「次の1歩」を決める関数を `src/core/explore.ts` に置いてテストする（乱数はシードから）

### 段階43（周回・狩り）と砂の底のために、今はデータの形だけ決めておくもの

- 返し終えた区画に入り直した時の中身は、1回目とは別に書けるようにする（例：区画の `hunt`）。中身は、敵が入るたびにまた出る、宝箱の代わりに何度でも拾える採取の場所、部屋ごとに出やすい敵の表（「この部屋は金魚ノイズが多い」）、会話・コマ・番人はなし。作るのは段階43
- 砂の底の組み立て（部品を乱数で並べる）は作らない。部屋に時代の札と出入口の決まりがあれば、後から組める

### 確かめ方と、どの区画で使うか

- **確かめ方**：新しい絵を待たずに確かめられるよう、デバッグメニューに「試しの区画」を作る（今ある地図の絵3枚を部屋としてつなぎ、4種類の敵を置く）。本編の区画は変えない
- **どの区画から使うか**：まだ地図の絵がない 2-2（文化祭の高校）から部屋をつなぐ形で作る（段階39）。もう縦長の絵がある 2-1 は、今の絵を1つ目の部屋にして、寄り道の部屋を1〜2つ足す（寄り道の部屋の絵は、正方形の部屋として ChatGPT に頼む）。1-1・1-2 は部屋1つのまま。狩りのために部屋を足すかは段階43で決める
- **絵の頼み方**（`docs/ART.md` の「地図の頭」に部屋の決まりを足す）：部屋の形（正方形か縦長か）、出入口の辺と幅（「上の辺の真ん中に、幅が絵の6分の1の出入口。ほかの辺はふさぐ」）を言葉で書く。さらに、文字の地図から作った配置の下絵（通れる所と通れない所を色分けした絵。`scripts/` に作る道具を足す）を付けて、「この配置で描いて」と頼む。絵と歩ける場所がずれにくくなる

## 段階46の詳細：感情を伝える動き

開発者の案（2026-10-11）：「今の2D のままだと、キャラの動きや感情が伝わりにくい。いちばん大事な『感情移入させる』に足りない」。見本のページ（4つの動き）を見て、4つとも入れると決めた。新しい絵はなるべく使わず、今ある絵で作る。

### 46a 戦闘中のひとこと（`docs/design/battle.md` の 12-3）

- 気持ちが動く瞬間だけ、仲間の顔の帯を横から差し込み、ひとこと言わせる。帯は敵の下のあたり。顔は立ち絵の顔のあたりを切り出す（新しい絵は要らない）
- 出す時：弱点を突いた（突いた人）、1回で最大 HP の4割以上削られた・残りが3割を切った（削られた人）、仲間が倒れた（ほかの仲間が名前を呼ぶ）、連携技（2人がかけ合う。今の連携技の帯に顔と台詞を足す）、勝った（1人）
- 出しすぎない：弱点と削られた時のひとことは、出した後の2回の行動では出さない。倒れた・連携技・勝った時は必ず出す。早送り（演出中のタップ）では出さない。×2・×3 とオートでは、ほかの演出と同じく速くなる
- 誰が何を言うかは `src/core/bark.ts`（Phaser を読み込まない。テストあり）が出来事の列から決める。台詞は `src/data/barks.ts`（人ごと・場面ごとに数個。どれを言うかはラウンドと行動の数で決まり、乱数を使わない＝戦闘の結果は変わらない）

### 46b 立ち絵のまばたきと口パク（`docs/design/dialogue.md` の 2.）

- 会話の立ち絵が、2.2〜5.4秒おきにまばたきする（4回に1回くらい2回続ける）。話している人は、文字が出ている間だけ口が動く（句読点では閉じる）。早送りの間は動かさない
- 差分の絵は「目を閉じた所」「口を開けた所」だけを切り抜いた透明な絵で、表情の絵に重ねる。今ある表情の絵から切り貼りで作る（`scripts/portrait_parts.py`。同じ構図で作ってきたので、ほぼずれずに重なる）
- 今作れる物：あかりのまばたき（目は「大笑い」から。目を開けた表情すべて）、3人の口パク（口は「驚き」「心配」から。口を閉じた表情）。ハルトとりくには目を閉じた絵がないので、まばたきは目を閉じた絵（Gemini）が届いてから（指示文は `docs/ART.md` の 5-4）。→ 2026-10-11、目を閉じた絵が届いたので、ハルトとりくのまばたきも入れた。差分のない表情は今まで通り

### 46c 動く1枚絵（`docs/design/dialogue.md` の 2.）

- 1枚絵に、今のゆっくり寄る動きに加えて、舞う粒（`ambient`）と光のゆらぎ（`glow`）を重ねられるようにする。どちらも1枚絵の台帳 `CGS` に書く（台本は直さない）

### 46d 記憶の再生（`docs/design/return.md` の 3.）
