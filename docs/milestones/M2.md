# M2：1〜2章（前半の土台：取り戻して返すくり返し）

> **2026-10-10 段階分けを決定**（開発者と確認。前提の決まりは下の「決まったこと」）。今は段階33（33a は済、33b のたたき台を確認してもらう所）。

「取り戻して返す」くり返しが、章をまたいで気持ちよく回る形を作る。M1 の垂直スライス（プロローグと 1-1）の続きから、2章の終わりまで。全体の道のりは `docs/ROADMAP.md`、物語は `docs/STORY.md` の 2-8〜2-12。

**完成の基準**：2章の終わりまで通しで遊べる。「取り戻して返す」くり返しが気持ちよく回るか、カイへの悔しさが3章へ引っぱるかを、遊んだ人の反応で確かめる（`docs/ROADMAP.md`）。

## 作業の進め方

- M1 と同じ：段階ごとに依頼し、各段階の終わりにスマホで確かめる。段階は、この文書に「依頼する内容」と「スマホで確かめること」を書いてから作る
- **いつでも通しで遊べる状態を保つ**：先に流れの骨組みを2章の終わりまで伸ばし、まだできていない所は仮の画面でつなぐ（M1 の段階23と同じやり方）
- **型を先に作って、量は後で増やす**：区画・日常・返した翌日の場面は、最初の1つ（1-2）で型を作り、2章ではデータを足すだけで作れるようにする
- 絵と音は仮の素材で作り、開発者の素材が届いたら入れる（M1 と同じ）
- 新しい仕組み（1日の流れ、絆、アルバムの編集など）は、作る段階で `docs/design/` に設計書を足すか、今の設計書に書き足す
