# 2本目の武器と持ち替え（2026-11-16。たたき台。開発者と相談中）

今の決まり（`docs/design/growth.md` の 8-1）：進化の木は合流しないので、選ばなかった枝は、同じ種類の武器をもう1本育てて目指す。
成長は武器にたまるので、持ち替えても無駄にならない（`docs/CONCEPT.md`）。いつ・どう手に入れるかは、まだ決めていない（文書では「5章の拠点」の案）。

## 1. 決めること
1. いつ出すか
2. どうやって手に入れるか（物語の中の理由）
3. 2本目はどこから育てるか（Lv1 から、など）
4. 持ち替えはどこでできるか

## 2. 案
### 1. いつ
- **A（おすすめ）：4章の後（早瀬が加わった後の拠点）**。今作ってある範囲（4章まで）で遊べる。木は3回目まであるので、2本目で別の系統を試す楽しみがすぐある
- B：5章の拠点（今の文書の案）。5章を作る時まで後回し
- C：3章。早すぎる（1本目もまだ2回目くらい）

### 2. 手に入れ方
- **A（おすすめ）：早瀬が組む**。時計屋の職人の早瀬が、武器のもとの思い出の品（腕時計・髪留め・トランプ…）の「写し」を、記憶の欠片から組み直す。4章で加わる職人の役目にも合う。記憶の欠片の使い道にもなる
- B：交換所（ペトラ）で買う。手軽だが、物語の意味が薄い
- C：砂の底で見つかる。運しだいになる

### 3. 2本目の育ち方
- **A（おすすめ）：Lv1・まっさらから。ただし1本目のレベルに追いつくまで、経験値が多めに入る**（追いつきの補正）。素材を刻むのはいつもどおり
- B：1本目の半分の経験値から始める
- C：補正なし（やり込み向け。手間が大きい）

### 4. 持ち替え
- **A（おすすめ）：拠点の武器の画面だけ**（戦闘・砂の底の中では替えない）。持っていない方の武器も、素材を刻めて育てられる
- B：区画に入る前の準備でも替えられる

## 3. 作る時に気をつけること
- セーブの形が変わる（仲間ごとに武器が2本）。セーブの版を上げ、今の武器は1本目として引き継ぐ
- 武器の画面に「1本目・2本目」の切り替えが要る。図鑑に「前に作った進化先」を残す件（`docs/design/growth.md` の 8-5 のまだのもの）も一緒に
- 遅く加わる仲間（小夜子・早瀬）の2本目も、加わった時の選択（`joinTier`）と同じように、その段まで条件なしで選べるか
