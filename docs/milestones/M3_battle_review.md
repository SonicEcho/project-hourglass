## 2. 根本の問題（なぜ飽きるか）

1. **敵が「数の違う袋」になっている**：敵の違いは HP・攻撃・弱点の属性だけで、行動はでたらめ。読むことがないので、敵を見て作戦を変える理由がない。絵が違っても中身が同じ
2. **どこでも効く「正解の手順」が1つある**：弱点を探す → 突いてダウン → 延長 → ためは防御 → 崩れたら連携技。これが1章から4章まで同じように効く。自動対戦でも、この方針だけで 93〜100% 勝てる。一度覚えると、考えなくても勝てる
3. **手札の道具が増えない**：スナップは2章の後、増えていない。仲間が増えても、属性の違う単体・全体の技が増えるだけで、新しい「できること」（動詞）が増えない
4. **戦う目的が毎回同じ**：どの戦闘も「敵を全部倒す」。守る・間に合わせる・逃がさない、のような違いがない
5. **数が多く、1戦が薄い**：186戦のうち大半が、同じ形の雑魚戦。ぬしは 8〜17ラウンドと長く、同じ手順を繰り返す時間が長い
6. **難しさを数で上げている**：章が進むと、敵の HP と攻撃に倍率（×1.3〜×2.3）を掛けているだけ。強くなった実感も、新しい手ごわさもない

## 3. 直し方の柱（案）

4本の柱を組み合わせる。どれも、話の主題（盗まれた時間・写し・記憶）と結びつける。

### 柱A 敵を「読む」相手にする（敵の癖と役割）
- どの敵にも、戦い方を変える癖を1つ持たせる（例：かばう、仲間を治す、仲間を呼ぶ、時報で決まったラウンドに大技、ふくらんで破裂、倒すと隣が強くなる）。4章の12体の案は `M3_playtest2.md` の「18 と 19 の案」
- 雑魚の組み合わせに役割を持たせる（前に立つ・後ろで治す・呼ぶ）。倒す順番が作戦になる
- 敵の次の行動を、いつも予告する（今はぬしの「ため」だけ）。読んで、先に手を打つ遊びにする

### 柱B 戦闘ごとに「お題」を変える（話と結んだ特別な決まり）
- 例：写しの人を守りながら戦う／時計の針が回り切る前に倒す（ラウンドの数に限り）／逃げる敵を逃がさない／記憶がすり減って手札が1枚ずつ欠ける／昼と夜で弱点が変わる
- 雑魚戦の何戦かに1つ、ぬしには必ず、お題を付ける。お題を果たすと、ごほうびが増える

### 柱C 章ごとに、新しい「できること」が増える
- 章ごとに、戦闘の仕組みを1つ足す（1章：部位とため、2章：アルバム・バトン、のように）。3章から先も、話の主題にそった仕組みを足す
- 案：「時間」を使う仕組み。戦闘の画面はフィルムの見た目なので、**コマ送り**（敵の行動を1つ後ろへずらす）、**巻き戻し**（前のラウンドの始めに戻す。1戦に1回）、**早送り**（仲間の行動を2回に分けて先へ）などを、仲間ごとの固有の技にする（小夜子・早瀬が加わる時に、その人らしい仕組みを1つずつ）
- 返した話ごとの新しいスナップ（メモ 19）で、手札の道具を話ごとに増やす

### 柱D 数を減らして、1戦を濃くする
- 区画の雑魚戦を減らし（例：1区画 16〜22戦 → 8〜10戦）、その分、1戦ごとの中身（癖・お題）を濃くする
- 弱い敵は、探索で触れずによけられる・まとめて片づけられる形にする（今もオートはあるが、手で選ぶ戦闘の数を減らす）
- ぬしは、HP が減ると形が変わる（段階を持つ）。同じ手順を長く繰り返さないよう、ラウンドを 6〜8 に短くし、段階ごとに戦い方を変える

## 7. 抜本的な案（2026-11-04）

### 手本の2作が、なぜ飽きなかったか

| | ペルソナ | ロックマンエグゼ |
| --- | --- | --- |
| 1戦の中 | 弱点を突けば1ターンで終わる速さ。外すと、敵も**こちらの弱点を突いて**押し返してくる（負けがある） | 敵（ウイルス）ごとに**動きの型**があり、見て、よけて、当てる。同じ敵でも並びで別の戦いになる |
| 戦いの外 | ペルソナを集めて**付け替える**。耐性と技の組み合わせを、敵に合わせて考え直す | 倒し方の**評価（バスティングレベル）**で、その敵の**チップがもらえる**。フォルダを組み直すたびに、戦い方が変わる |
| 道具が増え続ける | 合体で、最後まで新しいペルソナが出る | 最後まで新しいチップと、チップの組み合わせ（P.A.）が出る |

今の RESTOPIA は、手本の「仕組みの名前」（弱点・Extend・バトン・総攻撃にあたる連携技・フォルダにあたるアルバム・ナビカス盤にあたるムーブメント）は入っているが、**相手が手ごわく変わること**と、**道具が増え続けること**が抜けている。

### 案1 文字盤の戦闘（ラウンドをなくし、時計の上で戦う）

- ラウンドをやめ、**時計の文字盤**の上に、仲間と敵の「次の番」をずっと先まで並べる（今のフィルムのコマを、そのまま先まで続けて見せる）。行動ごとに、次の番が来るまでの時間（重さ）が違う。速い技を連打するか、重い大技でじっくり待つか
- 時間を動かすのが作戦の中心になる。弱点を突くと、敵の番を**後ろへ押し出す**（今のダウンの代わり）。仲間の技で、敵の番を**遅らせる・止める・入れ替える**。自分の番を**早める**
- 敵の大技は「◯時に来る」と文字盤に見えている。その前に止めるか、受けるかを選ぶ
- **刻限**：針が一周するたびに、場が変わる（ぬしが形を変える・夜が明ける・砂嵐が増える）。構想ノートの「刻限」とFF10の CTB にあたる。話の主題（盗まれた時間・時計屋）と、いちばん強く結びつく
- 大きさ：戦闘の仕組み（`src/core/battle.ts`）と画面をほぼ作り直す。いちばん大きな直し

### 案2 砂嵐から「コマ」を奪う（倒し方で、その敵の技が手に入る）

- 砂嵐はすり切れた時間のかけら。倒し方の評価（速さ・受けたダメージ・弱点で倒したか・最後の一撃）で、**その敵の技がスナップとして落ちる**。56種の敵から56種のスナップ。鳩時計の「時報」、ヨーヨーの「行って戻る」を、自分で使える
- 欲しいスナップのために、敵を「よく倒す」理由ができる（同じ雑魚戦でも、ねらいが変わる）。アルバム（フォルダ）を組み直す楽しみが、最後まで続く
- エグゼのチップの「コード」にあたる決まりも足す：スナップに**時代の印**（昭和・平成・大正など）を付け、同じ時代を同じ番にまとめて切ると強くなる。アルバムを組む悩みが増える
- 大きさ：スナップを56種作る（数値と効き目。絵は敵の絵を使い回せる）。戦闘の仕組みは中くらいの直し

### 案3 向こうも、こちらを突いてくる（負けのある緊張）

- 仲間にも**弱点と耐性**を持たせる。敵がこちらの弱点を突くと、仲間がダウンし、敵がもう一度動く（ペルソナと同じ怖さ）
- 弱点は、ムーブメント（盤）や武器で埋められる。どの仲間を出すか・何を付けるかを、敵に合わせて考える理由になる（今の並びの選択が、ただの好みでなくなる）
- 探索で、砂嵐に後ろから触れると先制、正面からぶつかられると不意打ち（向こうが先に動く）
- 大きさ：仕組みは小さめの直し。ただ、数値の測り直しは全部の区画で要る

### 案4 陣地（2列×3つの立ち位置）

- 仲間と敵に前・後ろの列と、左・中・右の位置を持たせる（エグゼのマス目を、ターン制で軽くした形）。敵の攻撃は「この列」「この縦」と予告し、仲間を動かしてよけられる
- 前列は強く当てられるが、狙われやすい。後ろは安全だが、届く技が限られる
- 大きさ：画面の作りが大きく変わる（縦長の画面に、敵3つ・仲間3つの位置を見せる）。案1と一緒にすると、とても大きい

### 案5 ぬし戦は「思い出の再演」（毎回ちがう遊び）

- ぬしとの戦いを、その思い出の場面の決まりで戦う、1つずつ違う遊びにする。例：金魚鉢のぬしは「ポイが破れる前に」、最後の打席は「9回裏2アウト、3球の勝負」、汽車のぬしは「線路を近づいてくる汽車を、駅までに止める」
- 大きさ：ぬしごとに専用の決まりを作る（11体）。一度に作らず、新しい章のぬしから入れられる

### すすめる組み合わせ

**案1（文字盤）を土台に、案2（コマを奪う）と案3（向こうも突く）を乗せ、ぬしには案5を少しずつ**。柱A〜Dは、この上でそのまま生きる（敵の癖は文字盤の上の動きになり、お題は刻限で出しやすくなる）。案4は画面の負担が大きいので、今は見送る。

- 文字盤は、この話にしかない戦闘になる（時間を返す話で、時間そのものを動かして戦う）。今のフィルムのコマの見た目も生かせる
- コマを奪うで、道具が最後まで増え続ける（エグゼの楽しさ）
- 向こうも突くで、たまに負ける緊張が生まれる（ペルソナの楽しさ）

### 進め方（案）

1. 文字盤だけを、試しの区画に作る（敵3〜4種、仲間3人）。スマホで遊んでもらい、手応えを見る
2. よければ、コマを奪うと、向こうも突くを足して、もう一度遊んでもらう
3. 決まったら、戦闘の設計書を書き直し、1章から順に敵と数値を作り直す（186戦のデータの直しと、測り直し）

## 10. 試しの手応え（2026-11-04。開発者）

文字盤の戦闘は微妙だった。
- 次に誰が動くのかが分かりにくい（文字盤のふちの印の並びから、順番が読み取れない）
- 時間の進みが分かりにくい。敵の番が、コマ送りのように次々と処理されて、何が起きたか追えない

考えたこと：
- 円の上の位置で順番を見せるのは、スマホの小さな画面では読み取りにくい。順番は「左から右」のように1列で見せる方が分かる（今のフィルムの帯は、これができている）
- 敵の番を自動で続けて流すと、追えない。1つずつ止まるか、まとめて見せてから流す必要がある
- 文字盤そのものはやめる。ただ、試しで入れた「敵の次の技がいつも見える」「向こうも弱点を突く」「控えとバトンで交代」は、今のラウンドの戦闘にのせられる

## 11. スナップを大量に増やすための仕組み（2026-11-04。開発者の問い「ネタ切れしないよう、効果の幅が要る。その観点で、戦闘の仕組みはどうか」）

### 今の幅
今の戦闘で、スナップや技が持てる効き目は10種類だけ：ダメージ・回復・引く・引き直す・捨て札から戻す・防御・サーチ・先制・アンコール・HP/MP の回復。56種の敵からスナップを作ると、ほとんどが「属性と威力の違うダメージ」になり、すぐネタ切れする。

### 考え方：いじれる「つまみ（軸）」を増やし、効き目を部品の組み合わせで作る
効き目の幅は、戦闘の中に、スナップが触れる物がどれだけあるかで決まる。つまみが増えるほど、組み合わせはかけ算で増える。

| つまみ | 今 | 足す物の例 |
| --- | --- | --- |
| 順番 | 先制だけ | 敵を列の後ろへ押し出す、次の行動を飛ばす、仲間と順番を入れ替える、もう1回動く |
| 敵の予告 | ぬしの「ため」だけ | 予告を見て打ち消す・書き換える・1つ後ろへずらす・奪って自分が使う（案2） |
| 属性と弱点 | 弱点を突く・見つける | 弱点を付ける、耐性を消す、仲間の技に属性を足す |
| 状態 | なし | やけど・こおり・しびれ・眠り、攻撃や防御の上げ下げ、かばう、反撃 |
| 場 | なし | 戦場の「時代」や「時刻」（夕暮れ・夜など）。場によって属性の強さが変わり、スナップで場を変えられる |
| 手札と山札 | 引く・探す・戻す | 持っているだけで育つ札、同じ時代の札をまとめて切ると強くなる（時代の印）、捨てた時に効く札 |
| 仲間と控え | なし | 控えと交代、控えから手助け（控えにいる仲間のスナップ） |
| 部位 | 部位を壊す | 部位を奪う、部位を直させない |

スナップ1枚は「条件 × つまみ × 見返り」で作れる。例：
- 「ダウンしている敵に」×「火のダメージ」×「MP が戻る」
- 「場が夜なら」×「敵の予告を1つ後ろへ」×「1枚引く」
- 「同じ時代の札を2枚目に切った時」×「全体の雷」

8つのつまみと、条件・見返りを組み合わせれば、100枚を超えても、違う使い方の札を作れる。

### 文字盤（案1）とラウンド（案ア）を、この観点で比べる
- 文字盤は「順番」のつまみが細かい（何時間ずらす）が、見て分からなかった。数字の細かさは、スナップの違いとして伝わらない
- ラウンドの戦闘は、順番がフィルムの帯で1列に見えるので、「押し出す・飛ばす・入れ替える」がはっきり見える。予告・状態・場・控えも、今の画面にのせられる
- そこで、**ラウンドの戦闘のまま、つまみを足す**のがよい。ただ、今の戦闘の仕組みは効き目をその都度作っているので、先に**効き目を部品にする**直しが要る（スナップを数値の表だけで作れるようにし、新しい札のたびに仕組みを書き足さなくてよい形）

### 進め方（案）
1. スナップの一覧のたたき台を、先に紙の上で作る（60〜80枚。敵ごとの56枚を含む）。つまみごとの枚数と、ネタが続くかを確かめる。足りないつまみがあれば、ここで見つかる
2. 戦闘の仕組みを、効き目の部品（条件・つまみ・見返り）・状態・場を持てる形に直す（今の戦闘のルールは変えずに、中身だけ組み直す）
3. 試しの区画で、新しいつまみ（予告・状態・控え）と、10〜20枚の新しいスナップを遊んでもらう

## 12. 雑魚戦の練り直し（2026-11-05。開発者と相談）

開発者：雑魚戦でも戦略性が出て、長いシナリオで中だるみしない形にしたい。中盤以降も、オートの早送りに頼り切らず、コンボや連鎖などの仕組みと作戦で、雑魚戦が早く終わるのが理想。

### 試しのコンボと現像（段階155）の手応え
ぬし・ボスの長い戦闘では生きそうだが、雑魚戦では狙う前にふつうに倒してしまい、あまり効かなかった。溜めてから使う仕組みは、2〜3ラウンドの戦闘では元が取れない。

### 数字で見た今の雑魚戦（自動対戦。各区画の雑魚戦すべて×30回）
- 雑魚は全員「弱点をちょうど1つ」持つ（1〜4章で、弱点のない雑魚・2つ持つ雑魚は0体）。1戦はほぼ3体
- 弱点をねらう方針は平均 2.3〜3.0ラウンド、でたらめな方針は 3.6〜4.3ラウンド。腕の差は約1ラウンドで、時間の差より負ける危険の差（3-1 で勝率 57% と 100%）に出ている
- 弱点をねらう方針は、約半分の戦闘で1ラウンド目に敵を全員ダウンさせているのに、ご褒美がなく、残りの HP を削るのに2〜3ラウンドかかる
- とどめの7〜8割は弱点だが、弱点で倒すと延長が付かない（うまく倒すほど手番を失う）
- とどめで倒しすぎた量は、敵の最大 HP の4〜6割（強い一手ほど無駄になる）

### いくつも出した案と、ピンと来なかった理由
マス目の戦闘（要素が多すぎる）、総攻撃・弱点で倒しても延長・倒しすぎを持ち越し、シャッター（全員止めたら切り取って決着）、写し取り、止まった時間で読む（敵の予定が全部見える）、思い出のかけら、すり切れたテープ、砂時計の奪い合い、一手決着、交代が主役、探索で仕込む、もしも札、しかけの連鎖、予定の書き換え、試写、段取り、を出した。良さそうなのは「シャッター」と「止まった時間で読む」だけで、どれもピンと来なかった。

考えた理由：ルールの話ばかりで「気持ちいい瞬間」がなかった。困りごとを消す方向（短くする）から考えていた。足し算ばかりだった。手本の部品のつぎはぎだった。

開発者の答え：
1. 気持ちよかったのは、エグゼの PA や自分で考えたチップのコンボが決まった時と、それを考えてフォルダを見直す時。敵ごとに特徴や動きが違った。ペルソナの、弱点を突いて総攻撃が決まった時と、敵に合わせてペルソナを選ぶ時。Slay the Spire の、手札を組み合わせてコンボと使う順番を考える時
2. 今の戦闘は、弱点を突く → 威力のある技を叩き込む、の1つの流れに固まっている。一度正解が分かると、同じ繰り返し
3. 惹かれたのは、考える楽しさ
4. 3人分の予約は、計画した物が動き出した時に思い通りに動くか、という少しプログラミング的な所が面白いと思って入れた。敵の行動の予定は、前もって見せる前提
5. 連携技は、メンバーを替える意味を持たせるため（クロノ・トリガーの連携技）

### 正解が1つに固まる理由
- 札の価値が「威力×弱点」の1つの物差しで決まる（14枚のほとんどが「ある属性で、ある威力」）
- 札どうしが影響し合わない（先に使っても後に使っても同じ。コンボは決まったレシピ）
- 敵の違いが数字だけ（動き方はでたらめ。どの敵にも弱点を突くのが正解）

### 決めた形：「並べて、つなげる」戦闘（今までで一番いい、と開発者）
- **敵の予定が見える**（止まった時間）：計画の前に、敵全員の次の行動・狙う相手・動く時刻が、フィルムに見えている
- **時間の予算として並べる**（FF10 と Slay the Spire）：フィルムに時刻の目盛りがある。仲間は並べた順に、行動の重さの分だけ時間を使う。重い大技を先に置くと、後ろの仲間が敵の時刻を過ぎてしまう。FF10 の「重い技ほど後になる」を残すため、並べた順だけで動かす形（重さの意味がなくなる）にはしない
- **札が前後の札とつながる**（エグゼの自作コンボ）：札に型がある。置く（敵に印）・受ける（直前の仲間の行動を受けて変わる）・数える（このラウンドに動いた数で強くなる）・締める（印やダウンで強くなる）
- **弱点が正解とは限らない敵**：敵ごとに1つの特徴（かたい・予告の全体攻撃・はじける・鏡）
- **仲間ごとの型**と、**フィルムで続けて動くと起きる連携技**（クロノ・トリガー）：誰を連れていくかで、使える連携技が変わる。メンバーを替える意味は、ここで持たせる。連携技は物語の出来事で増やし、絆の数値では増やさない
- **締め**：生きている敵が全員ダウンしたら、シャッターで切り取って決着（ペルソナの総攻撃）
- 捨てるもの：決まったレシピのコンボ（札の性質でつながる形にする）、現像。控えとの交代は、試しの手応えを見てから
- 懸念：作り直しが大きい（札・敵・戦闘のロジック・全区画の数値）。考える時間が延びる（雑魚戦1〜2分の目安）。並べ方と敵の予定を縦の画面に収める

試しは段階156（`docs/milestones/M3.md`）。

### 試しの手応え（2026-11-05。開発者）
- 考える楽しさは格段に上がった
- 行動がコマ送りで、何が処理されているのか分かりにくかった
- 同じ時刻に並んでいる敵と、どちらが先に動くのか分からなかった

直し（段階156の調整1）：フィルムに動く順の番号を付け、実行は1つずつ「誰が・何を・誰に」→「結果」の2段で見せ、動く順の一覧に結果を残す。タップで次へ

開発者の頼み 2：実行中のタイムラインは、コマ送りでなく左から右へなめらかに動かし、行動もその時刻に合わせて動く。攻撃元と攻撃先にエフェクトを付けると、誰が誰に攻撃したか分かりやすいのでは（うるさくならないか）。
考え：エフェクトは1つの行動に1組だけ（元が光る → 玉が飛ぶ → 相手が光る）、画面を揺らさない、起きなかった行動には出さない、にすれば、うるさくならず分かりやすくなる。段階156の調整2で作った

### 試しの手応え 2（2026-11-05。開発者）と、調整3
- 札の型の濡れ・油が分かりづらい → 印は属性の色だけにし、「同じ色を重ねると広がる（共鳴）」の1つの決まりにした。並べている時に、付く予定の印と「共鳴 ◯体」を出す
- 仲間の型と連携技が分からず使わなかった → 3つの案（時間の使い方が仲間ごとに違う／専用の札が手札に混ざる／自動の反応）から、開発者が「専用の札」を選んだ。「時間の使い方」はギアの効果であるべき（開発者）。組む2人の専用の札が手札にそろうと、手札の上に連携技が出る
- 敵の特徴の条件が難しい → 時間と順番で解ける特徴を中心に出し直し、開発者が10を選んだ：はじける・すばやい・盾・殻・ねばねば・起こし役・反撃・分裂・時限・逃げる（見送り：せかす・入れ替え・号令・挑発・まね・眠り・呼び出し）
- 自動対戦（60回）：考える方針は平均1.8〜2.2ラウンド、でたらめな方針は約4〜5ラウンドで、勝率は組み合わせで37〜100%
